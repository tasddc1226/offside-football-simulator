# OFFSIDE brand asset

`offside-app-icon-fulltime-v6.svg` is the source icon (pitch green + amber checkered linesman flag,
matching the 풀타임 palette). Runtime header, favicon, Apple touch icon, manifest icons, and the
Open Graph card use resized derivatives generated with Sharp.

`site.webmanifest` supplies install icon metadata only. It does not claim or provide offline/PWA support.
