# 미니 선수 v3 재설계 시안

PR #677에서 추가했던 헤어 6종·키퍼 용품 및 후속 도트 보정을 되돌린 뒤, 원본 PNG를 직접 표시하는 웹 렌더러를 추가했다. 기본 실행은 기존 9종이며 로컬 미리보기에서 새 PNG를 선택할 수 있다. 기존 꾸미기·은퇴 외형 제한·저장 동작은 유지한다.

## 새 시안

[비교 페이지](index.html)에서 전체 원본을 확인할 수 있다. 내장 image_gen으로 만든 투명 PNG를 도트 변환하지 않고 웹 전신 캐릭터와 실제 선수 카드 컴포넌트에 연결했다. 색·외형은 원본에 고정된 로컬 검토 단계다.

| 파일 | 디자인 |
| --- | --- |
| concepts/bald.png | 완전 민머리 |
| concepts/shaved.png | 짧은 삭발 |
| concepts/dread.png | 드레드 |
| concepts/fauxhawk.png | 금발 스파이크 모히칸 |
| concepts/ponytail.png | 금발 포니테일 |
| concepts/mullet.png | 투톤 꽁지머리 |
| concepts/keeper.png | 장갑·긴 소매·양쪽 무릎 보호대 |

각 시트는 서기·달리기·슈팅 3자세다. 기존 런타임의 전체 17자세는 아직 만들지 않았다. 같은 얼굴과 체형을 기준으로 생성했지만 생성 이미지 사이의 픽셀 단위 동일성을 보장하는 결과물은 아니다.

## 제작 기준

1. image_gen에서 전체 캐릭터 시안을 만든다. 얼굴·두상·체형 기준은 `references/approved-dread-keeper.png`다. 개별 헤어 참고 이미지는 머리 모양만 참고한다.
2. 원본 PNG는 수정하지 않고 해시와 정확한 프롬프트를 [generation.json](generation.json)에 남긴다. 웹 에셋으로 복사한 파일도 원본 바이트를 유지한다.
3. 도트 변환·재질 지도·색 재칠하기를 하지 않는다. SVG는 원본 PNG의 표시 영역을 자르는 뷰포트일 뿐이며 `image` 요소가 PNG를 직접 읽는다. `preserveAspectRatio`와 명시적 clipPath로 원본 비율과 자세별 경계를 유지한다.
4. 얼굴 패치·두상 압축·눈 위치 재조립·몸통 늘리기로 맞추지 않는다. 필요한 조형 수정은 image_gen 원본 단계에서 한다.
5. 실제 게임용 전체 모션과 커리어별 외형 매핑·꾸미기 정책은 후속 단계에서 결정한다. 고정 색 PNG를 기존 피부·머리·유니폼 선택의 결과로 저장하지 않는다.

## 로컬 웹 확인

`pnpm --filter @offside/web dev --host 127.0.0.1 --port 5201 --strictPort`로 실행한 뒤 `/avatar-png-preview.html`을 연다. 전신 144px·실제 게임 크기 72px, 일반·compact·mini 선수 카드, 원본 3자세, 밝은/어두운 배경을 비교할 수 있다. 리뷰 화면은 API·분석·세이브 초기화를 실행하지 않는다.

`/?avatarPng=dread`처럼 로컬 게임을 열면 웹 캐릭터·카드도 PNG로 표시한다. 이 옵션은 개발 서버에서만 동작하고 그 탭의 모든 선수에게 선택한 시안이 표시된다. 커리어별 배정이나 저장은 하지 않으며 기존 모션은 그대로다. PNG 로딩 실패 시 정지 캐릭터·카드는 기존 도트 렌더러로 돌아간다.

현재 단계는 **원본 PNG 웹 적용 미리보기**다. 운영 기본 적용·모바일 앱·전체 모션·색상별 꾸미기 연결·운영 배포는 포함하지 않는다. 검토용 HTML 엔트리는 운영 빌드에 포함되지 않는다.

## 이번 검증

- 롤백 직후 소스 트리는 기준 커밋 `393e2d19`와 동일
- 기존 avatar/save 테스트 35개 통과
- game 패키지 타입 검사 통과
- 새 PNG 원본은 재인코딩 없이 복사하고 SHA-256 기록
- 비교 페이지: 데스크톱 1466px·모바일 390px에서 PNG 8개 로딩, 비율 유지 및 가로 넘침 없음 확인
- 웹 PNG 원본 해시·알파·자세 경계 테스트 14개 통과
- 웹·app-core 타입 검사, 변경 파일 ESLint, i18n 검사 통과
- 웹 빌드·초기 번들 검사 통과(142.80KB gzip / 143KB 예산)
- 7종 모두 실제 전신·일반/compact/mini 카드 표시, 390px·320px에서 가로 넘침·카드 잘림 없음 확인
- 네이티브 앱 및 전체 모션 QA는 이번 웹 정지 외형 범위에 포함하지 않음
