# 미니 선수 v3 재설계 시안

PR #677에서 추가했던 헤어 6종·키퍼 용품 및 후속 도트 보정을 되돌렸다. 실행 코드는 기존 9종 미니 선수 기준으로 복원했으며 기존 꾸미기·은퇴 외형 제한·저장 동작은 유지한다.

## 새 시안

[비교 페이지](index.html)에서 전체 원본을 확인할 수 있다. 내장 image_gen으로 만든 투명 PNG이며 게임에 연결하지 않은 검토용 원본이다.

| 파일 | 디자인 |
| --- | --- |
| concepts/bald.png | 완전 민머리 |
| concepts/shaved.png | 짧은 삭발 |
| concepts/dread.png | 드레드 |
| concepts/fauxhawk.png | 금발 스파이크 모히칸 |
| concepts/ponytail.png | 금발 포니테일 |
| concepts/mullet.png | 투톤 꽁지머리 |
| concepts/keeper.png | 장갑·긴 소매·양쪽 무릎 보호대 |

각 시트는 서기·달리기·슈팅 3자세다. 기존 런타임의 전체 17자세나 색상 선택용 재질 지도는 아직 만들지 않았다. 같은 얼굴과 체형을 기준으로 생성했지만 생성 이미지 사이의 픽셀 단위 동일성을 보장하는 결과물은 아니다.

## 제작 기준

1. image_gen에서 전체 캐릭터 시안을 만든다. 얼굴·두상·체형 기준은 `references/approved-dread-keeper.png`다. 개별 헤어 참고 이미지는 머리 모양만 참고한다.
2. 사용자가 시안을 검토한 뒤 선택한 원본을 고정한다. 원본 PNG는 수정하지 않고 해시와 정확한 프롬프트를 [generation.json](generation.json)에 남긴다.
3. 도트 변환은 종횡비를 유지한 균일 배율로 진행한다. 결과가 나쁘면 원본에서 다시 변환하며 변환본을 연속 보정하지 않는다.
4. 얼굴 패치·두상 압축·눈 위치 재조립·몸통 늘리기로 맞추지 않는다. 필요한 조형 수정은 image_gen 원본 단계에서 한다.
5. 게임 연결 전 원본 대비 얼굴·실루엣, 기존 9종과의 일관성, 모든 모션·선수 카드, 웹·모바일 표시를 검증한다.

현재 단계는 **시안 검토**다. 도트 변환·게임 재연결·운영 배포는 포함하지 않는다. 비교 페이지는 PNG를 비율 그대로 보여 주며 바둑판 배경은 투명 영역 확인을 위한 CSS다.

## 이번 검증

- 롤백 직후 소스 트리는 기준 커밋 `393e2d19`와 동일
- 기존 avatar/save 테스트 35개 통과
- game 패키지 타입 검사 통과
- 새 PNG 원본은 재인코딩 없이 복사하고 SHA-256 기록
- 비교 페이지: 데스크톱 1466px·모바일 390px에서 PNG 8개 로딩, 비율 유지 및 가로 넘침 없음 확인
- 새 시안은 런타임에서 사용하지 않으므로 웹·앱 내 모션/카드 QA는 재연결 단계에서 진행
