# 00. 개발 로드맵

## 목표

OFFSIDE를 거대한 일괄 개발이 아닌, 매 단계 실제 플레이 가능한 수직 슬라이스로 완성한다. 각 Phase는 이전 Phase의 저장 데이터를 유지하며 독립된 완료 조건을 가진다.

## 기준 사용자 여정

```text
온보딩 → 커리어 허브 → 선수 생성 → 유소년 배경 → 입단 테스트 → 첫 계약
→ 커리어 대시보드 → 프리시즌 → 출전 경쟁 → 핵심 경기 챕터/이벤트 → 시즌 결산
→ 재계약·임대·이적 → 부상·관계·대표팀 → 성장·노쇠
→ 은퇴 → 통산 기록·Legacy Score·엔딩·연대기 → 새 커리어
```

운영 안정화 이후 WORLD STAGE ruleset의 신규 Career는 `국내 주전 경쟁 → 해외 관심·등록 → 가상 해외 리그·대륙대회 → 대표팀 국제대회` 경로를 Phase 3~5 사이에 추가한다. Phase 8은 개발·출시 순서이며 선수 인생의 마지막 단계가 아니다.

## 코드보다 먼저: 종이 프로토타입

Phase 0을 시작하기 전에 [종이 프로토타입](../content/prototype/season-01-inside-forward.md)을 최소 3회 플레이한다. 아키타입 하나, U18 한 시즌, 이벤트 10개, 핵심 경기 챕터 3개로 구성된다. 목적은 저장 안전성이 아니라 재미와 결정 밀도의 검증이다. 시즌당 결정 수, 소요 시간, 한 번도 고르지 않은 선택지, 이해되지 않은 숫자를 기록하고 [시간 모델](11-time-model-and-pacing.md)의 예산을 조정한 뒤 Phase 0에 들어간다.

## 단계와 출시 게이트

| Phase | 플레이 결과 | 핵심 게이트 |
|---|---|---|
| 0 | 앱·DB·시뮬레이터 골격 실행 | 결정론 테스트, 마이그레이션, CI |
| 1 | 생성한 선수가 첫 계약을 체결하고 복구 코드를 받음 | 새로고침 복원, 중복 제출 차단, 다른 브라우저 복구 |
| 2 | 한 시즌을 마치고 결과 확인 | 동일 seed 재현, 포지션별 통계, 챕터 판단 |
| LINE TEST | 외부 사용자가 한 시즌을 공개 플레이 | 세션 길이 목표, 결정 예산, 이탈 지점 측정 |
| 3 | 다음 팀·계약을 선택 | 협상 상태기계, 이적 원자 저장 |
| 4 | 부상과 관계가 커리어에 작용 | EffectQueue 만료·후속 이벤트 |
| 5 | 여러 시즌 후 은퇴·엔딩 | 전체 연대기 재생, Legacy 설명 가능성 |
| 6 | KICKOFF 시즌 도전과 결산 | 구/신규 시즌 분리, 보관함 보존 |
| 7 | 콘텐츠를 안전하게 운영 | 관측성, 롤백, 밸런스 리포트 |
| 8 | 해외 리그와 국제 무대로 확장 | 세계 데이터 호환, 등록 원자성, 복수 대회 집계 |

## 작업 스트림

각 Phase는 아래 스트림을 동시에 닫아야 완료된다.

1. **도메인**: 규칙, 상태 전이, 불변 조건.
2. **데이터**: 스키마, 마이그레이션, Snapshot.
3. **API**: 명령과 조회, 오류 계약, 멱등성.
4. **화면**: 로딩·편집·커밋·성공·오류·빈 상태.
5. **콘텐츠**: 이벤트·문구·확률·효과 데이터.
6. **검증**: 단위·계약·E2E·결정론·접근성.
7. **운영**: 로그·지표·릴리스·복구.

## 의사결정 게이트

ADR-001~009는 2026-09-02에 [`docs/adr/`](../adr/README.md)에서 확정했다. 요약: Vite React SPA, 클라이언트 Web Worker 시뮬레이션, 로컬 우선 저장과 서버 동기화, JSON 콘텐츠 팩, pnpm·Turborepo 모노레포, Cloudflare Workers Static Assets·API Workers·D1, 익명 프로필 + Google 로그인 1종, 앱인토스 미니앱으로 언제든 출시할 수 있는 채널 구조. 도메인 계약은 프레임워크에 의존하지 않는다.

남은 게이트는 사용자 액션 U-001~003(도메인·Cloudflare·Google OAuth)이다. 앱인토스 출시 준비(U-007~U-011)는 미니앱 출시를 결정한 뒤 착수한다. 상세는 [진행 보드](../tracking/board.md).

진행 관리와 워커 위임 규칙은 [`docs/tracking/`](../tracking/README.md)을 따른다.

## Phase 3 이후 병렬화

2026-09-03 결정. Phase 2까지는 순차다. 이후 모든 Phase가 시즌 루프(FootballSeason, 전술 적합도, 경기 통계, 시즌 집계 Effect) 위에서 돌기 때문이다. Phase 2 안에서도 도메인 슬라이스는 순서대로, 화면·검증만 병렬로 간다.

Phase 2가 끝나면 다음 구조로 병렬화한다.

1. **공유 계약을 먼저 닫는다**(Phase 2 계획의 T-2-014). Effect 큐의 만료·중첩 규칙, 시장가치의 입력 항목과 소유 Phase, CareerTag 목록과 부여 인터페이스. ADR 또는 contracts 작업으로 확정한다.
2. **트랙 A·B 병렬**: Phase 3(계약·임대·이적)과 Phase 4(부상·관계·평판). 도메인 영역이 겹치지 않는다. 맞물리는 지점은 Phase 4의 평판이 Phase 3의 시장가치 입력이 되는 것과, Effect 규칙을 둘 다 쓰는 것뿐이며 1번이 그 경계를 정한다.
3. **트랙 C·D 병렬**: Phase 5(은퇴·Legacy)와 Phase 6(KICKOFF 시즌 도전·결산). Phase 5는 다년 진행과 Phase 3 이적을 실제로 태워야 검증되고 태그는 Phase 4 산출물이다. Phase 6의 인프라(ServiceSeason 전이, 도전 evaluator, 보관함)는 먼저 만들 수 있으나 정식 시즌은 Phase 5까지 끝난 뒤 연다.
4. **LINE TEST와 겹치기**: LINE TEST가 도는 동안 Phase 3·4의 도메인 골격(계약 상태기계, 부상 모델)을 만든다. 밸런스 수치 조정만 LINE TEST 기준선 뒤로 미룬다. "LINE TEST 결과로 룰셋 1.0.0을 확정한 뒤 Phase 3"는 수치 확정에 대한 규칙으로 읽는다.

상한은 트랙 3개다. 워커 수보다 오케스트레이터 리뷰 병목, 5시간 사용량 한도, `packages/domain`·`contracts` 동시 수정 충돌이 한계를 정한다. 병렬 Phase는 서로 다른 상태 필드에만 쓰고, 공유 필드는 1번의 계약을 통해서만 바꾼다.

## LINE TEST 공개 게이트

Phase 2가 끝나면 `PRESEASON: LINE TEST` 서비스 시즌으로 외부 공개 테스트를 연다. Phase 3~5를 기다리지 않는다. 이 테스트의 커리어는 테스트 보관함으로 분리하고 정식 시즌 도전에 집계하지 않는다.

- 측정: [시간 모델](11-time-model-and-pacing.md)의 세션 길이 목표, 시즌당 결정 수, 이탈 step, 선택지 분포.
- 통과 기준: 첫 프로 계약 도달률, 첫 시즌 완주율, 두 번째 시즌 시작률을 기준선으로 기록한다. 기준선 자체가 산출물이며 Phase 3 이후 개선 목표가 된다.
- LINE TEST 결과로 ruleset 1.0.0을 확정한 뒤 Phase 3에 들어간다.

## 공통 Definition of Done

- 관련 요구사항 ID가 코드·PR·테스트에 연결된다.
- 정상·빈 상태·오류·재시도·중복 요청을 검증한다.
- 360px 모바일, 키보드, 스크린리더 핵심 흐름을 통과한다.
- 새 화면은 [시각 디자인 시스템](13-visual-design-system.md)의 토큰만 사용하고 [브랜드 가이드](12-brand-guidelines.md)의 어휘 폐쇄 목록을 지킨다.
- 결정이 열리는 화면은 [시간 모델](11-time-model-and-pacing.md)의 결정 예산 안에 있다.
- 동일 `seed + rulesetVersion + contentPackVersion + command`가 동일 결과를 낸다.
- 마이그레이션의 forward와 rollback 또는 안전한 roll-forward 절차가 있다.
- 사용자에게 보이는 결과와 저장된 정본이 일치한다.

## 범위 통제

첫 출시에서 실시간 3D 경기, 실제 구단·선수 라이선스, PvP, 유료 시즌 패스, 길드는 제외한다. WORLD STAGE도 실명 리그·구단을 복제하지 않고 독자적인 가상 리그 브랜드로 확장한다. 핵심은 짧은 선택으로 한 선수의 긴 축구 인생을 반복 플레이하는 경험이다.
