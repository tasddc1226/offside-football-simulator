# 12. 브랜드 가이드

## 브랜드 결정

| 항목 | 결정 |
|---|---|
| 워드마크 | `OFFSIDE` |
| 정식 서비스명 | `OFFSIDE: Football Career` / 한국어 `오프사이드 커리어` |
| 대표 문장 | 한 발 앞서거나, 모든 것을 놓치거나 |
| 선언문 | 커리어에는 VAR이 없다 |
| 시각 모티프 | 오프사이드 라인. 화면을 가로지르는 한 줄 |

`OFFSIDE`는 일반명사라 도메인·스토어·검색에서 단독 식별이 어렵다. 스토어 등록명, 도메인, SNS 핸들은 정식 서비스명 또는 `오프사이드 커리어`를 쓴다. 상표·도메인 가용성 확인은 Phase 0 ADR-006으로 둔다. 확인 전에는 워드마크만 문서와 UI에 사용한다.

## 브랜드가 약속하는 것

1. 커리어의 성패는 능력 하나가 아니라 타이밍·전술·관계가 함께 가른다.
2. 선택은 되돌릴 수 없다. 대신 선택 전에 위험과 영향 범위를 알려준다.
3. 은퇴한 선수는 실패 데이터가 아니라 완결된 축구 인생이다.
4. 새 시즌은 데이터를 지우는 리셋이 아니라 새 규칙으로 새 인생을 시작할 이유다.

약속 2와 3은 규칙으로 강제한다. 확정 결과 재추첨 금지는 RULE-EVT-001, 엔딩 표현 규칙은 [Legacy·엔딩](14-legacy-score-and-endings.md)을 따른다.

## 브랜드 어휘 폐쇄 목록

브랜드 어휘는 아래 목록으로 닫는다. 화면이나 캠페인에서 새 영문 대문자 용어를 만들 때는 이 문서를 먼저 고친다.

| 어휘 | 쓰는 순간 | 쓰지 않는 곳 |
|---|---|---|
| `KICKOFF` | 새 커리어 확정 CTA, 허브의 새 커리어 진입 | 시즌 시작, 경기 시작 |
| `FULL TIME` | 은퇴 확정 화면 표제 | 시즌 결산, 경기 종료 |
| `THE LINE HAS MOVED` | 서비스 시즌 전환 공지 표제 | 규칙 패치 공지, 일반 업데이트 |
| 시즌명 | `PRESEASON: LINE TEST`, `SEASON 1: KICKOFF` 등 | 축구 시즌 라벨 |

고정 서브라인:

- `THE LINE HAS MOVED` 아래에는 항상 `새로운 라인이 그어집니다`를 쓴다. `적용됩니다`는 폐기한다.
- `FULL TIME` 화면 마지막 줄에만 선언문 `커리어에는 VAR이 없다`를 쓴다. 온보딩(SCR-034)에서 한 번 더 보여줄 수 있다.

폐기한 어휘:

- `VAR CHECK`. VAR은 판정이 뒤집힐 수 있다는 뜻이라 "확정 결과 다시 보기"에 쓰면 재추첨 기대를 만든다. 다시 보기는 평이한 `리플레이`로 표기한다.
- 시즌 결산의 `FULL TIME`. 시즌 결산은 `시즌 결산`이다.

## 보이스 규칙

- 브랜드 어휘는 전환·확정·결산처럼 감정 무게가 있는 순간에만 쓴다. 일반 버튼과 설명 문구는 평이한 한국어를 쓴다.
- 계약, 부상, 저장, 삭제, 복구처럼 오해 비용이 큰 기능에는 브랜드 어휘를 쓰지 않는다.
- 결과 문구는 원인을 먼저 말한다. "실패했습니다"보다 "감독 신뢰가 낮아 선발에서 밀렸습니다"가 먼저다.
- 낮은 결과를 조롱하지 않는다. 하위 백분위, "실패한 커리어", "아쉬운 선수" 같은 표현은 금지한다.
- 실제 구단·선수·감독 이름을 쓰지 않는다. 팀·인물은 콘텐츠 pack의 가상 명칭만 쓴다.
- 조사 결합은 narrative token 후처리로 해결한다. 문장 템플릿에 `{name:이/가}` 형태를 쓰고 렌더러가 받침을 판정한다.

## 시각 정체성 요약

시각 토큰과 컴포넌트 규칙은 [시각 디자인 시스템](13-visual-design-system.md)이 정본이다. 브랜드 수준에서 고정하는 것은 다음이다.

- 라인 모티프는 KICKOFF, FULL TIME, THE LINE HAS MOVED 세 순간과 워드마크에만 쓴다. 일반 구분선으로 남발하지 않는다.
- 원작 커리어 게임의 오렌지·네이비 카드 룩을 쓰지 않는다.
- 숫자는 항상 고정폭 자릿수로 표시한다.
- Base OVR과 경기 예상치는 서로 다른 시각 토큰을 가진다.

## 원작과의 거리

이 프로젝트는 야구 커리어 게임 분석에서 출발했다. 장르 아이디어는 공유하되 다음은 반드시 달라야 한다.

| 영역 | 원작 | OFFSIDE |
|---|---|---|
| 화면 구조 | 카드 스택 단일 흐름 | 커리어 대시보드(SCR-029)를 중심으로 결정 화면이 열리고 닫힘 |
| 핵심 결정 | 시즌 단위 확률 추첨 | 핵심 경기 챕터(SCR-031)와 위험이 보이는 판단 |
| 능력 표현 | OVR 하나 | Base OVR과 경기 예상치 분리, 잠재력은 범위 |
| 엔딩 | 통산 기록 백분위 | 엔딩 타이틀과 기여 요인, 백분위는 보조 |
| 시각 | 오렌지·네이비 카드 | 심야 경기장 방송 그래픽, 라인 모티프 |

## 시즌 네이밍 체계

| 시즌 | 이름 | 중심 |
|---|---|---|
| 0 | `PRESEASON: LINE TEST` | 공개 테스트, 저장·OVR·이벤트 밸런스 |
| 1 | `SEASON 1: KICKOFF` | 프로 데뷔와 주전 경쟁 |
| 2 | `SEASON 2: TRANSFER WINDOW` | 이적·임대·에이전트 |
| 3 | `SEASON 3: DERBY` | 라이벌·라커룸 |
| 4 | `SEASON 4: EXTRA TIME` | 노장·복귀·은퇴 번복 |
| 5 | `SEASON 5: THE FINAL` | 대표팀·국제대회 |

시즌 이름은 축구 경기 용어를 시간 순서대로 따라간다. 새 시즌 이름을 정할 때도 이 순서를 지킨다.
