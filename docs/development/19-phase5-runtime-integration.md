# 19. Phase 5 런타임 통합과 인수 기준

2026-09-05 사용자 요청: 한국 국적 모듈을 포함하고, Phase 5를 main까지 통합한다.
초기 격리 코어 브리프는 당시 작업 이력이다. 현재 구현 범위는 이 문서가 설명하며,
미통과 항목을 완료로 바꾸지 않는다. Phase 3·4의 작업 소유권과 상태는 변경하지 않는다.

## 실행 경로

`START_SEASON(legacyLedger=true)` → 경기·결산 → 다음 커리어 선택 →
`RETIRE` → 원본 Snapshot + Archive + LegacyResult 원자 저장 → FULL TIME →
Legacy / 연대기 / 최종 프로필 → 선수 보관함에서 새 커리어.

- 기존 명령 로그에는 필드를 소급 삽입하지 않는다. 선택적 ledger로 기존 golden hash를 보존한다.
- 은퇴는 완료된 시즌 경계에서만 확정한다. 진행 중 시즌의 부분 결산은 지원하지 않는다.
- 취소는 명령을 만들지 않는다. 확정은 revision CAS 및 기존 commandId 멱등성 경로를 사용한다.
- 게임 상태는 `RETIRED`를 유지한다. Archive 존재 여부를 별도 저장한다. 서버가 단독으로
  게임 Snapshot을 `ARCHIVED`로 바꿔 재생 hash를 깨뜨리지 않는다. 기존 `ARCHIVED` 자료의
  임의 변환/복구는 이 변경에 포함하지 않는다.
- 마지막 계약은 실제 OFFERS 안의 철회되지 않은 1시즌 제안만 가능하다. 수락 성공과
  `lastChanceConsumed`를 같은 상태에 저장한다. 허용된 시즌을 마치면 추가 START_SEASON을
  거부하고 명시적인 은퇴 선택을 요구한다. 단순 나이만으로 자동 은퇴시키지 않는다.

## 수입·결장·대표팀 기록

- 새 ledger는 시즌 시작 계약의 주급, 해당 시즌 계약금, contractId를 고정한다.
  게임 수입은 `52 × 주급 + 해당 시즌 계약금`이며 세금·현실 통화 환산이 아니다.
  휴식 복무 시즌은 출전과 이 수입이 0이다. 실제 부상 결장은 경기 `outReason=INJURY`만 센다.
- 관계는 결산 후 약속 위반 반영까지 마친 감독/주장/라이벌/팬/에이전트 값을 기록한다.
- 승격은 선수의 팀 내 선발 순위가 아니라 해당 리그 순위와 promotionSlots로 판단한다.
- 과거 ledger 없는 시즌 수입은 추정하지 않는다. COMPLETE/PARTIAL/UNAVAILABLE을 표시한다.
- 성인 대표팀 출전은 현재 엔진의 NATIONAL_DEBUT 챕터 증거만 센다. 소집 횟수와 같지 않으며
  전체 A매치 통계라고 표시하지 않는다. U23 출전은 별도 집계한다.

## Legacy 1.0.0 정책

정규화 구현은 `packages/domain/src/legacy/result.ts`의 동결된 `LEGACY_POLICY`다.
계수는 정수 및 퍼센트로 직렬화해 정의 checksum을 만들고 결과에 보존한다.
기존 ruleset/content manifest의 실제 checksum을 Archive에 고정한다. 기존 manifest 파일을
덮어쓰지 않으며, 정책 내용 변경 시에는 새 Legacy 버전과 이전 실행 코드 보존이 필요하다.

| 축         | 현재 정확한 계산                                                                                                                                                                                            |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 성취 30%   | 리그 15/컵 10 × 리그 단계 100/75/50/25%, 출전 비율 40% 미만 절반. 평점 7.5·10경기·출전 60% 이상 개인 시즌 평가 6(최대 60), 성공 챕터 2(최대 30), 성인 출전 0.5(최대 20), U23 금/은/동 12/8/5. 전체 상한 100 |
| 기여 25%   | 시즌 평균: 출전 비율 × 40 + 포지션 기록 점수 × 50% + 약속 이행 10. 포지션 점수는 90분당 기록/기대치 × 80, 상한 100. GK 선방 3, DF 태클+차단+공중볼 8, MF 기회+전진패스+회수 12, FW 골+도움 0.7              |
| 장기성 15% | 0~20시즌 단조 증가 상한표 + 출전/50(최대 10) − 중대 부상 에피소드당 3(최대 15) + 컴백 태그 10. 상한 100                                                                                                     |
| 관계 15%   | 시즌 평균 80% + 최종 평균 20%. 감독/주장/팬/에이전트 4축. 과거 시즌은 보존된 감독 신뢰만 사용                                                                                                               |
| 서사 15%   | 태그 COMMON 5 / RARE 12 / EPIC 25 합, 상한 100                                                                                                                                                              |

시즌 전체가 아니라 trophy / individual-merit / performance / duration / relationships처럼
증거 종류별 sourceId를 나눈다. 같은 평점을 성취와 기여에 중복 사용하지 않는다.
태그는 원 사건 점수를 재가산하지 않고 희귀도만 사용한다.

14종 eligibility와 기존 우선순위 해소기를 연결한다. `ending-evidence.test.ts`는 각 엔딩을
원본 기록 → 검증된 Archive → LegacyResult 경로로 확인하며 무관 80점 이상 사례도 검증한다.
이는 통제된 RAW_EVIDENCE fixture이며, 모든 엔딩을 자연 발생시킨 명령 재생 테스트라고
주장하지 않는다. 복무·마지막 계약·멘토링·20시즌 명령 재생 테스트는 별도로 유지한다.
대기만성의 문서상 OVR/Legacy 밴드
혼용은 **최고 Base OVR 70 이상**으로 명시한다. 대기만성·멘토·무관은 은퇴 시 태그를
평가하며 신규 부여 이력과 Timeline을 남긴다. 최고 순간은 성공 챕터, 트로피, 최초 시즌,
은퇴 기록 순으로 실제 source를 선택한다. 아쉬운 기회는 마지막 확인에서 선택하지 않은
선수/지도자 에필로그이며, 존재하지 않은 이적 거절 사건을 꾸며내지 않는다.

### 대규모 분포는 별도 생성·관찰이 필요하다

포지션별 10,000개(총 40,000개) 실제 시뮬레이션 모집단 및 밴드 목표 2%/8%/30% 검증은
작은 단위 테스트로 대체할 수 없다. 검증된 production artifact가 없는 동안 백분위는
`percentileHidden=true`이며 UI에서도 숨긴다. 이 상태를 모집단 검증 완료라고 부르지 않는다.
정책 조정 이후에는 모집단을 다시 생성해야 한다. 실제 생성 프로토콜과 실행 결과는
추적 문서에서 관리한다. 2026-09-06 사용자 결정으로 이 합성 grade 비율은 관찰 목표이며 단독
merge hard gate가 아니다. Archive·Legacy 저장 호환성, 동일 품질 포지션 공정성, 실제 근거의
고득점 도달성, population provenance·count·seed 무결성은 계속 필수다.

## 한국 국적 모듈 — 이번 Phase 필수 범위

- KR + MALE는 KOREA 모듈, 다른 조합은 DEFAULT다. 기존 최소 DEFAULT 상태도 읽을 수 있다.
- 18세 이후 시즌 경계에서 축구 병행 복무 또는 두 시즌 선수 생활 휴식을 선택한다.
- 축구 병행은 현재 소속을 유지하는 **게임 추상화**이며 실제 군 구단 입단 제도가 아니다.
- 휴식은 2개 실제 FootballSeason을 소모하고 출전·수입을 중단한다. 선발 탈락/부상으로
  오기록하지 않는다. SERVICE_STARTED → SERVICE_COMPLETED가 연대기에 남는다.
- 18~~23세, OVR 65 이상, 짝수 번째 시즌 경계, 활성 부상·복무 없음이면 간소 U23 대회를
  시즌당 한 번 진행한다. 6경기, 경기당 결정 RNG 1회. 승리 기준은 OVR−10(25~~85 제한),
  5승/4승/3승을 금/은/동으로 기록한다. 4의 배수 시즌은 올림픽, 나머지는 아시안게임이다.
  실제 대회 일정·토너먼트 규칙을 재현하지 않는 게임용 달력이다.
- 아시안게임 금 또는 올림픽 메달은 체육요원 경로로 연결한다. 게임은 이를 ‘병역 면제’로
  표현하지 않는다. 현실 자격·의무 판정은 제공하지 않는다.
  제도 용어 참고: [병무청 예술·체육요원](https://www.mma.go.kr/contents.do?mc=mma0000752).
- 멘토링은 30세 이후, 주장 관계 50 이상, 시즌당 한 번이다. 3시즌 성공 기록이 멘토 태그로
  이어지며 실제 후배 선수 육성 시뮬레이션이나 감독 커리어 전체는 범위 밖이다.

## 저장·동기화

- 로컬: RETIRE의 Snapshot/명령/커리어/멱등 키/Archive/Legacy를 기존 RW 트랜잭션 하나에 저장.
- API: 소유권 검증 후 서버가 원본에서 Archive와 Legacy를 재계산해 `career_archives`에 저장.
  career CAS 및 snapshot/commands와 같은 D1 batch. 원본 hash 검증은 부정행위 탐지나
  서버 전체 명령 재생을 대신하지 않는다.
- GET은 소유자에게만 보관 원본을 반환한다. import는 원본과 Legacy를 재검산한 뒤 저장하며
  변조 결과와 unsynced 로컬 덮어쓰기를 거부한다. 커리어 삭제 시 보관 기록도 삭제한다.
- 은퇴 PUT의 선택적 `retirementReferencePopulationId`는 로컬에 이미 저장된 평가 기준을
  고정한다. 누락/null은 과거 집단 미탑재 결과이므로 서버도 백분위를 추가하지 않는다.
  문자열은 서버의 등록 집단 ID와 일치해야 한다. 점수·분포 배열은 클라이언트에서 받지 않는다.
  새 참조집단 배포 후 구버전/오프라인 은퇴를 처음 동기화해도 평가 기준이 달라지지 않는다.
- D1 migration `0004_mature_micromax.sql`은 추가 테이블만 만들며 기존 테이블/기록을 삭제하지 않는다.
- main 병합 후 CI의 quality + browser gates 통과 → staging D1 migration → API/web 배포.
  production 출시와 staging 자동 배포는 같은 의미가 아니다.

## 화면 검증 범위

SCR-025 FULL TIME은 통산·구단·최고 평점 시즌·트로피·수입·복무·대표팀 요약을 표시한다.
SCR-026은 엔딩/총점/밴드/기여 3개/아쉬운 경로/최고 순간, 상세의 5축이다.
SCR-027은 원본 Timeline revision 앵커, SCR-028은 공개 프로필과 한국어 태그다.
hidden potential/RNG는 UI에 제공하지 않는다. 시즌 결과는 연령 하락이 기록된 경우
SCR-023 성장 이슈 안내를 추가하고 기존 포지션별 능력 추세와 훈련 선택 흐름을 재사용한다.

UI는 기존 TDS 계열 토큰과 Dialog를 재사용한다. 새 전역 모션 시스템을 만들지 않고 기존
reduced-motion·화면 전환·초점 제어·블러 배경을 유지한다. 취소/저장 중 중복 제출/오류 재시도,
은퇴 후 재은퇴 버튼 비노출, 모바일 overflow, 새로고침 후 보관 결과 읽기를 확인한다.
