# 03. 경기·시즌 시뮬레이션 엔진

## 원칙

- Base OVR은 영구 기본 능력의 요약이지 출전 자격이나 경기 결과가 아니다.
- 감독 전술, 역할, 폼, 체력, 사기, 포지션 숙련도가 실제 경기 예상치를 만든다.
- 낮은 OVR 선수도 좋은 맥락과 판단으로 선발되고 활약할 수 있다.
- 같은 입력과 seed의 결과는 완전히 재현되어야 한다.

## RULE-OVR-001 Base OVR

```text
Base OVR = round(Σ 세부 능력치 × 포지션·역할 가중치)
```

- 역할 가중치의 합은 1.0이다.
- `roleWeightVersion`을 결과와 함께 기록한다.
- Form, Fitness, Morale, 감독 신뢰, 리그 수준은 포함하지 않는다.
- 큰 부상도 즉시 고정폭 감소시키지 않고 재활 결과로 영구 능력을 변경한다.

## RULE-PERF-001 경기 예상 퍼포먼스

초기 기준식:

```text
Expected Performance =
  Base OVR × 0.70
  + Tactical Fit × 0.12
  + Form × 0.08
  + Fitness × 0.06
  + Morale × 0.04

최종 Expected Performance *= Position Familiarity
```

포지션 숙련도 초기값은 자연 포지션 1.00, 숙련 포지션 0.97, 임시 포지션 0.92를 권장한다. 상수는 ruleset manifest에서 버전 관리한다.

Expected Performance는 **경기장 위의 퍼포먼스**만 설명한다. 이 식에서 전술 적합도 가중치는 12%라서 Base OVR 4점 차이를 뒤집으려면 적합도 약 34점 차이가 필요하다. "OVR이 낮아도 선발된다"는 약속은 이 식이 아니라 아래 선발 판정이 지킨다.

## RULE-SEL-001 선발 판정

감독은 경기마다 같은 역할 후보를 Selection Score로 줄 세운다.

```text
Selection Score =
  Tactical Fit × 0.40
  + Manager Trust × 0.25
  + Expected Performance × 0.25
  + Squad Status × 0.10
```

- Squad Status는 계약상 출전 약속, 주장·부주장 여부, 직전 경기 평점을 0~100으로 합산한 값이다.
- 상위 후보가 선발, 다음이 벤치, 나머지가 결장이다. 역할 정원은 팀 전술이 정한다.
- 부상·징계·대표팀 차출은 판정 전에 후보에서 제외한다.
- 감독 교체는 Tactical Fit과 Manager Trust를 재평가하므로 같은 선수의 선발 순위가 바뀔 수 있다.
- 결과 화면은 선발·벤치·결장 이유를 Selection Score 구성 요소 중 가장 큰 차이로 설명한다.

계산 예:

| 선수 | Base OVR | 전술 적합도 | 감독 신뢰 | 예상치 | Squad Status | Selection Score |
|---|---:|---:|---:|---:|---:|---:|
| A | 80 | 50 | 45 | 74.0 | 40 | 53.8 |
| B | 74 | 88 | 70 | 77.5 | 60 | 78.1 |

선수 B는 Base OVR이 6 낮지만 시즌 대부분을 선발로 뛴다. 이 표는 golden fixture가 된다.

## 시즌 생성 파이프라인

시즌은 [시간 모델](11-time-model-and-pacing.md)의 12개 step으로 진행한다. 파이프라인은 step 단위로 반복된다.

1. 일정, 대회, 팀 전술, 스쿼드 경쟁, 부상 가능 상태를 고정한다.
2. 각 경기의 선발·벤치·결장을 RULE-SEL-001로 결정한다.
3. 상대 수준과 역할별 관여량으로 출전 시간과 포지션 통계를 생성한다.
4. 핵심 경기만 사용자 선택 챕터로 열고 나머지는 빠르게 계산한다.
5. 팀 결과와 개인 기록, 약속 이행, 관계 변화를 함께 결산한다.
6. 영구 변화는 Base OVR 입력 능력에, 단기 변화는 별도 상태에 적용한다.

## 포지션별 결과

| 포지션군 | 필수 통계 |
|---|---|
| FW | 출전, 득점, 도움, xG, 슈팅, 전환율, 오프사이드 |
| MF | 출전, 도움, 기회 창출, 전진 패스, 패스 성공률, 볼 회수 |
| DF | 출전, 태클, 차단, 공중볼, 실점 관여, 클린시트 |
| GK | 출전, 선방, PSxG 대비 실점, 클린시트, 크로스 처리, 빌드업 |

모든 포지션에 0분, 교체 출전, 퇴장, 부상 이탈을 표현할 수 있어야 한다.

## 핵심 경기 선택

전체 경기를 직접 조작하지 않는다. 다음 조건 중 하나를 만족할 때 핵심 경기 챕터(SCR-031)를 생성한다.

| 조건 | 중요도 |
|---|---|
| 프로 데뷔전, 컵 결승, 승격·강등 결정전, 국가대표 데뷔 | MAJOR |
| 라이벌 더비, 친정팀 상대, 국제대회 토너먼트 | MINOR |
| 주전 경쟁자 부상·복귀 직후, 감독 교체 직후 첫 경기 | MINOR |
| 커리어 태그나 시즌 도전 과제와 관련된 경기 | 태그 정의가 지정 |

- 시즌당 챕터 수는 [시간 모델](11-time-model-and-pacing.md)의 결정 예산을 넘지 않는다. 후보가 많으면 MAJOR가 먼저, 같은 중요도면 가중치 순이다.
- `FAST` 모드는 MAJOR 챕터만 연다. 열리지 않은 챕터는 일반 경기로 계산하고 roll을 소비하지 않는다.
- 챕터 안의 경기 중 판단은 1~3개다. 각 판단은 `직접 돌파`, `안전한 연결`, `공간 창출`처럼 대가가 다른 2~3개 옵션을 제공하고, 결과 확률은 낮음/보통/높음 또는 정확한 수치로 사전에 알린다.
- 판단 선택지는 포지션군과 역할에 따라 다르다. 포지션 전용 선택지는 SCR-023 경기 판단 변형을 따른다.
- 챕터 결과는 경기 기록, 폼, 평판, 감독 신뢰, 커리어 태그에 작용하며 Base OVR을 직접 바꾸지 않는다.

## 성장과 노쇠

```text
세부 능력 변화 = 훈련 + 출전 시간 + 경기 경험 + 코칭 + 성격 보정
                 - 부상 후유증 - 연령 하락
```

- 속도·가속은 18~25세 성장 후 가장 먼저 감소한다.
- 기술은 21~29세 성장하고 30대 초반까지 비교적 안정적이다.
- 판단·위치선정은 24~33세까지 성장 가능하다.
- 골키핑·리더십은 27~34세 전성기가 가능하다.
- Potential은 도착점이 아니라 성장 속도와 soft cap에 영향을 준다.

## 리그와 시장가치

OVR은 리그와 무관한 동일 척도를 유지한다. 기록 비교 시 `leagueStrength`와 `competitionLevel`로 난이도를 정규화한다.

```text
Market Value Index = Base OVR 35% + Scouted Potential Mid 20% + Age Curve 15%
                   + Contract 10% + League 10% + Form 5% + Popularity 5%
```

- `Scouted Potential Mid`는 공개된 정찰 범위의 중간값이다. 숨긴 `truePotential`을 쓰면 시장가치에서 잠재력이 역산되므로 금지한다.
- 금액은 국가 경제, 포지션 희소성, 잔여 계약, 구단 재정을 추가 적용한다. 시장가치와 연봉은 OVR을 역산해 결정하지 않는다.

## 결정론 입력

```text
SimulationInput = careerSnapshot + command + seed
                + rulesetVersion + contentPackVersion
```

날짜, 배열 순서, 부동소수점 반올림, 난수 소비 순서를 명시한다. 시스템 시간이나 DB 정렬에 결과를 의존시키지 않는다.

시뮬레이션은 브라우저 Web Worker에서 실행되고 서버는 같은 코드로 리플레이 검증만 한다([ADR-003](../adr/ADR-003-simulation-location.md)). 따라서 `packages/domain`은 `Date.now`, `Math.random`, 파일·네트워크·DOM API를 쓰지 않고, 확률 계산은 정수 또는 고정 소수점으로 한다. 정렬은 항상 안정 키를 지정한다.

## 필수 테스트 벡터

- 포지션·역할별 고정 능력 세트의 OVR golden test.
- RULE-SEL-001 계산 예의 선수 A·B가 한 시즌에서 선발 수 B > A를 만족.
- 시장가치가 정찰 범위 밖의 정보를 드러내지 않음(같은 범위·다른 truePotential의 두 선수가 같은 시장가치).
- FAST와 CHAPTER 모드의 경기 통계 분포 동일성.
- 0분·퇴장·부상 시즌 통계 집계.
- 같은 seed 1,000회 재실행 해시 일치.
- 성장·노쇠 경계 나이와 clamp.
- 리그 이동 전후 Base OVR 불변.
