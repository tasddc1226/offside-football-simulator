# T-11-385 Cloudflare 포함 자원 활용 개선

목표: 추가 요금제 가입 없이 불필요한 Workers/D1 작업을 줄이고 실패 복구 여유와 보안을 강화한다. 2026-10-18 사용자 승인으로 계획·구현·검증·운영 반영·전후 관측을 순차 실행한다.

운영 DB의 대량 삭제·임의 재처리, 결제 메시지 자동 재전송, 신규 유료 제품 가입은 범위 밖이다. 설정 변경 전 원본과 복구 값을 보존한다. 권한 또는 등록기관 외부 의존성은 완료로 표시하지 않고 구체적인 후속 조치를 남긴다. 개선 폭은 실제 지표가 확인된 범위에서만 보고한다.

## 기준선

2026-10-01 09:00~10-18 16:15 KST Analytics 집계: Workers 약 1,758만 호출/CPU 1억 978만 ms, D1 읽기 약 111.9억 행·쓰기 약 4,340만 행. 운영 D1 현재 약 4.36GB, R2 현재 약 8.98GB. 청구 API 권한 제한으로 계약·갱신일·실제 청구액은 미확인이다. 달력 월 누적은 청구 주기의 잔여량이 아니다.

Smart Placement·D1 자동 읽기 복제·HTTP/3·Brotli·Early Hints·Tiered Cache·DLQ·예산 알림은 이미 사용 중이다. Argo는 별도 과금 기능이므로 효과·청구 내역 확인 전 임의 해지하지 않는다.

## 2026-10-19 재개 점검

최신 main `8834aabf`를 기존 전용 워크트리에 통합했다. 기존 구현과 롤백 기준은 유지한다.

- [자동 예약 실행](https://github.com/tasddc1226/offside-football-simulator/actions/runs/39175266178)과 [09:56 KST 수동 최신 조회](https://github.com/tasddc1226/offside-football-simulator/actions/runs/39182985463)는 모두 성공했다. 수동 조회를 자동 실행으로 세지 않는다.
- 일일 처리 `day=2026-10-18`은 UTC 날짜 키다. 실제 시작·완료 시각은 10-19 KST이며 백업 40개 조각·696,654,491바이트와 완료 메타가 일치했다. 전체 복원 검증을 수행한 것은 아니다.
- 최신 리소스 조회: DLQ 5개 모두 적체 0·14일, D1 건강 스냅샷 4.02GiB·이슈 없음, R2 9.959GB 경고. R2 현재 payload는 월 GB-month 청구량·하드 용량 제한이 아니다. 새 백업 약 0.697GB가 증가 요인임을 확인했으며 사용자 보관 기록·월간 백업·30일 일별 보존을 유지한다.
- DNSSEC 활성화 요청 시각은 10-18 16:27 KST다. Cloudflare Registrar는 CDS/CDNSKEY 검색으로 자동 DS를 제출하며 공식 문서는 1~2일이 걸릴 수 있고 수동 발행 시점 제어는 불가하다고 설명한다. 10-20 16:27 KST까지도 미발행이면 등록기관 지원 확인용 근거를 다시 수집한다. 비활성화·재활성화로 상태를 흔들지 않는다.
- 현재 goal 미완료 사유는 DNSSEC 검증 체인 미성립이다. 요금제·갱신일·실제 청구액 조회 제한과 백업 실복원 미실시도 보고서에 구분한다.
