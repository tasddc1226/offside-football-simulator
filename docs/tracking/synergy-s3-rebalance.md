# 시즌 3 듀오 재조정 (T-11-843)

## 배경

디시 갤러리 11-28 장문 후기의 핵심은 "오래 할수록 99 뽑고 나머지는 갈아서 강화하는 게 정답이 되고, 포메이션도 4-2-3-1이 정답"이라는 수렴 문제였다.
11-28 시즌 2 팀 순위 1~~200위 · 501~~600위 · 1001~1100위(400팀)를 공개 팀 API로 받아 확인했다.

- 1~~50위는 선발 11명 전원을 강화했다(자리당 +5.7). 51~~200위와의 OVR 차이 6.3 중 3.3이 강화다.
- 시너지는 약하지 않다. 1~50위에서 시너지와 강화의 득점 기대 기여(로그 xG)가 비슷하고(0.43 · 0.40), 50팀 전부 '우리가 키운 팀' · '클럽 동료'를 켰다. 시너지 총량을 올리면 상위권만 더 세진다.
- 4-2-3-1이 1~~50위의 54%(51~~200위 22%). 상위 200팀에서 4-2-3-1은 듀오를 평균 11.1개, 4-3-3은 7.6개, 스리백은 7.4개 켰다.
- 상위 200팀에서 거의 안 켜진 듀오: 양 날개 5 · 스리백 7 · 철벽 9 · 더블 볼란치 9 · 섀도 스트라이커 17 · 빅 앤 스몰 55. 철벽(골문 +2)은 벽 계산에 0.3만 들어가 1~50위 중 0팀.

## 결정

시너지 총량과 기존 듀오는 그대로 두고, 안 쓰이던 듀오 여섯 개만 서비스 시즌 3부터 효과를 올린다(`DuoDef.s3`, `duosFor(season)`이 시즌 3부터 바꿔 준다). 시즌 2까지의 팀 · 경기는 옛 효과로 센다.

| 듀오            | 시즌 2까지          | 시즌 3부터          |
| --------------- | ------------------- | ------------------- |
| 스리백          | 중원 +0.5 · 수비 +1 | 중원 +0.5 · 수비 +2 |
| 철벽            | 골문 +2             | 수비 +1.5 · 골문 +1 |
| 빅 앤 스몰      | 공격 +1             | 공격 +1.5           |
| 양 날개         | 공격 +1             | 공격 +1.5           |
| 섀도 스트라이커 | 공격 +0.5           | 공격 +1             |
| 더블 볼란치     | 수비 +0.5           | 중원 +1 · 수비 +1   |

포메이션마다 선수 유형을 가장 잘 맞췄을 때 켤 수 있는 듀오의 득점 기대 기여(로그 xG, 언덕 오르기 탐색):
4-2-3-1 0.328 → 0.329, 4-3-3 0.323 → 0.329, 4-4-2 0.332 → 0.348, 3-4-3 0.314 → 0.350, 3-5-2 0.279 → 0.334, 5-3-2 0.254 → 0.300, 4-4-1-1 0.238 → 0.274, 4-1-4-1 0.204 → 0.224.
스리백 계열이 4-2-3-1 수준까지 올라오고 4-2-3-1은 그대로다.

## 하지 않은 것

- 강화 비용 인하: 상위 50팀 차이의 절반이 강화라 싸지면 쏠림이 커진다.
- 강화 묶임(한 번 강화한 선수를 못 바꿈)은 수치로 풀리지 않아 다음 단계(강화 옮기기, 유료 판매 없음)로 따로 정한다.
- 4-1-4-1 · 4-4-1-1은 여전히 낮다. 시즌 3 데이터를 보고 다시 본다.

## 다시 볼 것

시즌 3 개막 2주 뒤 같은 방법으로 상위 200팀 포메이션 분포와 포메이션별 듀오 수를 다시 센다.
