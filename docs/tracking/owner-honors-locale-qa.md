# 구단주·명예관 영어/일본어 화면 검증

검증 대상은 PR #563에서 변경한 내 구단, 프로필 편집, 구단 가치 안내, 선수 관리·기록·상세, 명예관과 시즌 기록이다. 게임의 모든 기존 화면을 전수 검증한 결과는 아니다.

## 웹

- 로컬 `honors563.localhost:5196`, 로컬 복원 DB의 명예관 테스트 계정으로 확인했다.
- 영어·일본어 각각 320 / 375 / 768px에서 본문 줄바꿈, 버튼 너비, 가로 넘침을 확인했다.
- 획득/도전 중 칭호, 진행 중 시즌/프리시즌, 시즌 상세 하단, 트로피, 선수 방출 확인 상태를 포함했다. 실제 선수 방출·공유는 실행하지 않았다.
- 프로필 편집은 320px 큰 글자 설정도 확인했다.
- 긴 선수 관리·시즌 버튼 문구를 줄이고, 중복 숫자 단위를 제거했다. 일본어 팀 레이팅 라벨을 짧게 정리했다.
- 시즌 순위는 긴 항목명과 순위·상위 비율을 두 줄로 나누어 비율 배지가 잘리지 않도록 했다.
- 브라우저 측정에서 페이지 가로 넘침은 없었다. 계정 링크 버튼의 4px 확장값은 텍스트 넘침이 아니라 기존 가상 요소의 터치 영역이다.

스크린샷과 측정 보고서: `/tmp/locale-audit/` (로컬 임시 파일).

## Android

연결 기기: Samsung SM-N976B, Android 13, 1440×3040 / 560dpi, 시스템 글자 배율 1.0.

운영 앱과 분리된 `com.offsidelab.app.honors563` 테스트 앱을 로컬 API에 연결해 검증했다. 기존 로컬 디버그 앱에는 현재 광고 네이티브 모듈이 없어 신규 테스트 바이너리를 생성했다. 운영 앱 데이터는 변경하지 않았다.

- 영어·일본어 내 구단, 구단 가치 안내, 프로필 편집, 선수 목록·상세, 획득/도전 중 칭호, 프리시즌 상세를 직접 조작해 확인했다.
- 내 구단과 프로필 편집은 앱의 표준/매우 큰 글자 설정 모두 확인했다. 영어·일본어 화면에서 키보드를 연 상태에서도 이름 입력창, 변경 버튼, 닫기 버튼이 보인다.
- 프로필 편집의 키보드 가림을 재현한 뒤, 해당 다이얼로그에만 키보드 회피를 적용했다.
- 상세 결산이 열리자마자 다시 접히던 Android 오류를 수정했다. 내장 결산의 `useRefresh` 등록으로 ScrollView의 새로고침 래퍼가 추가되면서 명예관이 재마운트되었다. 이미 불러온 내장 결산은 새로고침에 참여하지 않도록 했다. 독립 화면의 기본 동작은 유지한다.
- 시즌 기록 배지와 팀 통계는 2열로 정리하고, 내 구단의 전적 칸을 넓혀 일본어 마지막 글자만 줄이 바뀌는 현상을 줄였다.
- 상세 선수단, 통계, 시즌 순위와 하단 공유 버튼을 스크롤해 확인했다. 실제 공유·프로필 저장·선수 방출은 수행하지 않았다.
- 테스트 앱의 글자 크기는 표준으로 복원했다. 시스템 설정은 바꾸지 않았다.

스크린샷: `/tmp/android-locale-audit/` (로컬 임시 파일).

## iOS 실기기

연결 기기: iPhone 16e, iOS 26.6.1, 1170×2532px / 390×844pt. USB XCTest 자동 조작과 스크린샷으로 확인했다.

기존 개발 앱을 보존하고 `com.offsidelab.app.honors563` 별도 테스트 앱을 설치했다. 로컬 API와 같은 명예관 테스트 계정을 사용했다. 운영 계정·데이터는 변경하지 않았다.

- 영어·일본어 내 구단, 프로필 편집, 구단 가치 안내, 보유 선수·시즌별 기록·선수 상세, 획득/도전 중 칭호를 확인했다.
- 두 언어 모두 앱 글자 크기 표준/매우 크게에서 내 구단과 프로필 편집을 확인했다. 키보드가 열린 상태에도 이름 입력창, 변경, 닫기 버튼이 보인다. 기기의 한국어 키보드를 사용했고 시스템 언어·글자 크기는 변경하지 않았다.
- 진행 중 시즌과 프리시즌, 선수단·통계·팀 전적·시즌 순위·공유 버튼까지 확인했다. 상세 기록은 펼친 상태로 유지된다. 하단 버튼은 홈 인디케이터와 메뉴 위에 표시된다.
- 스크롤 본문이 시계·배터리 뒤로 비치는 문제를 재현했다. iOS의 상단 안전 여백을 스크롤 내용에서 바깥 컨테이너로 옮기고 실제 스크롤 화면에서 해결을 확인했다. Android 분기는 유지했다.
- 구단 가치 안내의 기본 확인 버튼이 기기 언어로 표시되는 것을 확인하고, 기존 번역 사전의 닫기 문구를 명시해 앱 언어를 따르도록 수정했다.
- 테스트 앱 글자 크기는 표준으로 복원했다. 실제 프로필 저장·이미지 업로드·선수 방출·공유는 실행하지 않았다. 보유 선수는 선발 상태라 방출 비활성 안내를 확인했으며, iOS에서 방출 완료 흐름을 검증한 것은 아니다.

스크린샷과 빌드·검사 로그: `/tmp/ios-locale-audit/` (로컬 임시 파일).

## 자동 검증

웹 영어/일본어 시즌 순위 배치 회귀 테스트(320/375/768px)와 기존 명예관 흐름, 프로필·선수 관리 E2E를 통과했다. 모바일 타입 검사·ESLint, 웹 타입 검사, i18n 및 릴리스 노트 검증도 통과했다. 웹 Svelte 검사에는 기존 경고 2개가 남아 있다.

## 검증 범위의 한계

운영 배포, 실결제, 광고 보상, 운영 계정 변경은 이 작업의 검증 결과에 포함하지 않는다. iOS 검증은 별도 Debug 앱과 로컬 API 기준이며, App Store 배포 바이너리나 웹 Safari 실기기 검증이 아니다.
