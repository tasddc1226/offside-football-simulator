# T-11-223: 감독 커리어 이벤트 50

[감독 키우기 1단계 기획](manager-career-plan.md)의 시즌 구간 이벤트 후보다. 실제 감독 커리어에서 널리 알려진 장면을 뼈대로 삼았다.

- **실명은 게임에 쓰지 않는다.** "영감" 칸은 기획 참고용이다. 게임 문구는 가상의 구단 · 선수 · 인물로 쓰고 `copy-style.md`를 따른다(장면으로 끝내기, 해요체).
- 사례는 공개적으로 잘 알려진 사실만 골랐다. 구현 단계에서 문구로 옮길 때 사실관계를 다시 확인하지 않아도 되도록, 게임 문장은 사례를 그대로 재현하지 않고 상황만 빌린다.
- 선택지는 2~3개다. 정답 하나보다 대가가 다른 선택을 두었다.

## 영향 값

| 값   | 뜻                                              |
| ---- | ----------------------------------------------- |
| 평판 | 감독 시장 가치. 제안 오는 구단 수준 · 은퇴 등급 |
| 신뢰 | 이사회 신뢰. 낮으면 경질 위험                   |
| 사기 | 선수단 사기. 다음 구간 성적 보정                |
| 팬   | 팬 지지. 신뢰 회복 속도 · 언론 이벤트 빈도      |
| 재정 | 구단 예산. 영입 · 시설 이벤트 선택지를 연다     |
| 전력 | 다음 구간(또는 시즌) 팀 전력 보정               |
| 숙련 | 포메이션 숙련 진척(지금 주력 포메이션)          |
| 성향 | 공격 · 균형 · 수비 · 역습 쪽으로 기울기         |
| 특기 | 특기 진척(측면 · 중원 · 수비 · 역습 · 유스)     |

표기: ↑ 오름, ↓ 내림, ↑↑ 크게 오름. 수치는 구현 때 정한다.
