# 5대 리그 유스 슈퍼리그 경로 기획

> 상태: 기획 제안 · 구현 및 운영 적용 전
> 기준: 2026-10-13 원격 main `1a67ecd7`. T-11-238의 네 기능은 별도 로컬 구현이며 이 문서 PR에 포함되지 않습니다.
> 수치·새 저장 필드·새 함수명은 구현 시 검증할 설계 후보입니다. 이 PR 병합은 기능 출시 승인이 아닙니다.

## 문제와 목표

국적을 달리 골라도 한국 고교에서 시작하는 현재 경로 외에 해외 유스에서 프로로 올라가는 선택지를 제공합니다. 피드백의 유스슈퍼리그는 **게임 내 가상 통합 유스 대회**로 기획합니다. 실제 존재하거나 공식 자격 규칙을 재현하는 리그로 소개하지 않습니다.

## Phase 0 현재 기반과 제약

- `packages/contracts/src/club-names.ts`: `LEAGUE_BASE`, `CLUB_NAMES`, `clubIdOf`. 배열 위치로 구단 ID를 만들므로 기존 배열을 재정렬하면 옛 저장의 소속이 바뀝니다.
- `packages/game/src/engine.ts`의 `newGame`, `packages/game/src/season.ts`의 `highSchoolShelf`, `universityShelf`, `makeOffers`는 고교→대학/프로 경로를 가집니다.
- `packages/game/src/nation.ts`는 외국 국적도 한국 고3에서 시작한다고 명시합니다. 국적과 시작 경로는 다른 선택입니다.
- `packages/game/src/comps.ts`의 `CUPS`·`CONT_SLOTS`, 리그별 일정/성장/연봉, 프로·아마추어 판정과 서버 은퇴 가치 계산도 영향을 받습니다.

## 제안 범위와 흐름

새 커리어에 한해 기존 고교 경로와 유럽 유스 경로를 선택합니다. 기존 커리어를 유스로 이동시키지 않습니다. 생성 나이를 낮추는 기능은 첫 단계에서 제외하고 현재 시작 나이와 같은 연령에서 경로만 달리합니다.

첫 버전은 영국·스페인·독일·이탈리아·프랑스 배경의 가상 유스 구단을 하나의 리그에 모읍니다. 팀 수와 명칭은 별도 콘텐츠 표로 확정합니다. 성인 1군 구단의 실제 명칭·순위를 그대로 유스 전력으로 쓰지 않습니다. 구단 카드는 유스임을 명확히 표시합니다.

유스 시즌 종료 시 프로 입단 제안과 유스 잔류를 제안합니다. 최대 재적 시즌과 방출 시 대체 경로를 정해 선택지가 없는 저장을 만들지 않습니다. 대체 경로 후보는 국내/해외 하부 프로 테스트이며 대학 자동 편입은 첫 버전에서 제외합니다.

## 성장·계약·국가대표 경계

유스는 초기 능력치·잠재력의 추가 보너스 경로가 아닙니다. 기존 고교와 같은 생성 총합에서 출발해 일정/성장 차이는 실험으로 검증합니다. 유스 수당/연봉·유스 활약의 프로 제안 평가·프로 통산 기록 포함 여부는 명시해야 합니다. 아마추어 기준을 재사용할지 별도 육성 리그 구분을 둘지는 서버 집계까지 보고 결정합니다.

유스 소속만으로 챔스·성인 리그 우승을 얻지 않습니다. 대표팀 발탁은 국적/기량의 기존 규칙과 충돌하지 않아야 하며, 대한민국 국적의 병역을 해외 유스 소속 때문에 면제하지 않습니다. 은퇴 가치·LS·최초 기록에서 유스 시즌을 성인 5대 리그 시즌으로 세지 않습니다.

## Phase 1 모델과 일정

- 새 리그와 구단 ID는 기존 항목 뒤에 독립적으로 추가합니다. `newGame`의 시작 경로, 최대 재적 기간, 시즌 종료 선택지, 실패 시 테스트 경로를 먼저 문서화합니다.
- 국내/유럽 달력과 시즌 이름이 뒤섞이지 않도록 유스 리그의 연간 일정·경기 수·컵 참가 여부를 정합니다.
- 검증: 기존 고교/대학 세이브·구단 ID 동일, 외국/한국 국적 모두 생성 가능, 졸업/방출/입단/무제안 경로가 끝까지 진행됨, 프로 통산/가치 제외 규칙 일치.

## Phase 2 웹 앱과 서버 계약

- 생성 화면에서 경로를 고르고 후보는 동일한 생성 규칙을 사용합니다. 리그 이름만 바꾸고 기존 고교 소속을 그대로 저장하지 않습니다.
- 커리어 업로드·은퇴 요약 검증·명예의 전당 필터·공개 가이드·국가별 표시를 함께 점검합니다. 새 리그를 모르는 구버전 앱의 저장/복원 정책도 정합니다.
- 검증: 고교와 유스의 프로 데뷔 나이·유럽 도달률·최고 OVR·LS·자금 분포 비교, 리그별 새 쿼리 인덱스 필요 여부, 웹/앱 경로 일치.

## 미확정 사항

팀 수·클럽 별칭, 재적 상한, 계약/수당, 리그 수준, 기존 시즌 중 출시와 다음 서비스 시즌 적용 중 선택, 방출 후 대체 경로를 확정해야 합니다. 기존 리그 배열 변경만으로 출시할 수 있는 작업은 아닙니다.
