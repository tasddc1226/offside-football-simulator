# 선수 사치품과 사업 확장 기획 경계

> 상태: 기획 제안 · 구현 및 운영 적용 전
> 기준: 2026-10-13 원격 main `1a67ecd7`. T-11-238의 네 기능은 별도 로컬 구현이며 이 문서 PR에 포함되지 않습니다.
> 수치·새 저장 필드·새 함수명은 구현 시 검증할 설계 후보입니다. 이 PR 병합은 기능 출시 승인이 아닙니다.

## 상태와 목표

사용자가 별도 작업으로 진행할 예정이라고 지정한 항목입니다. 이 문서는 담당 작업과의 계약을 정리하는 기획 초안이며, 이번 잔여 과제에서 병행 구현하지 않습니다. 소비·선택으로 선수의 생활을 표현하되 반복 구매가 기존 육성 체계를 무제한 대체하지 않도록 합니다.

## Phase 0 현재 기반

- `packages/game/src/training.ts`의 `INVESTS`, `investCost`, `applyInvest`와 `packages/game/src/invest.test.ts`의 기존 자기 투자 동작을 먼저 읽습니다.
- `packages/game/src/types.ts`의 선수 `money`, `invest`, 계약 연봉과 `packages/game/src/boost.ts`의 성장 자금 지출 경로를 구분합니다. 파일·심볼의 실제 위치는 구현 착수 시 다시 확인합니다.
- `docs/tracking/owner-funds-card-market-plan.md`는 구단주 카드 경제의 별도 기획입니다. 초기 작성 당시의 '재화 없음' 같은 상태는 현행 구현을 뜻하지 않습니다.

## 제안하는 최소 범위

첫 단계는 사치품 보유형 선택과 사업 한 종류를 분리해 실험합니다. 선수 개인 자금으로만 구매하고, 구단주 자금·IAP·광고 보상으로 직접 스탯을 사는 경로는 연결하지 않습니다. 장식품의 소유, 사업의 수익, 훈련 효과를 같은 값으로 혼합하지 않습니다.

차량·주거 같은 사치품은 만족도/회복 같은 생활 효과 후보로, 사업은 자금 수입과 관리 비용 후보로 다룹니다. 영구 능력치 상승을 넣을 경우 품목별 1회·시즌별 누적 상한과 기존 투자와의 중복 규칙을 먼저 정합니다. 반복 구매·매각 차익·시즌 변경으로 누적 상한을 우회하지 못하게 합니다.

## 사용자 흐름

선수 탭에서 비용·유지비·발동 시점·효과·보유 상태를 보고 명시적으로 구매합니다. 매각이나 사업 철수는 다음 정산에 어떤 영향이 있는지 안내합니다. 원금 보장 여부와 손실 가능성을 게임 규칙으로 먼저 정하며 실제 금융상품처럼 소개하지 않습니다.

## Phase 1 담당 작업과 합의

- 기존 자기 투자 목록에서 중복되는 효과를 표로 대조합니다. 품목·가격·상한·사업 정산 시점과 손실 정책은 별도 담당 기획에서 확정합니다.
- 선수 자금의 귀속, 은퇴 시 보유품 처리, 다른 선수에게 이전 불가 여부, 사업 때문에 기존 커리어를 강제로 끝낼지 여부를 문서로 정합니다. 강제 종료는 첫 버전에서 제외하는 방향을 제안합니다.
- 검증: 단위/통화 혼동 없음, 결제 보상과 우회 연결 없음, 이미 구현된 투자와 동일 효과 중복 구매 없음.

## Phase 2 저장과 밸런스

보유품 불변 ID·효과 적용 이력·마지막 정산 시즌을 저장하는 안을 검토합니다. 옛 저장은 보유품 없음으로 시작하고 기존 자금/성장 값은 유지합니다. 이미 마친 시즌에 사업 수익을 소급 지급하지 않습니다.

동일 시드의 구매 없음/최적 구매/반복 매매 정책을 비교해 최고 OVR·LS·자금·기존 투자 사용률을 확인합니다. 사업 수익으로 사업을 계속 늘리는 루프와 인상된 연봉으로 자금이 폭증하는 조합을 [임금협상](03-salary-negotiation.md)과 함께 검증합니다.

## 인수 조건과 미확정 사항

품목 목록·구매/유지비·수익/손실 규칙·스탯 여부·상한·은퇴 처리·담당 작업 링크가 정해져야 구현 착수가 가능합니다. 별도 담당 작업이 이미 이 내용을 갖고 있으면 그 문서를 정본으로 연결하고 이 문서의 값을 복제하지 않습니다.
