# 결승전 결정 장면 미니게임 기획

> 상태: 기획 제안 · 구현 및 운영 적용 전
> 기준: 2026-10-13 원격 main `1a67ecd7`. T-11-238의 네 기능은 별도 로컬 구현이며 이 문서 PR에 포함되지 않습니다.
> 수치·새 저장 필드·새 함수명은 구현 시 검증할 설계 후보입니다. 이 PR 병합은 기능 출시 승인이 아닙니다.

## 문제와 목표

결승도 구간 계산에 묻혀 선수의 결정적인 플레이가 체감되지 않습니다. 첫 단계는 실제 출전 중인 선수에게 제한된 결승 장면을 제공하고 한 번의 입력이 그 경기의 승자를 결정하도록 하는 것입니다. 모든 결승을 반드시 승리시키는 보상 기능은 아닙니다.

## Phase 0 현재 기반과 제약

- `packages/game/src/minigame.ts`: `MgKind`, `zoneWidth`, `markerAt`, `tapOffset`, `offsetToRoll`, `MG_TIME_MS`. 기존 3초 제한과 판정 구간은 재사용 후보이며 결승에 적합한 시간은 따로 검증합니다.
- `packages/app-core/src/game-actions.ts`의 `chooseEvent`, 웹/앱 `sheets/Minigame`은 이벤트 선택의 타이밍 결과를 `resolveChoice`로 넘깁니다.
- 현재 `compsPhase`의 `tie`는 같은 호출 안에서 승패·기록을 계산합니다. 전체 `playPhase`를 다시 호출해서 결승만 재생하면 훈련·투자·경기를 중복 계산하게 됩니다.
- `CompGame`은 상대/스코어를 보유하지 않습니다. '동점 결승의 마지막 킥'을 내보내려면 이를 뒷받침하는 실제 경기 상태가 먼저 필요합니다.

## 첫 출시 범위

클럽 국내 컵 결승 한 종류부터 적용하고, UEFA 결승·국가대표·구단주 컵은 후속으로 둡니다. 실제 출전 시간이 있는 선수만 참여합니다. 부상 결장·벤치 미출전은 자동 결과를 보여 줍니다. 같은 구간에 여러 결승이 있으면 한 장면씩 직렬로 처리합니다.

장면은 두 후보 중 하나로 좁힙니다. 필드 선수는 동점 상황의 마지막 승부차기 킥, GK는 성공하면 우승이 확정되는 상대 마지막 킥 선방입니다. GK의 선방 한 번을 맥락 없이 팀 우승으로 바꾸지 않습니다. 경기 중 결승골 장면은 분·스코어·득점 기록 지원 이후 확장합니다.

## 사용자 흐름과 접근성

결승 안내 → 내 출전/현재 승부 상황 → 직접 플레이 또는 자동 판정 선택 → 한 번의 입력 → 결과 확정 → 중계/결산 계속 순서입니다. 자동 판정은 같은 공개 능력 기반 확률을 쓰고 보상을 낮추지 않습니다. 동작 줄이기에서 강제로 시간제한 조작을 요구하지 않습니다. 키보드·터치 모두 지원하고 입력 버튼은 하단 안전 영역 안에 둡니다.

## 저장과 원자적 확정

대회/경기 ID, 장면 ID, 판정 확률, 직전 스코어/승부차기 상태, 출전 정보, 미입력/확정 상태, 이후 실행할 구간 작업을 저장하는 새 pending 모델을 제안합니다. 장면을 보여 주기 전에 저장하고 복귀 시 같은 장면을 이어갑니다.

승부와 기록 갱신을 한 공용 확정 함수에서 한 번만 실행합니다. 이미 확정된 장면의 중복 탭·재열기·복원은 기록을 더하지 않습니다. 승부차기 골은 공식 경기 득점으로 더하지 않습니다. 일반 경기 결승골을 나중에 지원하면 경기/대회/시즌 득점을 정확히 한 번 갱신합니다.

## Phase 1 엔진 중단과 재개

- `playPhase`의 기존 훈련→투자→경기→이벤트 순서를 읽고, 결승 직전 중단과 이후 재개를 명시적인 상태 기계로 설계합니다. 현재 함수에 있다고 가정한 pause API를 호출하지 않습니다.
- 비대화형 시뮬레이터도 같은 장면 확정 경로를 자동 판정으로 통과해야 합니다.
- 검증: 중단 전 비용/훈련은 한 번, 확정 후 경기/상/나이 증가는 한 번, 자동 판정과 손입력 판정이 같은 승자/기록 경로 사용, 여러 결승 순서 유지.

## Phase 2 화면과 결과 검증

- 기존 미니게임의 바늘·타이밍 판정/동작 줄이기 패턴을 참고하되 결승 상황은 엔진의 저장 상태를 그대로 표시합니다.
- 성공·실패·시간 초과·자동 선택·닫기/백그라운드·저장 실패·재접속·중복 탭을 검증합니다. 백그라운드 동안 입력 시간을 계속 흘려 강제 실패시키는 방식은 제외하는 방향을 제안합니다.
- 숙련자가 거의 항상 성공할 때의 우승률·트로피·LS 증가를 포지션별로 시뮬레이션합니다. 장면 발생 빈도/성공 구간을 조정한 뒤 주요 대회로 확대합니다.

## 미확정 사항

최초 대상 컵, 장면 발생 빈도, 자동 판정 전환·타이머 재개 정책, 성공 숙련도의 허용 우승률 차이, 골 기록을 다루는 확장 범위를 정해야 합니다. [대진표](01-major-tournament-bracket.md)와 경기 ID/승자 정본을 공유합니다.
