# 감독 커리어 (T-11-310)

2026-10-16 확정. 옛 기획 [PR #657](https://github.com/tasddc1226/offside-football-simulator/pull/657)(T-11-223
`manager-career-plan.md` · `manager-career-events.md`)을 참고만 하고 합치지 않았다. 이 문서가 감독 커리어의 정본이다.

## 한 줄 요약

지금 가진 선수 카드(은퇴한 직접 육성 선수 · 영입한 선수, 옛 기록 포함)로 8~10시즌짜리 감독 커리어를 기기에서 진행하고,
끝낸 감독을 구단주 팀 감독 칸에 앉혀 작은 보정을 받는다. 감독 쪽에는 유료 아이템이 없다.

## 확정한 결정

| 항목 | 결정 |
| --- | --- |
| 대상 | 지금 가진 카드 전부(기존 은퇴 선수 포함). 구글 로그인한 구단주만 |
| 분류 | 시작하면 카드가 감독(`cards.manager = 1`)으로 분류된다. 지금 시즌 선발 · 친선 편성 · 프리셋에서 빠지고(빈자리는 유스), 열린 판매 등록은 내려가고, 판매 · 방출 · 잠금 대상에서 빠진다. 선발에서 빠진 만큼 구단 가치가 줄고, 확인 창이 미리 보여 준다 |
| 컵 | 컵 참가 중 선발에 든 선수는 감독으로 바꿀 수 없다. 컵 명단이 잠긴 동안에는 감독 칸도 바꿀 수 없다 |
| 진행 중 커리어 | 한 번에 하나(선수 커리어와는 동시에 할 수 있다). 포기하면 원래 선수로 돌아오고 선발에는 자동으로 넣지 않는다. 끝내면 감독 카드가 확정되고 다른 선수로 새 감독 커리어를 시작한다 |
| 시작값 | 경험 중심, 명성만 OVR · 레전드 점수 반영. 포지션 → 성향, 프로 시즌 · 출전 → 장악력, 구단 수 → 적응력, 우승 → 이사회 신뢰, 대표팀 → 대표팀 감독 제의 이벤트, 최고 OVR · 레전드 점수 → 명성(첫 구단 수준만). 모르는 옛 기록은 기본값. 시작 나이는 은퇴 나이 + 1~2 |
| 시즌 흐름 | 시즌 준비(포메이션 4-3-3 · 4-4-2 · 3-5-2, 성향 공격 · 균형 · 수비 · 역습, 이사회 목표) → 이적 3지선다(넘기기 가능) → 시즌 이야기 2~3개 → 결산(재계약 · 경질 · 제의). 경질 뒤 공백기 · 재기. 한국 리그만 승강(K3 ↔ K2 ↔ K1) |
| 감독 카드 | 포메이션 숙련 3종(C~S), 성향, 특기 0~2(시너지와 짝), 표시 등급(C~S, S는 리그 우승이 있어야 함), 엔딩 칭호 7종, 거래 불가 |
| 감독 칸 | 팀마다 하나. 지난 시즌 감독 · 여러 팀 중복 가능. 효과는 지금 포메이션 숙련(S +1.0 · A +0.6 · B +0.3)을 공격 · 중원 · 수비 세 줄에, 성향 이득 · 대가, 특기는 짝이 되는 시너지가 켜질 때 +1(유스 육성은 중원 · 수비 +0.5). 줄마다 −1.5~+3.0, 같은 전력 승률 +5%p 안쪽. 칸이 비면 지금과 같다 |
| 진행 연출 | 선수 커리어처럼 시즌 경기를 한 경기씩 중계(승 · 무 · 패 · 승점 집계, 결과 바로 보기), 결산에 우승 · 컵 · 승격 · 강등 · 경질 배지와 이번 시즌 변화 칩 · 숙련 오름, 이벤트 답마다 변화 칩, 끝 화면 숫자 카운트업. 경기 목록은 결산 승무패를 나눈 연출이고 커리어 난수를 쓰지 않는다(`managerMatchday`) |
| 업적 | 감독 업적(`manager` 분류) 공개: 첫 감독 · 감독 수 · 감독 우승 · 감독 승격 · 숙련 S · 감독 등급 S · 감독 칸 |
| 유료 | 없음 |

변형 배치(4-2-3-1 등)는 바탕 포메이션(`owner_teams.formation`)의 숙련을 쓴다.

## 구조

- 규칙 값: `packages/contracts/src/manager-rules.ts`(zod 없음 · 서버 경기와 화면이 같이 쓴다), API 스키마 `manager.ts`.
- 게임: `packages/game/src/manager.ts`(독립 시드 RNG, 세이브 `ft_mgr_save` · 버전 1). 선수 엔진 · 골든 해시와 무관하다.
- 서버: `manager_careers`(마이그레이션 0104, 진행 중은 구단주마다 하나 · 카드마다 한 번 유니크),
  `GET/POST /v1/managers`, `POST /v1/managers/:id/abandon`, `POST /v1/managers/:id/finish`, `PUT /v1/owner-team/coach`.
  서버는 감독 커리어를 시뮬레이션하지 않고 시작값(origin · seed)과 끝낸 결과만 가진다. 경기 시뮬레이션은 두 팀 감독 칸을
  읽어 `managerLines`를 더한다(같은 구단주가 끝낸 감독만).
- 화면: 웹 `ui/Manager.svelte`(지연 청크) · 앱 `screens/owner/Manager.tsx`, 구단주 화면 '감독 커리어' 카드, 팀 화면 감독 칸 줄.
  문구 `app-core i18n manager`, 엔진 문구 `game i18n gManager`(ko · en · ja).
- 밸런스 확인: `tooling/fulltime-sim/manager.ts`(`pnpm --filter @offside/fulltime-sim exec tsx manager.ts [N] [random|greedy|safe]`).

## 2단계로 미룬 것

- 옛 동료 · 제자 보정: 감독이 선수 시절 함께 뛴 선수 · 감독 시절 키운 선수가 선발에 있으면 작은 보정. 선수 시즌 기록을 이어
  붙이는 조회가 필요해 사용 데이터를 본 뒤 정한다.
- 서버 공개 기록(명예의 전당 감독 탭 · 감독 랭킹), 감독 카드 공유 이미지.
- 결과 검증 강화: 지금은 기기가 보낸 결과를 범위만 검사한다(감독 칸 효과 상한이 작아 조작 이득이 작다).
