# 선수 자금 콘텐츠 기획 (2026-11-16, 1차 구현 T-11-733)

선수 자금이 커리어 후반에 쌓이기만 하고 쓸 곳이 없다. 이 문서는 그 자금을 "결과가 불확실한 재미"로 바꾸는 다섯 기획을 정리한다.
수치는 모두 초안이다. 확정 전에 시뮬레이터와 운영 분포로 다시 맞춘다.

## 1. 배경 데이터

운영 `season_telemetry.growth_json.vc.m`(시즌 업로드 때 선수 자금, 단위 만 원) 최근 표본.

| 구간      | 표본  | 25%  | 50%   | 75%   | 90%   | 95%   | 99%     |
| --------- | ----- | ---- | ----- | ----- | ----- | ----- | ------- |
| 30~31세   | 1,206 | 56억 | 121억 | 254억 | -     | 537억 | -       |
| 36세 이상 | 4,140 | 71억 | 173억 | 372억 | 618억 | 788억 | 1,048억 |

- 30세 이상 시즌의 60~~68%가 100억 이상을 갖고 있다. 몸 관리(T-11-513)는 30대 시즌의 18~~23%만 쓴다.
- 지금 자금을 쓰는 곳: 개인 코치 · 자기 투자(구간마다, 연봉의 몇 %) · 잠재력 강화(29세까지) · 잠재력 보기 · 몸 관리(30대) · 꾸미기 가게 · 일부 이벤트.
- 도파민이 확실한 소비처는 잠재력 강화 하나다. 성공 · 실패 · 대성공이 있고, 이 자리의 보상형 광고가 광고 수익 1위다(11-13~15 $55.5).
  29세에 끝나서 30대에는 반복할 소비처가 없다.

## 2. 공통 원칙

- **비용은 연봉 비례 + 최소 금액**(`salaryCost`). 연봉이 큰 선수와 작은 선수의 부담을 비슷하게 하고, 운영 도구 배율(BAL)을 곱한다.
- **판정은 게임 RNG를 행동할 때 한 번만** 쓴다. 쓰지 않은 커리어는 결과가 예전과 같아야 한다(`golden.test.ts`).
- **확률은 화면에 숫자로 보인다.** 잠재력 강화와 같다. "강해도 질 수 있다"가 게임의 재미이므로 확정 결과는 팔지 않는다.
- **구단 자금 · 실제 결제와 섞지 않는다.** 선수 자금 → 구단 자금 전환 없음, 확률 · 시도를 유료로 팔지 않음(강화 원칙과 같다).
- **보상형 광고 자리는 기능마다 하나까지.** 자금이 모자랄 때 한 번 더 같은 보조 역할이고 횟수 상한을 둔다. 광고 제거 · 멤버십은 기존처럼 광고 없이 받는다.
- **수치는 밸런스 스펙에 연다**(`balance-spec.ts` · `balance-text.ts`, 기본값 = 출시 값). 새 키를 열 때 `SEED`로 변경 전후 결과가 같은지 확인한다.
- **연출이 절반이다.** 결과를 바로 보여 주지 않고 0.8~1.5초 동안 긴장을 만든 뒤 터뜨린다(강화 판정 바늘 · 카드 뒤집기 · 상자 열기). 감속 모션 설정이면 바로 보여 준다.
- 웹 · 앱 함께 낸다(보상형 광고만 앱). 문구 4개 언어, 공개 가이드 · FAQ 같이 고친다.

## 3. 기획 ① 전성기 연장 도전

**한 줄:** 30대의 잠재력 강화. 선수 자금으로 "능력치가 떨어지기 시작하는 나이"를 한 시즌씩 늦추는 데 도전한다.

### 규칙

- 대상: 정점 나이(`peakEndAge`) 1년 전 시즌부터 은퇴 전까지. 시즌마다 한 번.
- 효과: 성공하면 연장 단계(`flags.primeExt`)가 +1, 정점 나이가 +1년 늦어진다. 최대 +3단계.
- 대성공: 성공 중 일부는 두 단계를 한 번에 올린다(최고 단계를 넘는 시도엔 없음). 같은 난수 값으로 가른다(강화 T-11-593과 같은 방식).
- 실패: 자금만 잃고, 같은 단계의 다음 확률이 +5%p 오른다. 성공하면 보정은 처음으로 돌아간다.
- 몸 관리와 같이 쓸 수 있다. 몸 관리는 "이번 시즌 하락 폭을 확실히 줄임", 연장은 "하락 시작을 확률로 늦춤"이라 역할이 다르다.

### 수치 초안

| 단계 | 성공 확률 | 비용(연봉 배수) | 최소 금액 |
| ---- | --------- | --------------- | --------- |
| +1   | 40%       | 1.0배           | 1억       |
| +2   | 25%       | 2.0배           | 3억       |
| +3   | 15%       | 3.5배           | 6억       |

- 대성공 비율 15%(BAL `primeExtGreat`), 비용 배율 BAL `primeExtCost`, 기능 켜기 BAL `primeExtOpen`.
- 자금이 모자란 시즌엔 앱에서 광고를 보고 한 번 도전한다(커리어 합계 2번, 확률 규칙은 같다).

### 화면과 연출

- 선수 탭의 몸 관리 카드 옆에 "전성기 연장" 카드: 지금 단계(●●○), 다음 확률 · 대성공 확률, 비용, 정점 나이 "33세 → 34세".
- 누르면 강화 판정 연출(바늘 게이지)을 다시 쓴다. 성공: "전성기 +1년" 금빛 카드, 대성공: 두 칸이 한꺼번에 켜지는 연출. 실패: 다음 확률 +5%p 표시.
- 시즌 결산 시트에 "올해도 전성기를 지켰어요(연장 2년째)" 한 줄.

### 위험과 검증

- 레전드 점수는 출전 · 골 · 도움 · 트로피 합이라, 전성기가 길면 점수가 오른다. 명예의 전당 순위가 흔들릴 수 있다.
  - 시뮬레이터(`INVEST=1`, smart, 시드 5개)로 "매 시즌 시도" vs "안 함"의 레전드 점수 평균 · 상위 1% · 은퇴 나이 차이를 잰다.
  - 목표: 평균 +3% 이하, 상위 1% +5% 이하. 넘으면 효과를 "단계마다 하락 배율 0.5"처럼 약하게 바꾼다.
- 강제 은퇴 나이(시즌별 `retireAt`)는 그대로 둔다.

### 저장 · 측정

- 세이브: `flags.primeExt`, `primeExt = { fails, log[] }`(강화 `BoostState`와 같은 모양). 옛 세이브는 없음 = 0단계.
- 측정: `growth_json`에 `pe: { lv, tries }`, GA4 `reward_ad_*` place `prime`.
- 작업: 게임 모듈 · 웹/앱 카드 · 문구 4개 언어 · 가이드 · 밸런스 키 · 시뮬레이터 옵션. 약 1.5일.

## 4. 기획 ② 전설 코치 영입 (뽑기)

**한 줄:** 선수 자금으로 코치 카드를 뽑는다. 등급이 공개되는 순간이 핵심이고, 코치는 그 시즌 동안 효과를 준다.

### 규칙

- 대상: 프로 선수. 프리시즌부터 전반기 끝까지, 시즌마다 영입 한 번 + 다시 뽑기 한 번(더 비쌈).
- 뽑으면 그 시즌이 끝날 때까지 코치가 붙는다. 새로 뽑으면 바뀐다(이전 코치는 떠남).
- 같은 코치를 다시 만나면 "재회": 효과 1.5배.

### 등급과 코치 풀 (가상 인물, 실존 인물 금지)

| 등급 | 확률 | 효과 예                                                                       |
| ---- | ---- | ----------------------------------------------------------------------------- |
| 일반 | 70%  | 한 능력치 훈련 성장 +10%                                                      |
| 희귀 | 25%  | 한 능력치 성장 +20%, 또는 부상 확률 −30%, 또는 경기 평점 +0.1                 |
| 전설 | 5%   | 희귀 효과 두 개 + 큰 경기(결승 · 더비 · A매치) 보정, 30대면 그 시즌 하락 −20% |

- 첫 판은 15명(일반 8 · 희귀 5 · 전설 2). 포지션 · 타입마다 맞는 코치가 다르게 보이도록 효과를 나눈다.
- 비용: 영입 연봉 × 0.8(최소 5,000만), 다시 뽑기 × 1.5. BAL `coachGachaCost`, 효과 배율 `coachGachaPower`.

### 화면과 연출

- 시즌 탭 훈련 카드 옆 "코치 영입". 카드 세 장이 뒤집히고, 희귀는 파란 빛, 전설은 금빛 번쩍임과 진동(앱 햅틱).
- 코치 도감: 만난 코치를 기기에 기록한다(이벤트 도감과 같은 방식). 전설 코치를 처음 만나면 라운지 공유 카드.
- 광고: "광고 보고 다시 뽑기"(시즌 한 번, 앱).

### 위험과 검증

- 성장 효과가 곧 잠재력 도달 속도라 밸런스 영향이 가장 크다. 시뮬레이터에 "매 시즌 영입" 정책을 넣어 최고 OVR · 레전드 점수 차이를 잰다.
- 전설 5%는 "자주 보이면 재미가 없고, 너무 드물면 포기한다" 사이. 출시 후 2주 동안 등급별 뽑힌 수와 재뽑기 비율을 본다.

### 저장 · 측정

- 세이브: `coach = { id, y, rerolled }`, 도감은 기기 저장(`ft_coach_dex`).
- 작업: 코치 데이터 · 효과 연결(훈련 성장 · 부상 · 평점) · 카드 연출 · 도감 · 문구 4개 언어(코치 15명 이름 · 소개). 약 3일.

## 5. 기획 ③ 드림 클럽 이적 시도

**한 줄:** 에이전트 비용을 내고 빅클럽 오퍼를 노린다. 성공하면 커리어가 바뀌고, 실패하면 돈만 잃는다.

### 규칙

- 이적 시장 화면에서 시즌 한 번 "에이전트에게 빅클럽 타진".
- 비용: 연봉 × 1.5(최소 2억). 결과와 상관없이 낸다.
- 성공 확률: OVR이 목표 리그 평균보다 얼마나 높은지 · 명성 · 나이로 정한다(예: 기본 30%, OVR 차 1당 ±3%p, 31세 이상 −5%p/년, 5~70% 사이). 숫자로 보인다.
- 성공: 지금보다 한 단계 위 리그의 구단 오퍼 1개가 오퍼 목록에 더해진다. 대성공(성공 중 10%): 최상위 리그 상위권 구단 + 연봉 20% 더.
- 오퍼를 받을지는 선수가 고른다. 상위 구단은 주전 경쟁이 세서 벤치에 앉을 수도 있다(정답 없는 선택).
- 실패: 구단 반응 문구(여러 종류) + 그 시즌 사기 −3.
- 병역 · 계약 · 나이 제약은 기존 이적 규칙을 그대로 따른다.

### 화면과 연출

- 누르면 "에이전트가 전화를 거는 중…" 3단계 진행 바(연락 → 협상 → 답변), 마지막에 구단 엠블럼(게임 속 구단 로고)이 뒤집힌다.
- 광고: 실패하면 "광고 보고 한 번 더 타진"(시즌 한 번, 앱).

### 위험과 검증

- 이적 흐름(`marketOptions`)에 오퍼를 끼워 넣어야 해서 구현 위험이 가장 크다. 상위 리그 이동이 쉬워지면 트로피 · 레전드 점수가 오른다.
- 시뮬레이터에 "매 시즌 타진" 정책을 넣어 리그 tier 분포 · 트로피 수 · 레전드 점수를 비교한다.

### 저장 · 측정

- 세이브: `dream = { y, ok }`(시즌 한 번 확인용), 로그 한 줄.
- 작업: 확률 · 오퍼 생성 · 이적 시장 화면(웹 · 앱) · 문구 4개 언어 · 시뮬레이터. 약 2.5일.

## 6. 기획 ④ 명품 경매 컬렉션

**한 줄:** 정체를 모르는 경매품을 사서 열어 본다. 게임 결과에는 영향이 없고, 모으고 자랑하는 재미다.

### 규칙

- 선수 탭(또는 꾸미기 화면 옆) "경매장". 시즌마다 경매품 3개가 바뀐다(게임 속 시간이라 하루 접속을 강요하지 않는다).
- 경매품은 종류만 보인다: 시계 · 자동차 · 미술품 · 트로피 레플리카 · 와인 · 기념 유니폼.
- 사서 열면 등급이 공개된다.

| 등급 | 확률 | 값(연봉 배수, 최소)                        |
| ---- | ---- | ------------------------------------------ |
| 일반 | 60%  | 종류마다 같은 값: 연봉 × 0.5, 최소 3,000만 |
| 고급 | 30%  |                                            |
| 명품 | 9%   |                                            |
| 전설 | 1%   |                                            |

- 겹치면 되팔기(산 값의 50%). 같은 종류 4등급을 모으면 세트 칭호(예: "시계 수집가"), 6종류 전설을 다 모으면 최고 칭호.
- 진열장: 선수 탭에 이 선수의 소장품. 은퇴하면 대표 소장품 3개가 명예의 전당 카드에 남는다.
- 광고: "광고 보고 경매품 새로 고침"(시즌 한 번, 앱).

### 화면과 연출

- 상자 흔들림 → 빛 색(등급색) → 열림. 전설은 화면 전체 금빛과 진동, 라운지 공유 카드.
- 그림: 종류 6 × 등급 4 = 24개 아이콘(도트 또는 평면 일러스트). 3D는 쓰지 않는다.

### 위험과 검증

- 밸런스 영향 없음. 돈이 빠지는 속도만 본다(30대 자금 중앙값이 줄어드는지).
- 확률형 아이템이라 확률표를 화면 · 가이드에 공개한다. 실제 결제로는 팔지 않으니 확률형 유료 아이템 표시 의무 대상은 아니지만 같은 수준으로 보인다.

### 저장 · 측정

- 세이브: `auction = { y, lots[], bought[] }`, `collection[]`. 명예의 전당 항목에 `items?: string[]`(contracts · API 저장 · 표시).
- 작업: 데이터 · 화면 · 연출 · 아이콘 24개 · 명예의 전당 필드(서버) · 칭호 · 문구 4개 언어. 약 3일 + 그림.

## 7. 기획 ⑤ 은퇴 유산

**한 줄:** 은퇴할 때 남은 자금을 업적 한 줄로 바꾼다.

### 규칙

- 은퇴 리포트에 "남은 자금으로 유산 남기기" 카드(선택 사항, 고르지 않으면 아무 일도 없음).
- 종류 셋: 유소년 아카데미 설립 · 자선 재단 · 첫 프로 구단 후원.
- 등급은 운영 분포(36세 이상) 백분위에 맞춘다.

| 등급   | 남은 자금  | 대략 백분위 | 보상                                 |
| ------ | ---------- | ----------- | ------------------------------------ |
| 동     | 70억 이상  | 상위 75%    | 은퇴 리포트 · 명예의 전당 한 줄      |
| 은     | 170억 이상 | 상위 50%    | + 꾸미기 기록 아이템                 |
| 금     | 370억 이상 | 상위 25%    | + 칭호(종류마다 하나)                |
| 레전드 | 800억 이상 | 상위 5%     | + 최고 칭호, 명예의 전당 카드 테두리 |

- 명예의 전당에는 등급과 종류만 보이고 금액은 보이지 않는다(추천).
- 레전드 점수 · 구단 자금에는 영향이 없다.

### 저장 · 측정

## 10. 1차 구현 (T-11-733, ① + ⑤)

- **① 전성기 연장**: `packages/game/src/prime.ts`, 화면 `app-core/prime-view.ts` · 웹 · 앱 선수 탭 카드, 연출은 잠재력 강화(BoostFx)를 같이 쓴다.
  수치는 초안 그대로(40 · 25 · 15%, 연봉 1 · 2 · 3.5배, 최소 1억 · 3억 · 6억, 실패 +5%p, 대성공 15%). 밸런스 키 `primeCost` · `primeGreat` · `primeAdTotal`.
  광고 자리(place `prime`, 사용 요약 `e`)는 따로 만든 AdMob 단위가 생기기 전까지 잠재력 강화 단위를 같이 쓴다.
- **시뮬레이션**(smart, 시드 2개 × 3,000): 매 시즌 도전하면 레전드 점수 평균 +0.9%(35세 은퇴) · +2.3%(38세 은퇴), 상위 1% +1.6% · +2.2%,

- **⑤ 은퇴 유산**: `packages/game/src/legacy.ts`. 은퇴 리포트에서 고르는 대신 **30세부터 선수 탭에서 미리 골라 두는** 방식으로 바꿨다.

  종류 · 등급을 은퇴 스냅샷(`LegendSnapshot.legacy`)에 남긴다(DB 변경 없음). 명예의 전당 · 은퇴 리포트에 '은퇴 유산' 장면이 나온다.
