# Game Center · Google Play Games (T-11-734)

1.1.9에서 iOS Game Center와 Android Google Play Games를 검증한다. 내부 테스트와 스토어 출시는 별개다.
네이티브 모듈·entitlement를 더하므로 기존 앱에 OTA만 보내서 사용할 수 없다.
현재 스토어 런타임 지문·최소/최신 버전 안내는 실제 출시 전까지 바꾸지 않는다.

## Android 구성

Google Play Games 프로젝트 ID는 `641136073759`다. Play Console이 발급한 실제 업적·순위표 ID는
`apps/mobile/src/platform/playGamesIds.ts`에 둔다. Apple의 문자열 ID를 Google로 보내지 않는다.
로컬 Expo 모듈 `OffsidePlayGames`와 `withPlayGames` 플러그인이 SDK 초기화와 매니페스트 설정을 맡는다.
플러그인만 수정하며 CNG로 생성한 `android/` 파일은 커밋하지 않는다.

- 플랫폼 인증은 OFFSIDE 로그인·계정 병합과 별개다. 기기의 Play Games 플레이어 ID를 서버 로그인 수단으로 쓰지 않는다.
- SDK의 기존 프로필 자동 인증은 지원하되, 새 프로필 생성 안내는 설정의 명시적 연결 동작에서만 연다.
- OFFSIDE 기록 전송 동의는 플랫폼마다 다른 기기 저장 키에 보관한다. iOS 동의를 Android에서 재사용하지 않는다.
- Google의 주간 경계는 일요일 07:00 UTC(한국 시각 일요일 16:00)다. Apple의 월요일 00:00 KST 경계와 구별한다.
- Google은 모든 순위표에 일간·주간·전체 보기 탭을 제공한다. 별도 주간 레전드 순위표만 해당 주에 은퇴한 선수의 점수를 전송한다.
  다른 최고 기록 순위표의 주간 탭은 Google이 최근 제출한 점수를 분류하는 방식이다.
- Android의 이번 주 순위 버튼은 주간 레전드 순위표의 주간 탭으로 바로 연다. 이전 주의 응답은 새 주에 제출하지 않는다.
- 연결을 끊어도 이미 보낸 플랫폼 최고점·업적은 유지된다. 오프라인 실패와 플랫폼 오류는 게임 진행·저장을 막지 않는다.
- Android 내부 테스트는 Play에서 서명한 앱으로 확인한다. 로컬 APK의 서명은 운영 OAuth 인증서와 다를 수 있다.

## 기록과 계정

- `GET /v1/owner/game-center`는 세션 소유 구단주의 남아 있는 은퇴 기록을 과거 시즌까지 집계한다.
  익명 앱 세션도 지원한다. 숨김·진행 중·다른 구단주 기록을 제외한다. 순위 점수에는 기존 명예의 전당
  자격(30세 이상)을 적용한다. 짧은 커리어도 목표 달성에는 반영한다.
- 기존 `first/europe`와 같은 리그 목록, `NATIONAL_WINS`, 은퇴 요약의 발롱도르 수를 사용한다.
  구단주 인덱스와 시즌 PK를 이용하는 조회 한 번이며 R2 상세나 N+1 조회는 없다.
- 설정에서 연결을 누른 뒤에만 GameKit 인증과 기록 전송을 한다. Sign in with Apple과 별개다.
  연결 동의는 이 기기의 OFFSIDE 프로필 ID와 Game Center `gamePlayerID` 쌍에 저장한다.
  서버 로그인 수단이나 계정 병합 기능을 추가하지 않는다.
- 세션이 바뀌거나 연결을 끊으면 진행 중 응답을 무시하고 다시 연결하도록 한다. Game Center 플레이어가
  바뀌어도 자동으로 다른 계정에 보내지 않는다. 이미 Apple에 보낸 최고점·완료 업적은 연결 해제로 지워지지 않는다.
- 명시적으로 열 때 60초 메모를 쓰고, 은퇴 업로드 성공 알림에서만 무효화한다. 주기 조회는 없다.
  전송 도중 새 업로드가 완료되면 한 번 더 동기화한다. 백그라운드에서는 로그인 UI를 띄우지 않는다.
- Game Center 오류는 기록 전송·설정 상태에만 남는다. 게임 저장·은퇴 업로드·광고 흐름을 막지 않는다.
  해당 플랫폼의 새 네이티브 모듈이 없는 옛 런타임에서는 설정 카드와 연동을 사용하지 않는다.

## TestFlight 확인

1. 기존 앱을 삭제하지 않고 1.1.9로 업데이트한다. 진행 중 커리어·은퇴 기록이 유지되는지 확인한다.
2. 설정 → Game Center 연결. 취소해도 게임을 계속할 수 있고, 다시 연결할 수 있어야 한다.
3. 순위표·목표 달성을 각각 열어 순위표 4개와 목표 18개가 표시되는지 확인한다. 기존 획득 기록과
   새 상위 목표 6개의 조건도 확인한다.
4. 저장된 은퇴 기록의 최고점·발롱도르·유럽 진출·국제대회 우승이 조건대로 반영되는지 확인한다.
   짧은 커리어는 첫 은퇴 목표만 반영될 수 있으며 순위 점수를 만들지 않는다.
5. 새 은퇴 기록을 서버에 올린 후 점수가 갱신되는지 확인한다. 오프라인 실패 후 다시 연결하면 재시도할 수 있어야 한다.
6. Game Center 계정 변경과 OFFSIDE 로그아웃/계정 변경 후 다른 계정으로 자동 전송되지 않는지 확인한다.
7. 작은 화면·큰 글자·다크 모드에서 버튼과 오류 안내가 잘리지 않는지 확인한다. Game Center 자체 표시 언어는
   Apple 계정/기기 설정을 따른다. OFFSIDE 설정 문구는 ko/en/ja/zh를 제공한다.

실기기 확인 결과를 받기 전에는 GameKit 동작 검증이나 스토어 출시를 완료로 기록하지 않는다.

## 연결 안내와 상시 진입

- 홈은 기기에 은퇴 기록이 있는 미연결 유저에게 안내한다. 받을 선물·출석 등 기존 홈 블록의 우선순위는 유지한다.
- 이 기기의 첫 은퇴 리포트 끝에도 기록과 연결된 안내를 둔다. 홈·은퇴 안내는 각각 기기에서 한 번씩이며, 서로 7일 간격을 둔다.
- 안내를 닫거나 연결을 수락하면 두 안내를 모두 마친 것으로 기억한다. 연결을 끊거나 계정을 바꿔도 다시 권하지 않는다.
- 기록실의 명예의 전당에는 순위표·목표 달성 진입 버튼을 계속 둔다. 미연결 상태에서는 기록 전송 안내를 읽고 명시적으로 연결한 뒤 선택한 화면을 연다.
- 노출 판단은 기기 기록과 로컬 키 `ft_game_services_offer_v1`만 사용한다. 안내 노출로 서버 조회·플랫폼 인증·분석 이벤트를 만들지 않는다.
- 네이티브 모듈이 없는 기존 런타임에는 안내와 버튼을 모두 숨긴다. 로그인 취소·연결 오류는 카드에서 안내하며 게임 진행·저장은 막지 않는다.

추가 확인: 홈에서 안내 닫기 → 앱 재시작 후 재노출 없음, 첫 은퇴 직후 홈에서 중복 안내 없음,
명예의 전당에서 미연결 상태로 순위표·목표 달성 진입, 로그인 취소·재연결, 작은 화면·큰 글자·다크 모드.
