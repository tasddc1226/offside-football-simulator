# 출석 체크 · 연속 출석 · 일일 미션 기획 (T-11-360)

작성일: 2026-10-17 · 상태: 1단계 구현(출석 · 매일 보상 도장판 · 연속 출석 · 출석 창, 2026-10-17) / 2·3단계 기획 · 소스 기준: origin/main `231a0f0c`

## 1. 목적과 원칙

**목적:** 구단주가 매일 한 번 게임에 들어와 실제로 한 가지 이상 플레이하게 만든다. 출석 버튼만 누르고 나가는
방문이 아니라 **출석 → 오늘의 미션 → 실제 플레이**로 이어지는 하루 루틴을 만든다.

원칙:

- **놓쳐도 잃지 않는다.** 2026-09-28 구단주 도전 과제 결정(`decision-log.md`)은 "일일 숙제·연속 접속·미접속 손실 없이"였다.
  이번 기능은 사용자 지시로 매일 들어올 이유를 일부러 만들지만, 그 정신은 지킨다. 핵심 보상은 **누적 출석 도장판**(빠진 날이
  있어도 도장은 그대로)에 두고, 연속 출석은 덤 보상과 표시에만 쓴다. 이 결정은 결정 로그에 같이 남긴다.
- **미션은 원래 하던 플레이다.** 시즌 진행·팀 경기·승부예측처럼 이미 있는 행동만 미션으로 쓴다. 미션을 위한 새 화면을 만들지 않는다.
- **서버가 확인할 수 있는 것만 보상한다.** 기기에서만 아는 행동(구간 진행, 화면 열람)은 보상 조건으로 쓰지 않는다.
- **보상은 소모 아이템.** 능력치·레전드 점수·랭킹·구단 자금은 주지 않는다(시즌 보상 정책 §1과 같다).
- **서버 쓰기는 사람당 하루 몇 번.** 미션 진행을 행동마다 카운터로 적지 않고, 보상을 받을 때 기존 테이블을 조회해 판정한다.

## 2. 대상

- **로그인한 구단주만 보상을 받는다.** 아이템(`owner_items`)이 구단주 전용(`requireOwner`)이라 홈 선물·친구 초대와 같은 조건이다.
- **확정(2026-10-17):** 출석 보상은 무조건 로그인한 구단주만 받는다. 익명 기간 출석을 소급해 주지 않는다.
- **로그인 유도(2026-10-17 수정):** 로그인하지 않은 기기에도 홈 입구와 출석 창을 보인다. 창에는 같은 도장판, 28일 동안 받는
  보상 합계, 로그인 버튼을 두고, 로그인하면 홈으로 돌아와 바로 출석할 수 있다. 처음 온 방문자(세션 없음)에게는 창을 저절로
  띄우지 않고 서버도 부르지 않는다. 플레이해 본 비로그인 기기는 한 번 확인(403)한 뒤 구단주 표시 메모로 다시 묻지 않는다.
- 웹·앱 함께 낸다(웹·앱 병행 규칙). 푸시 알림만 앱 전용이다.

## 3. 하루 흐름

1. 홈에 들어오면 하루(KST) 한 번 **출석 창**(아래에서 올라오는 창)이 저절로 뜬다. 닫은 뒤에는 컵 배너 · 홈 선물 아래의 한 줄 입구로 다시 연다.
2. **출석하기**를 누르면 도장 하나가 찍히고 연속 출석 일수가 오른다. 하루의 기준은 KST 00:00이다.
3. 카드 아래에 **오늘의 미션 3개**가 있다. 각 미션 옆 버튼은 해당 화면으로 바로 간다(시즌 진행 → 이번 커리어, 팀 경기 → 내 팀).
4. 미션을 마치고 홈에 돌아오면 그 미션의 **받기** 버튼이 켜진다. 누르면 보상이 들어간다.
5. 3개를 다 받으면 "오늘 할 일을 다 했어요" 상태가 되고, 남은 시간 동안 카드가 접힌다.

출석과 미션 보상은 자동으로 들어가지 않고 직접 받는다. 받는 순간이 작은 보상 경험이고, 서버 쓰기를 그때만 하기 위해서다.
그날 받지 않은 미션 보상은 자정에 사라진다(누적 도장은 출석 버튼 기준이라 영향 없다).

### 4.2 연속 출석 (덤)

- 카드에 "🔥 N일 연속"을 보인다. 최고 기록도 남긴다.
- **한 주(월~일)에 하루까지는 빠져도 이어진다.** 쉬는 날을 자동으로 메워 준다. 이틀 이상 빠지면 1부터 다시 센다.

## 5. 일일 미션

### 5.1 구성

매일 3칸. 칸마다 성격을 고정해 매일 비슷한 루틴이 되게 한다.

| 칸          | 성격             | 후보(서버 판정 근거)                                                                                                                          |
| ----------- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| ① 플레이    | 매일 같음        | **커리어 1시즌 진행하기**: 오늘 처음 올라온 시즌이 1개 이상(`careers` ⋈ `career_seasons.created_at`)                                          |
| ② 구단      | 팀이 있으면      | **팀 경기 1번 하기**: `team_matches` 또는 `friend_matches`에 오늘 내가 건 경기                                                                |
|             | 팀이 없으면 대신 | **커리어 2시즌 진행하기**(① 조건 강화)                                                                                                        |
| ③ 오늘의 것 | 날마다 돌아감    | 컵 경기가 있는 날: **승부예측 1경기**(`cup_predictions.created_at`) / 그 밖의 날: 아래 중 하나                                                |
|             |                  | **선수 1명 은퇴시키기**(`careers.retired_at`), **리롤권·스카우트권 1장 쓰기**(`owner_item_purchases` 등 사용 원장), **커리어 3시즌 진행하기** |

- ③의 후보는 날짜 해시로 정해서 **그날은 모두 같은 미션**을 받는다. 라운지에서 "오늘 미션 뭐였지" 같은 대화가 나오게 한다.
- 조건이 불가능한 미션(팀 없음, 진행 중 커리어 없음)은 내보내지 않고 다음 후보로 바꾼다.
- 채팅·댓글 쓰기는 미션으로 쓰지 않는다. 보상 때문에 의미 없는 글이 늘어난다.
- 화면 열람(명예의 전당 보기 등)은 서버가 모르므로 쓰지 않는다.

### 5.3 경제 영향(초안 기준, 28일 매일 완주 시 최대)

| 아이템        | 출석·미션 | 비교: 지금 있는 무료 경로                                  |
| ------------- | --------: | ---------------------------------------------------------- |
| 리롤권        |    약 124 | 앱 광고 리롤 하루 2회(월 60), 승부예측 적중마다 1, 컵 1~10 |
| 잠재력 강화권 |         8 | 홈 선물 20(1회), 영구결번 등                               |

- 리롤권은 이미 무료 경로가 넓어 하루 최대 4장은 감당할 수 있다고 본다. 반면 **잠재력 강화권은 명예의 전당 경쟁에 바로
  영향을 주므로** 매일 주지 않고 도장판에만 둔다.

  수량은 코드 상수 대신 **운영에서 바꿀 수 있는 값**으로 둔다(§7.4).

## 6. 화면

**1단계(2026-10-17 수정):** 홈 카드가 자리를 많이 차지해 홈에는 한 줄 입구(제목 · 연속 · 오늘 보상 또는 "오늘 도장 완료")만 두고,
도장판과 출석 버튼은 하루 한 번 저절로 뜨는 출석 창에 둔다. 띄운 날은 기기에 적고(`ft_att_popup`), 오늘 출석한 구단주와
다른 창(컵 우승 팝업 등)이 떠 있을 때는 띄우지 않는다. 아래 그림은 2단계 미션을 더할 때의 초안이다.

```
┌ 오늘의 출석 ─────────────────── 🔥 5일 연속 ┐
│ [ 출석하기 ]        도장 12/28 · 다음 보상 14칸 │
│                                               │
│ 오늘의 미션                                    │
│ ✓ 커리어 1시즌 진행하기        리롤권 1  [받기] │
│ ○ 팀 경기 1번 하기             리롤권 1  [가기] │
│ ○ 승부예측 1경기               리롤권 1  [가기] │
│ 3개 모두 하면 리롤권 1 더                       │
└───────────────────────────────────────────────┘
```

- 도장판 전체는 카드를 누르면 아래에서 올라오는 창으로 연다(감독 플레이와 같은 방식).
- 이미 다 했으면 한 줄로 접는다: "오늘 할 일을 다 했어요 · 내일 또 만나요" 같은 꼬리는 문구 규칙(`copy-style.md`)에 맞춰 다듬는다.
- 받기 순간에는 작은 도장 찍힘 애니메이션. 움직임 줄이기 설정을 지킨다.
- 문구는 ko·en·ja 세 벌(`packages/app-core/src/i18n/*/attendance.ts`).

## 7. 구현 설계

### 7.1 데이터

```
owner_attendance_days   (profile_id, day 'YYYY-MM-DD', checked_at, missions TEXT, claimed INTEGER bitmask)
                        PK (profile_id, day)
owner_attendance        (profile_id PK, stamps, board, streak, best_streak, last_day, grace_week, updated_at)
```

- 하루 한 줄 + 사람당 요약 한 줄. 그날 미션 3개(`missions`)는 출석할 때 정해서 적는다. 이후 미션 구성을 바꿔도 그날 받은 미션은 그대로다.
- 지급은 홈 선물과 같은 방식: 같은 batch에서 `INSERT OR IGNORE`(출석)나 `UPDATE … WHERE claimed & bit = 0`(미션)이
  실제로 줄을 바꿨을 때만 `grantItemStatement`가 돈다. 재전송·연타에도 한 번만 준다.

### 7.2 API

| 경로                                       | 내용                                                                                                 |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `GET /v1/attendance`                       | 오늘 출석 여부, 도장·연속, 오늘 미션과 각 미션 완료 여부. 구단주 아니면 `{ owner: false, missions }` |
| `POST /v1/attendance/check-in`             | 출석 + 도장 보상. idempotency 미들웨어                                                               |
| `POST /v1/attendance/missions/:slot/claim` | 서버가 조건을 다시 판정한 뒤 지급                                                                    |

- 미션 완료 판정은 GET·claim 때만, 오늘 KST 0시 이후 범위로 기존 인덱스를 탄다
  (`team_matches_profile_created_idx`, `friend_matches_profile_created_idx`, `careers_profile_id_idx` + `career_seasons` PK).
  `cup_predictions`는 `(profile_id, created_at)` 인덱스가 없어 마이그레이션을 같이 낸다.
- 웹·앱은 `cachedGet('/v1/attendance', 5분)`. 시즌 업로드는 outbox가 `clearApiCache()`를 부르므로 플레이 뒤 홈에 오면 새 값을 읽는다.
- 홈에 들어올 때마다 다시 부르지 않는다. e2e에서 홈 왕복 시 요청 횟수를 확인한다(백엔드 보호 규칙).
- 시간은 서버 시각만 쓴다(기기 시계를 바꿔도 소용없다). KST 하루는 `packages/contracts/src/kst.ts`의 `kstDay`.

### 7.3 푸시 (앱, 2단계)

- 오늘 출석하지 않았고 연속 3일 이상인 구단주에게 20시 KST 한 번: "오늘 도장을 아직 안 찍었어요".
- 알림 설정에 새 항목 `daily`를 더하고 기본은 켜짐. 기존 `careerReminder`와 같은 날 겹치면 하나만 보낸다.

### 7.4 수치 관리

보상 수량·도장 칸·미션 후보는 `packages/contracts/src/attendance.ts`에 두고, 운영 도구 밸런스 화면에서 버전으로 바꿀 수 있게 한다.
바뀐 값은 **다음 날 0시부터** 적용한다(이미 적힌 오늘 미션은 그대로).

| 지표               | 정의                                                                      | 목표 방향     |
| ------------------ | ------------------------------------------------------------------------- | ------------- |
| 주간 재방문        | 168시간 안 서로 다른 KST 날짜 2일 이상 플레이(`core-metrics` 정의 그대로) | ↑             |

| 미션 완주율        | 출석한 날 3개 모두 받은 비율                                              | 참고          |
| 가드레일           | IAP 매출, 리롤권·강화권 총 보유량 증가 속도, D1 쓰기 수                   | 크게 안 늘 것 |

- 1단계는 GA4 이벤트 대신 서버의 `owner_attendance_days`(구단주 · 출석한 KST 날짜)로 출석률 · 출석 뒤 시즌 업로드 전환을 잰다.
  GA4 이벤트(`attendance_check_in`, `attendance_mission_claim`)는 2단계 미션과 함께 더한다.
- **출석 → 플레이 전환이 낮으면** 출석만 하고 나가는 패턴이라 실패로 본다. 그때는 출석 보상을 줄이고 미션 보상을 늘린다.

## 9. 악용·예외

- 다중 계정: 구글·애플 로그인 필요, 하루 보상이 작아 계정을 늘릴 가치가 낮다.
- 1시즌 진행 미션을 위해 빠르게 새 선수를 만들고 1시즌만 하는 것은 정상 플레이로 본다. 자동 플레이 탐지(`signals_json`)는 관찰만 한다.
- 시즌 재업로드: `career_seasons.created_at`은 처음 올린 시각이라 같은 시즌을 다시 올려도 오늘 시즌으로 세지 않는다.
- 계정 삭제·복구: 출석 기록은 프로필에 붙고, 삭제하면 같이 사라진다.
- 시즌 마감·점검 중에도 출석은 된다.
