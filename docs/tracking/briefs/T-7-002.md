# T-7-002: 룰셋 1.4.0 회복 규칙 도메인 구현 — 역할 수락의 계약 반영·하향 거절 무벌점·미이행 무벌점 (이슈 #140, D-67)

## 목표

[T-7-001](T-7-001.md)이 만든 룰셋 1.4.0의 새 키를 `packages/domain`이 읽어, 원소속에 머무는 선수가 무출전에서 벗어날 수 있게 한다.
운영 QA(`docs/qa/2026-09-07-production-six-cases/README.md` 결함 1·7)에서 확인한 구조: 감독 역할 제안을 **수락**해도 `context.squadStatus`만 한 번 오르고
다음 경기부터 `playMatch`가 바뀌지 않은 `contract.rolePromise`로 되돌린다(`simulate.ts` ACCEPT 분기 → `match.ts` `nextSquadStatus`). **거절**은 -8.
시즌 결산의 약속 미이행은 선수의 감독 신뢰를 -8 깎아 다음 시즌 선발 점수를 더 낮춘다. 1.3.0 이하 룰셋의 재생 결과(골든·해시)는 그대로여야 한다.

선행: T-7-001이 main에 머지된 뒤 `origin/main`에서 시작한다(스키마 키가 있어야 typecheck가 통과한다).

## 범위

- 만질 패키지·경로: `packages/domain`만(`src/ruleset.ts` 타입, `src/simulate.ts`, 필요 시 `src/types.ts` 주석). 기존 테스트 파일에 케이스 추가.
- 만들 것:
  1. **역할 수락이 계약에 남는다.** `resolveRole`의 ACCEPT · `ROLE_CHANGE` 분기에서 `ruleset.selectionRules.roleProposal.acceptedRoleUpdatesPromise === true`이면 `contract`를 `{ ...contract, rolePromise: proposal.to, appearancePromise: { minutesShareBp: ruleset.contractRules.promiseMinutesShareBp[proposal.to] } }`로 갱신한다(`Contract`에 `appearancePromise`가 없으면 `rolePromise`만). 상향·하향 모두 적용한다(합의된 역할이 계약이다). 급여·기간·서명 revision은 바꾸지 않는다. 기존 `ROLE_RESOLVED` 타임라인 항목 외 새 항목 종류를 만들지 않는다. 이후 경기의 squadStatus는 이미 `state.contract.rolePromise`를 읽으므로(`simulate.ts` 경기 wiring) 자연히 유지된다 — 테스트로 2경기 이상 유지를 고정한다. 결산 `computePromiseFulfilment`의 `promised`도 갱신된 값을 쓴다.
  2. **하향 제안 거절은 무벌점.** DECLINE 분기에서 `proposal.type === 'ROLE_CHANGE'`이고 `proposal.to`가 `contract.rolePromise`보다 낮은 역할(`SQUAD_ROLE_GOODNESS` 비교)이며 `roleProposal.declineDowngradeTrustDelta`가 정의돼 있으면 그 값을, 아니면 기존 `declineTrustDelta`를 쓴다. POSITION_CHANGE·상향 제안 거절은 기존 그대로.
  3. **미이행 벌점 0에서도 기록은 남는다.** `managerTrustPromiseBreach`가 `0`일 때 `applyEffects`가 delta 0 효과를 건너뛰어 관계 로그(`reasonTag: 'PROMISE_BREACH'`)·`약속_위반` 태그·`contract.promiseBreaches` 증가가 사라지지 않는지 확인하고, 사라지면 로그·태그·카운터는 delta와 무관하게 남기도록 고친다(1.3.0 결과는 불변).
  4. **1시즌 회복.** `hasConsecutiveZeroMinuteSeasons`는 이미 정책값을 읽는다. 코드 변경 없이 1.4.0에서 0분 시즌 1회 뒤 결산 시장에 회복 제안이 1건 들어가고 `market.reason === 'INTEREST'`가 되는지 테스트로 고정한다.
- 만지지 말 것: `packages/content`(룰셋·스키마는 T-7-001), `apps/*`, `packages/contracts`(새 유니언 값을 만들지 않으므로 필요 없어야 한다), 골든 fixture 파일, docs.
