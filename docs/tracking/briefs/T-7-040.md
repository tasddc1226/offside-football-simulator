# T-7-040: 중요한 결정에서 멈추는 서버 연간 커리어

## 범위와 승인

2026-09-22 사용자가 자연스러운 능력치·상황 기반 사건 흐름, 고정 재계약 일정 제거, 한 버튼으로 한 시즌/1년 진행, 실제 출전 시간에 따른 눈에 보이는 성장을 요청했다. 추가 답변은 **중요한 결정이 생길 때만 잠시 멈춤**이다. 모든 결정을 자동 수락하는 설계는 승인되지 않았다. Luna 배정 무응답 뒤 다른 하위 에이전트 구현을 사용자 `진행`으로 승인했다. AGENTS 자체는 변경하지 않는다.

- 기준 main `fc281bd5`, 브랜치 `T-7-040-annual-career`.
- 신규 후보 `3.5.0 / 0.14.0`. 역사 팩·규칙·저장 해시 불변. 최종 통합 전 활성 포인터 변경 없음.
- main 병합·운영 배포는 이번 구현 승인에 포함하지 않는다.
- 참고: CLAUDE.md, ADR-002/003/005, FR-GROW-1/4, DATA-GROW-1, RULE-TIME-004, DATA-SEA-001, CMD-SIM-003, CMD-CON-001~003.

## 네 단계

1. **도메인/콘텐츠** (구현·작성자 검증·독립 검토 완료): 순수 고정 목표 연도 진행기, 모든 pending 분기, 자연 명령 재생; 출전 기회/역할 갈등/진로 관심의 저장된 후속 사건; 계약 만기 맥락 창; 실출전 성장과 전체 연도 변화 보고.
2. **권위 서버** (구현·작성자 검증·독립 검토 완료): 신규 버전 SERVER_ANNUAL 소유권, 시작/청크/선택/복구; 동일 작업 재시도·병렬 CAS·실행 로그와 snapshot 원자 저장. 과거 CLIENT_LOCAL 경로 보존.
3. **연간 UI** (미착수): 1년 보내기→중요 결정→같은 해 계속→연간 보고. 360px, 키보드, 모션 감소, 로딩·오류·재접속·중복 클릭.
4. **통합 검증** (미착수): 전체 체인, 실제 서버/브라우저, 역사 바이트 감사, 독립 리뷰. 배포와 로컬 검증 구분.

## 핵심 계약

- AnnualCheckpoint는 시작 revision/age/능력치/OVR/완료 시즌 수와 targetSeasonIndex를 고정한다. 부분 시즌 시작은 남은 시즌만 마치고 두 번째 해로 넘어가지 않는다.
- nextAnnualAction은 COMMAND/WAITING_DECISION/COMPLETED/ERROR 중 하나를 반환한다. 서버가 명령을 실행하고 예산 내 청크를 저장한다. HTTP 선택은 허용 choice ID만 받고 payload/outcome은 콘텐츠에서 재생성한다.
- 첫계약·이적·재계약·임대·은퇴·실질 역할 변경·중요 사건은 자동 수락하지 않는다. 빈 제안/KEEP 역할/일상 훈련·경기 장면은 정책으로 처리한다.
- 연간 보고는 시작과 종료 전체 속성 차이, 결산 성장과 기간 중 변화 차이를 함께 보여 준다. 결산 성장의 MINUTES/TRAINING/EXPERIENCE/AGE_DECLINE/POTENTIAL_CAP은 기존 사실 원장을 사용한다.
- 신규 버전 DEVELOP는 체력·숙련·관계에 영향을 주며 영구 능력치 상승은 결산에 한 번만 계산한다. 실제 출전 기여 0분은 0이고 소량 훈련, 연령·잠재력·연간 상한은 유지한다.
- 계약은 원래 1~3년이다. 매년 고정 재계약 버튼을 제거하며 실제 만기 계약에만 감독 신뢰에 따른 논의 시점을 둔다. 필수 만료 후 시장은 보존한다.
- 사건은 실제 감독 actor/구단/출전 기록과 최초 선택을 저장한다. 타 감독에게 기억을 넘기지 않는다. 동료 부상·확정 이적·확정 출전을 창작하지 않는다. 동일 창 재굴림 방지, 연간 새 줄거리 1개와 후속, 가족별 2시즌 쿨다운.
