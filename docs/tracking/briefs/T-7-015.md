# T-7-015: 상단 공통 네비바 "N명 플레이 중" 실시간 배지 + 하트비트 (apps/web + ui CSS)

## 목표

모든 화면의 상단 공통 네비바(`apps/web/src/routes/__root.tsx` `GameNavigation`)에 지금 플레이 중인 인원("12명 플레이 중")을 60초 주기로 갱신해 보여준다. 탭이 보이는 동안 60초마다 `POST /v1/presence/heartbeat`를 보내 이 기기의 세션도 집계에 포함되게 한다(D-78). 서버 API는 [T-7-014](T-7-014.md)(PR 머지됨)가 제공한다.

## 참조 명세

- 요구사항 ID: API-PRES-001·002(`docs/development/07-api-contract.md`), SCR-000 공통 셸(`docs/screens/`), NFR-A11Y, D-12(색은 `--os-*` 토큰만), D-78.
- 읽어야 할 코드: `apps/web/src/routes/__root.tsx` 75~171행(`GameNavigation`, `.os-app-nav` 좌 브랜드·우 컨트롤 2슬롯), `packages/ui/src/game.css` 92~101행·783~806행(`.os-app-nav`, `.os-nav-context`), `apps/web/src/shared/SyncBadge.tsx`(상태→문구 배지 선례), `apps/web/src/engine/service-season.ts` 27~37행(`queryOptions` + 훅 패턴), `apps/web/src/shared/query-client.ts`, `apps/web/src/api/client.ts`(`apiFetch` 래퍼, 185행 근처 예시), `packages/contracts/src/presence.ts`(`LivePresenceSchema`), `packages/platform/src/web/analytics.ts` 111~115행(`visibilitychange` 처리 선례), `apps/web/src/legal/privacy.tsx` 16~21행, `apps/web/src/routes/__root.test.ts`, `apps/web/src/app-routes.test.tsx`, `apps/web/e2e/mobile-refresh.spec.ts`(가로 넘침 검사).

## 범위

- 만질 패키지·경로: `apps/web/src/api/client.ts`(함수 2개), `apps/web/src/engine/presence.ts`(신규: 쿼리 옵션·훅·하트비트 훅), `apps/web/src/shared/LivePresenceBadge.tsx`(신규, props만 받는 표시 컴포넌트) + 기존 테스트 파일에 케이스 추가, `apps/web/src/routes/__root.tsx`(배지 렌더·하트비트 훅 장착), `packages/ui/src/game.css`(`.os-nav-live*` 스타일만), `apps/web/src/legal/privacy.tsx`(수집 정보 1줄).
- 만들 것:
  1. `client.ts`: `getLivePresence()`(GET `/v1/presence`, `LivePresenceSchema`), `postPresenceHeartbeat()`(POST `/v1/presence/heartbeat`, 본문 `{}`, 204 허용).
  2. `engine/presence.ts`: `livePresenceQueryOptions` = `queryKey ['presence','live']`, `refetchInterval: 60_000`, `refetchIntervalInBackground: false`, `staleTime: 30_000`, `retry: false`; `useLivePresence()`; `usePresenceHeartbeat()` — 마운트 시 1회 + 60초 간격, `document.visibilityState === 'visible'`일 때만 전송, `visibilitychange`로 visible 복귀 시 즉시 1회, 실패는 조용히 무시(콘솔 경고 없음). 하트비트 성공 뒤 `queryClient.invalidateQueries(['presence','live'])`는 하지 않는다(30초 캐시라 의미 없음).
  3. `LivePresenceBadge`: `({ playingNow }: { playingNow: number | undefined })`. 데이터가 없거나 0이면 `null`(헤더가 흔들리지 않게). 있으면 `<span className="os-nav-live" role="status" aria-live="off"><span className="os-nav-live-dot" aria-hidden="true" /><span>{n}명 플레이 중</span></span>`. 숫자는 `toLocaleString('ko-KR')`.
  4. `__root.tsx`: `RootComponent`에서 `usePresenceHeartbeat()`·`useLivePresence()`를 부르고 `GameNavigation`에 `playingNow`를 prop으로 넘긴다. 네비 우측 컨트롤(커리어 캡션 / 설정 링크)을 `<div className="os-nav-right">`로 감싸 배지를 그 왼쪽에 둔다(3슬롯이 아니라 우측 그룹). 브랜드 쪽은 손대지 않는다.
  5. `game.css`: `.os-nav-right { display:flex; align-items:center; gap: var(--os-space-3) }`, `.os-nav-live`는 `.os-nav-context`와 같은 캡션 크기·`--os-text-2`, `.os-nav-live-dot`는 8px 원, 배경 `var(--os-success)`, 모션 감소가 아닐 때만 2초 주기 부드러운 pulse(`prefers-reduced-motion: reduce`면 정지). 색 리터럴·`!important` 금지.
  6. `privacy.tsx` "수집하는 정보"에 1줄: `세션의 마지막 활동 시각 — 플레이 중 인원 집계(5분 창)에만 쓰이며 개인을 표시하지 않습니다.` (문구 그대로.)
- 만지지 말 것: `apps/api/**`, `packages/contracts`, `packages/ui` 컴포넌트(TSX), 브랜드 링크·설정 링크의 동작, 다른 화면의 캡션, e2e 단언 완화, docs.
