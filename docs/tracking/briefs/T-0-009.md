# T-0-009: `apps/web` 라우터·Tailwind 토큰·공통 상태 훅 골격과 허브 빈 상태 화면

## 목표

`apps/web`을 실제 앱 골격으로 만든다. TanStack Router로 SCR ID를 라우트 이름에 매핑하고, `packages/ui`에 13 문서의 `--os-*` 토큰(`tokens.css`)과 최소 프리미티브를 두고 Tailwind v4 `@theme`에 연결하며, 06 문서의 공통 상태 계약(LOADING·EMPTY·DRAFT·COMMITTING·RESOLVED·ERROR)을 훅과 컴포넌트로 구현한다. 첫 화면은 SCR-001 허브의 EMPTY 상태("커리어 없음")이며, 두 테마·360px·200% 확대에서 깨지지 않는다.

## 시작 전 필수

- 워크트리는 `origin/main`에서 만들어졌다. T-0-001 머지 커밋 이후인지 확인한다(`apps/web/src/main.tsx`가 있어야 한다). 아니면 `git fetch origin && git reset --hard origin/main`.
- `pnpm install --frozen-lockfile && pnpm lint && pnpm typecheck && pnpm test && pnpm build` 통과 상태에서 시작.
- T-0-002(domain)와 병렬로 진행된다. `@offside/domain`·`@offside/engine-client`·`@offside/platform`은 이 작업에서 import하지 않는다.

## 범위

만질 경로: `apps/web/**`, `packages/ui/**`. lockfile은 아래 허용 의존성 추가로만 바뀐다.

만지지 말 것: 다른 패키지, `apps/api`, `tooling/**`(lint 규칙이 방해되면 질문), `docs/**`, `.github/**`. 커리어 생성·엔진 연결·저장(T-0-007, T-0-012, Phase 1)은 하지 않는다.

허용 의존성(안정 최신, 프리릴리스 금지): `@tanstack/react-router`, `@tanstack/router-plugin`(Vite 플러그인, 파일 기반 라우트), `@tanstack/react-query`, `zustand`, `tailwindcss` + `@tailwindcss/vite`, `pretendard`(self-host용 폰트 파일). Radix는 아직 넣지 않는다(이 작업에 Dialog·RadioGroup이 없다). `@apps-in-toss/*` 금지.

### 만들 것

1. `packages/ui` (`@offside/ui`)
   - `src/tokens.css`: 13 DSN-COL-001·TYP-001·SPC-001의 CSS를 **그대로** 옮긴다(값 변경 금지). 다크는 `:root[data-theme="dark"]`와 `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) {…} }` 두 선택자에 같은 값. 추가로 `--os-safe-top: env(safe-area-inset-top, 0px)`, `--os-safe-bottom: env(safe-area-inset-bottom, 0px)`(DSN-CHN-001, web 채널 값). 폰트 `@font-face`는 `pretendard` 패키지의 variable woff2를 self-host하고 `font-display: swap`. 타이포 토큰은 `--os-text-display`… 대신 클래스 없이 CSS 변수 `--os-fs-h1: 1.5rem; --os-lh-h1: 2rem` 같은 크기·행간 쌍(표의 9개 행 전부, rem 단위). 숫자 클래스 `.os-num { font-variant-numeric: tabular-nums }`.
   - `src/tailwind.css`: `@import "tailwindcss"; @theme { --color-os-bg: var(--os-bg); … }`로 색·간격·radius·폰트를 Tailwind 유틸리티에 매핑한다. 임의 색상 클래스(`bg-[#…]`, `text-[#…]`)는 쓰지 않는다.
   - 프리미티브(모두 `packages/ui/src/components/`, React 19, `forwardRef` 불필요): `PageShell`(최대 폭 640/1120, 좌우 16px, `--os-safe-*` 패딩, 하단 고정 CTA 슬롯), `Button`(variant `primary`(accent 채움 + `--os-on-accent` 텍스트)·`secondary`·`ghost`, 최소 44×44, 포커스 링 `--os-focus` 2px/offset 2px), `Card`(1px `--os-border`, radius 8, 그림자 없음), `DisplayWord`(브랜드 어휘 전용: display 토큰 + 바로 아래 caption 필수 prop), `Skeleton`, `EmptyState`(이유 문구 + 안전한 다음 동작 CTA), `ErrorState`(원인·재시도·복구), `OffsideLine`(DSN-LINE-001: 2px/3px `--os-line`, 320ms scaleX 등장, `prefers-reduced-motion`이면 즉시 완성. **이 작업의 어떤 화면에도 렌더하지 않는다.** 허용 순간 3개는 이후 화면 작업이 쓴다).
   - `scripts/check-contrast.mjs` + `pnpm --filter @offside/ui check:contrast`: `tokens.css`를 파싱해 두 테마 각각 `text`·`text-2`를 `bg`·`surface`·`surface-2` 위에, `on-accent`를 `accent` 위에 올린 대비가 4.5:1 이상인지, `line`·`success`·`warning`·`danger`·`focus`가 `bg` 위에서 3:1 이상인지 계산해 미달이면 exit 1. 수치가 미달하면 토큰을 고치지 말고 결과를 PR 본문에 적고 질문한다.
   - 테스트: `Button`이 44px 최소 높이 스타일을 가진다, `DisplayWord`가 caption 없이 렌더되면 타입 오류(테스트는 `// @ts-expect-error`), `packages/ui/src`와 `apps/web/src`의 `.tsx`·`.css`(단 `tokens.css` 제외)에 `#[0-9a-fA-F]{3,8}` 리터럴이 없다(파일 스캔 테스트).
2. `apps/web`
   - `index.html`: `lang="ko"`, `<title>OFFSIDE</title>`, viewport `width=device-width, initial-scale=1, viewport-fit=cover`, `<meta name="theme-color">` 라이트 `#F7F6F1`·다크 `#0B1410`(`media` 속성으로 두 개, 이 파일의 hex는 예외), `<meta name="color-scheme" content="light dark">`.
   - Vite: `@tailwindcss/vite`, `@tanstack/router-plugin/vite`(`routesDirectory: src/routes`, 생성 파일 `src/routeTree.gen.ts`는 커밋한다), `build.rollupOptions.output.manualChunks`로 `react`·`react-dom`·`@tanstack/*`를 `vendor`로 분리. `vite build --mode toss`는 아직 특별한 동작이 없어도 되지만 실패하면 안 된다.
   - 라우트(파일 기반): `__root.tsx`(`PageShell` + `QueryClientProvider` + `notFoundComponent` → 허브로 안내), `index.tsx` = SCR-001, `career.new.tsx`(`/career/new`, EMPTY 상태 "커리어 생성은 다음 단계에서 열립니다" + 허브로 돌아가기. SCR-002 자리표시), `legal.terms.tsx`·`legal.privacy.tsx`(`/legal/terms`, `/legal/privacy`. h1과 "문서 준비 중" 한 문단. ADR-009: 외부 링크 금지). 라우트 파일 상단 주석에 SCR ID를 적는다. `src/routes.ts`에 `SCREEN_ROUTES = { 'SCR-001': '/', 'SCR-002': '/career/new', … } as const`를 두고 테스트로 라우트 트리와 대조한다.
   - 공통 상태: `src/shared/screen-state.ts`
     ```ts
     export type ScreenState<TData, TDraft = never> =
       | { kind: 'LOADING'; stage?: string }
       | { kind: 'EMPTY'; reason: string }
       | { kind: 'DRAFT'; draft: TDraft }
       | { kind: 'COMMITTING'; commandId: string }
       | { kind: 'RESOLVED'; data: TData }
       | { kind: 'ERROR'; code: string; message: string; retryable: boolean };
     export function useScreenState<TData, TDraft = never>(initial): { state; set; toLoading; toEmpty; toDraft; toCommitting; toResolved; toError };
     ```
     규칙(06 "공통 상태"·"내비게이션"): `COMMITTING`에서는 `toDraft`·`toCommitting` 호출을 무시하고(중복 제출 금지) `RESOLVED`·`ERROR`로만 간다. `ERROR`는 이전 `RESOLVED` 데이터를 `previous`로 보존한다. `<ScreenStateView state={…} loading empty error resolved draft />`가 상태별 렌더를 고정한다(`aria-live="polite"` 영역 하나, LOADING·COMMITTING 전환 시 단계 문구만 낭독).
   - 클라이언트 상태: `src/shared/ui-store.ts`(Zustand) `{ theme: 'SYSTEM'|'LIGHT'|'DARK'; reducedMotion: 'SYSTEM'|'ON'|'OFF'; textScale: 100|125|150 }`. `useApplyTheme()`가 `document.documentElement`에 `data-theme`(SYSTEM이면 속성 제거)와 `data-text-scale`을 반영한다. **영속화하지 않는다**(저장은 T-0-012의 `platform` LocalStore가 맡는다. `localStorage` 직접 접근 금지).
   - 서버 상태: `src/shared/query-client.ts`(TanStack Query, `retry: 1`, `staleTime: 30s`). 쿼리는 아직 없다.
   - SCR-001 허브(`index.tsx`): 이 작업에서는 항상 EMPTY 상태다. 구성: `DisplayWord` `KICKOFF` + caption "첫 커리어를 시작할 준비가 됐습니다"(12 어휘 표: 허브의 새 커리어 진입에 허용), `EmptyState` 이유 "아직 만든 커리어가 없습니다", 주 CTA `Button` 라벨 **"커리어 시작"**(DSN-BRD-001. `KICKOFF`를 버튼 라벨로 쓰지 않는다) → `/career/new`. 보조 링크: 설정(비활성, "다음 단계") 대신 두지 않는다. 푸터에 `/legal/terms`·`/legal/privacy` 내부 링크(`<Link>`). `--os-line` 색 사용 금지.
   - 접근성: 모든 상호작용 요소 키보드 도달·포커스 링, `EmptyState` 헤딩 구조(h1 하나), 버튼 라벨은 텍스트. 모션 감소 미디어쿼리에서 전환 즉시 완료(전역 CSS).
   - `scripts/check-bundle.mjs` + `pnpm --filter @offside/web check:bundle`: `vite build` 후 `dist/assets`의 진입 JS(라우트 청크 제외, `index-*.js` + `vendor-*.js`) gzip 합이 300KB 이하(DSN-CHN-001), 아니면 exit 1.
   - 테스트(Vitest + Testing Library, jsdom): 허브가 h1·"커리어 시작" 버튼·법적 링크 2개를 렌더한다, 버튼 클릭 시 `/career/new`로 이동(메모리 히스토리), `/legal/terms` 렌더, 존재하지 않는 경로는 not-found 안내, `useScreenState` COMMITTING 중 `toDraft` 무시·ERROR가 previous 보존, `useApplyTheme`가 `data-theme` 설정·제거, `SCREEN_ROUTES`의 모든 경로가 라우트 트리에 있다.
3. 루트 `package.json`은 건드리지 않는다(`build:toss` placeholder 유지). `apps/web/package.json` 스크립트: `dev`, `build`, `build:toss`(`vite build --mode toss`), `preview`, `test`, `typecheck`, `lint`, `check:bundle`.
