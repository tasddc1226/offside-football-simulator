# T-0-001: 모노레포 골격과 패키지 의존 방향 lint

## 목표

빈 저장소에 pnpm + Turborepo 모노레포 골격을 만들어, 이후 모든 작업이 `pnpm install && pnpm lint && pnpm typecheck && pnpm test && pnpm build` 한 줄로 검증되고 패키지 의존 방향 위반이 lint에서 잡히게 한다.

## 참조 명세

- 요구사항 ID: ADR-005(모노레포·의존 방향), ADR-001(웹 프레임워크), ADR-003(domain 순수성), ADR-007(Cloudflare), ADR-009(채널 어댑터 구조)
- 읽어야 할 문서: `docs/adr/ADR-005-monorepo-boundaries.md`, `docs/adr/ADR-001-web-framework.md`, `docs/adr/ADR-003-simulation-location.md`, `docs/development/01-system-architecture.md`의 "패키지 경계", `docs/development/03-game-simulation-engine.md`의 결정론 단락(마지막 문단)
- 정본 우선순위: docs/adr > docs/development > phases > screens > content > PDF

## 시작 전 필수

이 워크트리는 `origin/main`에서 만들어졌다. 시작 직후 `git log --oneline -1`이 `b352cf6` 이후 커밋인지 확인한다. 아니면 `git fetch origin && git reset --hard origin/main` 후 작업 브랜치를 만든다. 저장소에는 현재 문서만 있고 코드는 없다.

## 범위

만질 경로: 저장소 루트 설정 파일, `apps/web`, `apps/api`, `packages/domain`, `packages/content`, `packages/contracts`, `packages/engine-client`, `packages/platform`, `packages/ui`, `packages/fixtures`, `tooling/eslint-config`, `tooling/tsconfig`, `tooling/scripts`.

만지지 말 것: `docs/**`, `README.md`, `.github/**`(CI는 T-0-010), 게임 규칙·화면·API 구현(각각 다른 작업).

### 만들 것

1. 루트
   - `package.json`: `"packageManager": "pnpm@<현재 안정 메이저 최신>"`, `engines.node >=22`, 스크립트 `dev`, `build`, `test`, `lint`, `lint:deps`, `typecheck`, `format`, `content:validate`, `db:migrate`, `build:toss`(지금은 `echo "deferred: see docs/tracking/board.md M-002" && exit 0`).
   - `pnpm-workspace.yaml`(`apps/*`, `packages/*`, `tooling/*`), `turbo.json`(`build`는 `^build` 의존, `test`·`lint`·`typecheck`는 캐시, `dev`는 `persistent`).
   - `.node-version`(22), `.gitignore`, `.editorconfig`, `.prettierrc`, `eslint.config.js`(flat config, `tooling/eslint-config` 사용), `vitest.workspace.ts` 또는 각 패키지 `vitest.config.ts`.
   - TypeScript strict, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `verbatimModuleSyntax`. 베이스는 `tooling/tsconfig/base.json`, 변형은 `browser.json`, `worker.json`(Cloudflare Workers), `pure.json`(DOM·Node 타입 없음, `lib: ["ES2023"]`, `types: []`).
2. `packages/domain` (`@offside/domain`): `tsconfig`은 `pure.json`. `src/index.ts`에 `export const DOMAIN_VERSION = '0.0.0'`와 순수 함수 하나(예: `clamp`). 테스트 1개. 외부 dependencies 0개.
3. `packages/contracts`, `packages/content`, `packages/engine-client`, `packages/platform`, `packages/ui`, `packages/fixtures`: 각각 `@offside/<name>`, `src/index.ts` placeholder export, 테스트 1개, ADR-005 의존 방향에 맞는 `dependencies`만 선언. `platform`은 `src/web/index.ts`와 `src/toss/index.ts` 두 진입점을 `exports`로 노출하되 둘 다 같은 `Platform` 인터페이스 타입을 export하는 스텁이면 된다. 앱인토스 SDK 의존성은 추가하지 않는다.
4. `apps/web` (`@offside/web`): Vite(6 이상 안정) + React 19 + TypeScript. `index.html` 제목 `OFFSIDE`, `src/main.tsx`가 `<h1>OFFSIDE</h1>` 하나를 렌더한다. Tailwind는 넣지 않는다(T-0-009). 테스트: Vitest + Testing Library로 렌더 1개.
5. `apps/api` (`@offside/api`): Hono + `wrangler.jsonc`(name `offside-api`, `main: src/index.ts`, `compatibility_date`는 오늘 기준, D1 바인딩 없음). `GET /v1/health` → `{ "data": { "ok": true }, "meta": { "requestId": "<uuid>" } }`. 테스트 1개(Hono `app.request`). `wrangler dev`가 뜨는지 확인하되 Cloudflare 계정은 필요 없다.
6. `tooling/eslint-config`: 공통 규칙 + 패키지별 오버라이드.
   - `packages/domain`: `no-restricted-imports`로 모든 외부 모듈과 `node:*` 금지(상대 경로만 허용), `no-restricted-globals`로 `window`, `document`, `navigator`, `localStorage`, `indexedDB`, `fetch`, `setTimeout`, `setInterval`, `crypto`, `process` 금지, `no-restricted-properties`로 `Date.now`, `Math.random` 금지, `no-restricted-syntax`로 `new Date()` 금지.
   - `apps/web`, `packages/ui`, `packages/engine-client`: `@apps-in-toss/*` import 금지(메시지: "platform/toss에서만 허용").
   - `packages/ui`: `@offside/domain`·`@offside/engine-client` import 금지.
7. `tooling/scripts/check-deps.mjs`와 루트 `pnpm lint:deps`: 각 워크스페이스 `package.json`의 `dependencies`·`devDependencies` 중 `@offside/*`가 ADR-005 의존 방향 표의 허용 목록 안에 있는지 검사한다. 허용 목록은 스크립트 안의 상수 객체로 두고 ADR-005 표와 같은 순서로 적는다. 위반 시 exit 1과 패키지·의존성 이름 출력. 스크립트 자체 테스트 1개(임시 디렉터리 fixture로 위반·정상 각 1건).

## 완료 조건

- [ ] 새 클론에서 `pnpm install --frozen-lockfile && pnpm lint && pnpm lint:deps && pnpm typecheck && pnpm test && pnpm build` 가 모두 exit 0.
- [ ] `packages/domain/src`에 `import fs from 'node:fs'`와 `Date.now()`를 넣은 임시 파일을 만들면 `pnpm lint`가 두 위반을 보고한다. 확인 후 파일은 삭제하고 출력만 PR 본문에 붙인다.
- [ ] `packages/ui/package.json`에 `@offside/domain`을 넣으면 `pnpm lint:deps`가 실패한다. 확인 후 되돌리고 출력을 PR 본문에 붙인다.
- [ ] `pnpm --filter @offside/api dev`로 `GET http://localhost:8787/v1/health`가 위 JSON을 돌려준다.
- [ ] `pnpm --filter @offside/web dev`로 브라우저 제목이 `OFFSIDE`다.
- [ ] Turborepo 캐시가 두 번째 `pnpm build`에서 `FULL TURBO` 또는 cache hit를 보인다.
- [ ] 문서 수정 없음. 코드 주석은 한국어 또는 영어 자유.

## 제약

- domain 패키지는 외부 import·Node·브라우저 API 금지. 시간·난수는 입력으로만 받는다.
- 버전은 2026-09 기준 안정 최신을 쓰고 lockfile로 고정한다. 프리릴리스(rc, beta, canary) 금지.
- 라이선스 파일은 만들지 않는다.
- 커밋 메시지는 `T-0-001: …`로 시작. 브랜치는 `T-0-001-monorepo-skeleton`.
- 커밋 트레일러: `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`.
