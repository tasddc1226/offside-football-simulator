# T-7-034 상황에 따른 사건과 후속 서사

사용자 요청(2026-09-15): 사건의 경우의 수와 랜덤성을 늘리고 선택이 이야기로 이어지게 한다. 기준 main은 `533c3d4`, 운영 조합은 `1.7.0 / 0.6.3`이다.

## 목표와 범위

- FR-EVT-VARIETY-001: 새 팩 `0.6.4`에 최소 18개 사건, 최소 6개 주제의 연속 사건을 저작한다. 동료·경쟁자, 감독·전술, 팬·미디어, 훈련·부진, 벤치·복귀, 계약·잔류를 다룬다.
- FR-EVT-VARIETY-002: 각 사건은 2~3개 구체적 행동과 실제 적용 가능한 대가·보상을 제시한다. 서로 다른 선택이나 확률 결과가 다른 후속 사건으로 이어져야 한다.
- RULE-EVT-VARIETY-001: 기존 조건 DSL, 가중 추첨, 태그, 쿨다운, followUps를 우선 사용한다. 후속 사건의 단독 노출, 문맥에 맞지 않는 사건, 무한 반복을 막는다. 이벤트 수 증가는 시즌 결정 예산 증가를 뜻하지 않는다.
- RULE-EVT-VARIETY-002: 동일 seed·명령·버전의 결과는 동일하다. 재접속·재시도는 다시 추첨하지 않는다. 기존 팩과 룰셋 파일은 바꾸지 않는다.

## 소유권과 전달

Sol은 콘텐츠와 필요한 버전 등록을 구현한다. T-7-035의 이벤트 화면과 모달 파일은 편집하지 않는다. 기존 1.7.0 성장·은퇴·리그 밸런스를 계승한다. 운영 시즌의 기본 팩 전환은 이 PR에 포함하지 않으며 새 팩을 실제 로드하고 검증할 경로를 제공한다.

최소 회귀 검증은 D-62를 따른다. 같은 seed 재현, 다른 seed 경로 차이, 신규 사건의 실제 엔진 도달성, 분기·쿨다운, 과거 버전 보존을 증거로 남긴다. 후보 목록만 합성한 검증과 실제 ADVANCE 플레이를 구분한다. 콘텐츠 검사와 전체 체인·E2E 결과를 PR에 기록한다. 코디네이터가 원격 main과 비교해 리뷰한다.
