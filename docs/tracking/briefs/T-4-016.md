# T-4-016: 감사 확인 finding — web 소수정 (SCR-020 RETURN 관계 문구·{manager} 서사 토큰)

## 목표

감사에서 확정된 web 문구 결함 2건을 고친다. 임대 복귀 결과 카드가 관계를 "복원했다"고 잘못 말하는 문장(C8)과, 이벤트 서사의 `{manager}` 토큰이 실제 감독(`season.manager.name`)이 아닌 팩 사전 이름을 쓰는 문제(F5)다.

## 참조·선행

- 정본: [phase-3-4-plan.md](../phase-3-4-plan.md) D-45(관계 이월 표)·D-50, [화면 03](../../screens/03-career-events.md) SCR-020, [T-3-005](T-3-005.md) §2, [T-4-011](T-4-011.md).
- 선행: **T-4-011(SCR-020 STAY) 머지 뒤** 최신 `origin/main`에서 시작한다(`apps/web/src/shared/transfer-result.ts`에 `STAY` kind 존재로 확인).
- 코드: `apps/web/src/shared/transfer-result.ts:184~189`(`relationshipReason`), `apps/web/src/shared/narrative.ts:63~71`(`buildNarrativeTokens`, `manager: pack.narrativeTokens.manager[0]`), 도메인 `restoreParentClubState`(`packages/domain/src/simulate.ts:2957~`: managerTrust ← `newManagerTrustBase`, captain 0, rival 0, fans × `fansCarryBp`).

## 1. 작업

- **C8 RETURN 문구**: `relationshipReason`의 RETURN 분기를 도메인 규칙대로 "감독 신뢰·주장·라이벌 관계는 원소속 기준으로 재설정되고 팬 관계는 일부만 이월됩니다."로 바꾼다. `transfer-result.test.ts`에 kind별 관계 문장을 고정하는 테스트(RENEWAL·TRANSFER·FREE_AGENT·LOAN·RETURN·PERMANENT·STAY)를 추가한다.
- **F5 {manager} 토큰**: `buildNarrativeTokens`에서 `manager`를 `state.season?.manager?.name ?? state.nextManager?.name ?? pack.narrativeTokens.manager[0]`로 도메인 값 우선으로 바꾼다. `narrative.test.ts`에 season.manager가 있을 때·없을 때 케이스 추가. 팩 사전 `narrativeTokens.manager`는 건드리지 않는다(content 소유권).
