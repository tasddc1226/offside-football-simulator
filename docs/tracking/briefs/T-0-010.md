# T-0-010 — Cloudflare CI·preview·staging 배포

> 상태: in-progress. 브랜치 `infra/cloudflare-bootstrap`. 선행 U-002 완료(2026-09-04).

## 목표

GitHub Actions의 품질 게이트를 통과한 변경만 Cloudflare에 배포한다. PR은 번호별 웹·API Worker를 만들고, `main`은 staging을 갱신한다. D1 migration은 Worker 배포 전에 적용한다.

## 확정 리소스

| 환경 | 웹 Worker | API Worker | D1 |
|---|---|---|---|
| preview | `offside-web-pr-<N>` | `offside-api-pr-<N>` | `offside-preview` |
| staging | `offside-web-staging` | `offside-api-staging` | `offside-staging` |
| production | `offside-web` | `offside-api` | `offside-production` |

D1 세 개는 APAC location hint로 생성했다. 기존 계정의 `coinsquad-admin`·`coinsquad-db`는 범위 밖이며 수정하지 않는다. production은 이 작업에서 배포하거나 migration하지 않는다.

## 범위

- `.github/workflows/ci.yml`: lint·의존 방향·typecheck·unit/property·build·bundle·migration drift·Playwright/axe 게이트, PR preview, main staging.
- `.github/workflows/cleanup-preview.yml`: PR 종료 시 그 번호의 웹·API Worker만 삭제.
- `apps/api/wrangler.jsonc`: preview/staging/production D1 binding과 공개 변수. Google client ID·secret은 넣지 않는다.
- `apps/web/wrangler.jsonc`: assets-only Worker, SPA fallback.
- `apps/api/seeds/bootstrap-non-production.sql`: preview/staging의 `svc_kickoff` 멱등 bootstrap. production에는 사용하지 않는다.
- ADR-007과 배포 관련 문구를 Pages에서 Workers Static Assets로 정렬한다.

## 보안·운영 결정

1. GitHub Secrets는 `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`만 사용한다. 토큰 권한은 D1 Write, Workers Scripts Write, Account Settings Read이며 2027-09-04 만료다.
2. PR preview는 신뢰된 동일 저장소 브랜치에서만 돈다. 외부 fork에는 Secret을 전달하지 않는다.
3. 공유 preview D1의 migration·seed는 `cloudflare-preview-d1` concurrency group으로 직렬화한다. 테스트 데이터만 허용한다.
4. 도메인과 Google OAuth가 확정되기 전에는 `workers.dev` 주소를 쓴다. production 자동 배포는 별도 출시 게이트로 남긴다.
5. Free 플랜으로 시작하고 LINE TEST 직전에 U-014에서 Paid로 전환한다.

## 검증

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm lint:deps
pnpm typecheck
pnpm test
pnpm build
pnpm --filter @offside/web check:bundle
pnpm --filter @offside/api db:check
pnpm --filter @offside/web e2e
```

PR workflow가 preview D1 migration·seed, 웹·API 배포, 두 URL smoke test를 통과해야 한다. main merge 뒤 staging에서도 같은 순서와 smoke test를 통과해야 T-0-010을 `completed`로 바꾼다.
