## 검증 정책

사용자 지침대로 기존 테스트에 필요한 확인만 보강한다. 문구 전체·CSS 구조·애니메이션 시간을 snapshot으로 고정하지 않는다.
타입/lint/관련 기존 회귀와 생성·이적·결산 브라우저 경로를 확인하고, 병합 전 최신 main 및 CI를 다시 확인한다.
실제 화면 검증은 ego-browser의 격리 공간에서 하며 사용자 커리어·프로필은 변경하거나 삭제하지 않는다.

### 로컬 검증 결과

- Web 단위·화면 회귀: 47개 파일, 431개 테스트 통과.
- TypeScript 검사 및 lint 통과.
- 기존 `create`, `transfer`, `season-result` E2E: 10개 통과. 임대 수락→복귀 및 결산 저장 응답 유실 복구 포함.
- 이적 관련 8개 화면의 기존 접근성 검사: serious/critical 위반 0건.
- 추가 검증은 생성 화면의 미확정/저장 후 안내와 제안 유효 결정 수 경계에 한정했다.
- 챕터 정의에는 별도 `title`이 없으므로 실제 챕터 화면과 동일한 trigger label을 사용한다. 미등록 ID는 `핵심 경기`로 대체한다.
- CI run `33962528771`에서 첫 season-result E2E가 seed 없이 실행되어 결산 직후 INTEREST 시장이 열렸고, 다음 시즌 `/preseason` 기대가 깨졌다. 첫 테스트에도 기존 두 번째 테스트와 동일한 `E2E_SEASON_RESULT_SEED` 초기화 패턴을 적용해 경로를 결정적으로 고정했다. 라우팅 assertion은 완화하지 않았으며, 동일 스펙을 3회 반복해 확인했다.
