# T-7-008: 선택 카드(RadioGroup) Enter 키로 선택 (이슈 #149)

## 목표

이벤트·챕터 선택지는 `packages/ui`의 `RadioGroup`(Radix `@radix-ui/react-radio-group`) 위에 `ChoiceCard`로 그린다. Radix 기본 동작은 Space로 선택, 화살표로 이동이며 **Enter는 삼킨다**.
운영 QA 기능 관점(`docs/qa/2026-09-07-production-three-perspectives/README.md` P2)에서 키보드 사용자가 Enter로 카드를 고르지 못해 막혔다.
Enter를 누르면 포커스된 항목이 선택되게 한다(폼 submit은 일으키지 않는다). 확인 버튼 자동 실행(#168)은 범위 밖이다.

## 범위

- 만질 패키지·경로: `packages/ui/src/components/RadioGroup.tsx`(+`RadioGroup.test.tsx`)만.
- 만들 것: `RadioGroupItem`(또는 이 파일의 항목 래퍼)에 `onKeyDown`을 합성해 `event.key === 'Enter'`이면 `event.preventDefault()` 뒤 `event.currentTarget.click()`으로 선택한다. 사용자가 넘긴 `onKeyDown`이 있으면 먼저 호출하고 `defaultPrevented`면 건너뛴다. 이미 선택된 항목에서 Enter는 아무 일도 하지 않는다(값 변경 이벤트 중복 없음). Space·화살표 동작은 그대로.
- 만지지 말 것: `ChoiceCard.tsx`, `apps/web`, 확인 버튼 자동 실행(#168), docs.
