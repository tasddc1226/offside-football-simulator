## 순차 완료 조건

### 1. 실제 경기 선택과 피드백 — FR-GROW-1

- [x] 자연스러운 신규 커리어의 첫 경기에서 의미 있는 선택을 경험한다.
- [x] 선택이 실제 득점·도움·승패 등 해당 장면의 결과에 반영된다. 설명이나 평점만 바꾸는 구현으로 대체하지 않는다.
- [x] 선택 → 경기 결과 → 관계 반응을 저장된 사실로 연결해 보여 준다.
- [x] 스코어, 개인·팀 통계, 순위표, 경기 기록과 후속 참조가 서로 일치한다.

1단계 승인 설계: `3.2.0/0.11.0`의 opt-in 경기 장면은 현재 step에서 대상 경기의 기본 결과를 계산한 직후, 이후 경기를 진행하기 전에 멈춘다. 새 pending chapter의 우선순위로 일반 사건 슬롯이 이 멈춤을 삼키지 않게 하되 필수 부상·대표팀·계약 결정을 보존한다. step 종료 조건 처리는 결정을 마칠 때까지 미루고 같은 step을 정확히 한 번 재개한다. 같은 step에 두 번째 장면은 열지 않는다. 슈팅·도움·선방·차단 결과에는 변경 전후 스코어와 개인 통계 귀속 영수증을 남긴다. 이후 진행 전에 리그 원장·누적 기록·컵 진출과 최종 평점 의존 선수단 상태를 재계산한다. 과거 버전의 진행과 결과는 바꾸지 않는다.

### 2. 커리어 기사와 동일 조건 도전 — FR-GROW-2

- [ ] 실제 은퇴 기록에서 기사 제목과 핵심 사실을 만들고 공개 페이지로 공유할 수 있다. 없는 수상·활약을 만들어 내지 않는다.
- [ ] 기존 공개 공유 endpoint가 없음을 기준으로 필요한 API를 추가한다. 비공개 retirement core는 source state·log를 포함하므로 절대 그대로 공개하지 않고 허용 필드만 기사에 투영한다. 명시적 공개 동의, 취소와 접근 종료를 제공한다.
- [ ] 공유 링크의 도전은 최초 seed·룰셋·콘텐츠 버전·선수 설정·선택 빌드를 재현한다. 원본 커리어의 소유권·복구 코드·스냅샷·명령 로그는 전송하지 않는다.
- [ ] 다른 방문자가 링크에서 독립된 신규 커리어를 만들고 계속 플레이한다.
- [ ] 공개와 동일 조건 도전은 각각 명시적 UI 동작으로 실행한다. 검증 중 타인의 데이터를 자동 공개하지 않는다.

2단계 설계 주의: 기사의 허용 필드는 서버가 소유권과 archive의 스키마·해시 무결성을 확인한 저장 기록에서 파생한다. 기존 retirement 저장은 명령 재생 기반 부정행위 검증을 하지 않고 정상 sync도 `PENDING`이므로 이를 `VERIFIED` 또는 부정행위 방지 증거로 표현하지 않는다. 클라이언트가 보낸 임의 기사 성적을 신뢰하지 않는다. 도전은 최초 `simulationMode`, 전체 seed, 정확한 불변 버전 쌍과 최초 draft를 고정한다. 포지션은 경력 중 바뀐 최종 `primaryPosition` 대신 최초 `preferredPosition`을 사용한다. 이름은 참가자가 새로 정할 수 있으며 동등한 경기 조건이 재현 기준이다. 기존 `isAcceptedSeasonVersion`은 시즌 버전 쌍 또는 승인된 `svc_season_1` 버전만 허용하므로 공개 도전에 결합된 제한적 admission 경로를 마련하고 일반 시즌 검증을 우회하지 않는다.

### 3. 은퇴 선수 친선 경기 — FR-GROW-3

- [ ] 저장한 팀의 은퇴 선수로 실제 플레이 가능한 결정론적 친선 경기를 실행한다. 빈 자리는 기본 동료가 채워 첫 은퇴 선수부터 이용할 수 있다.
- [ ] 포지션·선발·조합 선택이 경기 계산에 의미 있게 반영된다.
- [ ] 경기 결과 영수증을 저장하고 새로고침 이후에도 읽을 수 있다. 원본 선수의 커리어 통계는 바꾸지 않는다.
- [ ] 친선 경기는 명시적 UI 동작으로 시작한다.
- [ ] 실시간 PvP를 포함하지 않는다. 편성 화면만 추가하거나 결과를 임의 표시하는 것으로 대체하지 않는다.

### 4. 인물 기억과 재회 — FR-GROW-4

- [ ] 이름과 정체성이 일관된 인물이 플레이어의 실제 선택을 기억한다.
- [ ] 선택의 후속 반응과 실제 이적·경기·경력에 근거한 재회가 자연 진행에서 발생한다.
- [ ] 인물·시점·과거 사실이 맞는 경우에만 문구를 노출한다. 무관한 무작위 대사나 허구의 수상으로 대체하지 않는다.
- [ ] 신규 콘텐츠는 추가 버전으로 제공하고 과거 저장본의 사건 의미를 유지한다.
