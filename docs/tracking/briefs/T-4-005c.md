## 1. 작업

- **점진 공개(D-57, 부모 §3)**: `career.$careerId.index.tsx` 라커룸·휴대폰 탭. 단계 판정은 `contract`·`seasonHistory.length`에서 파생(새 저장 필드 없음). 라벨은 `shared/labels.ts`의 기존 함수를 쓰고 부족한 라벨만 같은 파일에 추가한다. 감독 이름·재직 시즌(`season.manager`), 주장단(`captaincy`)은 3단계에서만. 어느 단계에서도 대시보드에서 결정을 확정하지 않는다.
- **대시보드 부상·대표팀 표시**: StatusStrip/일정표에 결장 잔여(`availability.matchesRemaining`)·회복 뒤 재발 판정 잔여(`recurrenceChecksRemaining`), `permanentDelta` 확정 에피소드만 능력치 변화 표기; 부상 중 자동 사양(타임라인 `NATIONAL_TEAM_DECLINED` refId INJURY) 사유 카드.
- **SCR-014 결과 카드**(`career.$careerId.event_.result.tsx`): 관계 변화(축·delta·`sourceId`·`reasonTag`), 평판 변화(`popularityCenti` → "인기 ↑/↓ n" 정수), 부상(진단·복귀 범위·재활 계획), 대표팀 결과(참가/사양/조건부 + "감독 신뢰 변화 없음"), 후속 이벤트 힌트. 리플레이·뒤로 가기가 roll을 소비하지 않는 기존 규칙 유지.
- **SCR-023 변형**(`career.$careerId.chapter.tsx`): 챕터 정의에 `positionGroups`가 있으면 헤더에 포지션군 라벨과 현재 선수 포지션군, 없으면 아무것도 추가하지 않는다.
