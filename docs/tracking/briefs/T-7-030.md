# T-7-030: 밸런스 조정 1라운드 ① — OVR 정점 연령 28~30세, 새 룰셋 1.6.1 (growthRules만)

## 목표

헤드리스 시뮬(1.5.0/0.6.0, opportunity, 은퇴까지·상한 30시즌, 1만 커리어)에서 OVR 정점 연령이 평균 34.1세(p10 32·p90 36)로 늦다(D-79, `docs/tracking/evidence/sim-baseline-10k-2026-09-14/report-150-10k.md`). 룰셋 **1.6.0 위에 1.6.1**을 새로 만들어 `growthRules`만 조정해 정점 연령을 **평균 28~30세, p90 33세 이하**로 옮긴다(D-80 1라운드 ①). 1.5.0·1.6.0 룰셋과 콘텐츠 팩 내용은 손대지 않는다.

## 참조 명세

- 요구사항 ID: RULE-GROWTH(성장·쇠퇴), D-62(룰셋 불변·새 버전), D-79·D-80(`docs/tracking/decision-log.md`).
- 읽어야 할 코드: `packages/content/rulesets/1.6.0/{ruleset.json,manifest.json}`(`growthRules`: `budgetCenti`·`gapCap`·`ageCurves.{PHYSICAL,TECHNICAL,MENTAL,GOALKEEPING}`·`decline.*`·`seasonDeltaMin/Max`), `packages/domain/src/growth.ts`(`computeGrowth` 83행~, `ageMultBpOf` 45행, decline 119~121행), `packages/content/src/rulesets/load-ruleset.ts`(`RULESET_VERSIONS`·`RULESET_SOURCES`), `packages/content/src/retirement-artifacts.ts`(`RULESET_MANIFESTS`), `packages/content/packs/0.6.1/manifest.json`(`compatibleRulesetVersions`), `packages/content/src/schema/ruleset.ts`, 1.5.0→1.6.0 선례 커밋 `4d60962`(#217)의 content 변경분, `tooling/scripts/career-sim.ts`(`--ruleset --pack --seed-prefix`), `tooling/scripts/career-sim-report.mjs`(`pnpm sim:report --a DIR --b DIR`).
- 기준선 수치(1.5.0 opportunity 1만, seed 접두어 `base-150`): 나이별 OVR 평균 19세 61.3 → 25세 67.4 → 28세 68.9 → 32세 69.6(최고) → 34세 69.3 → 36세 67.9 → 40세 62.3 → 44세 53.4 → 48세 42.5. peakOvr 평균 69.7(p10 62·p90 77), truePotential 평균 70.6, 잠재 도달률 89.7%.

## 범위

- 만질 것: `packages/content/rulesets/1.6.1/`(신규: 1.6.0 복사 후 `version` 문자열과 `growthRules`만 변경), `packages/content/src/rulesets/load-ruleset.ts`(1.6.1 등록), `packages/content/src/retirement-artifacts.ts`(manifest 등록만 — 활성화 화이트리스트는 건드리지 않음), 콘텐츠 팩 호환: `packages/content/packs/0.6.1/manifest.json`의 `compatibleRulesetVersions`에 `1.6.1` 추가 — 단, 팩 manifest를 검사하는 골든·해시·스냅샷 테스트가 있으면 추가 대신 **팩 0.6.2**(0.6.1 복사 + 호환 목록만)를 만든다(어느 쪽을 택했는지와 근거를 PR에 적는다). 기존 테스트 파일에 1.6.1 버전 목록 항목 추가(새 테스트 파일 금지).
- 만들 것:
  1. 1.6.1 `growthRules` 1차 시도값(출발점 — 아래 반복 절차로 조정 가능):
     - `ageCurves.PHYSICAL`: `[{maxAge:24,multBp:10000},{maxAge:27,multBp:5000},{maxAge:99,multBp:0}]` (현재 25/28/99)
     - `ageCurves.TECHNICAL`: `[{maxAge:20,multBp:8000},{maxAge:26,multBp:10000},{maxAge:29,multBp:5000},{maxAge:99,multBp:0}]` (현재 20/29/32/99)
     - `ageCurves.MENTAL`: `[{maxAge:23,multBp:7000},{maxAge:30,multBp:10000},{maxAge:99,multBp:0}]` (현재 말단 3000 — 고령 성장 유지의 원인이라 0으로)
     - `ageCurves.GOALKEEPING`: `[{maxAge:26,multBp:8000},{maxAge:31,multBp:10000},{maxAge:99,multBp:0}]` (현재 26/34/99·말단 3000)
     - `decline`: PHYSICAL `{startAge:27, perYearCenti:45}`(현재 29/40), TECHNICAL `{30, 30}`(현재 32/25), MENTAL `{32, 25}`(현재 34/20), GOALKEEPING `{33, 30}`(현재 35/25)
     - `budgetCenti`·`gapCap`·`seasonDeltaMin/Max`는 유지. 정점 OVR 평균이 67 아래로 떨어지면 `budgetCenti.U21`을 600→700으로 올려 보정한다.
  2. 반복 절차(한 호출 안에서): `pnpm content:validate` 통과 → `pnpm sim:career --ruleset 1.6.1 --pack <팩> --seeds 1000 --seasons 30 --to-retirement --policy opportunity --position all --jobs 8 --seed-prefix base-150 --out tooling/sim-out/t7025-iter<k>` (1천 커리어, 3~5분) → `pnpm sim:report --a tooling/sim-out/base-150-10k --b tooling/sim-out/t7025-iter<k> --label-a 1.5.0 --label-b 1.6.1-iter<k>`로 peakOvrAge(평균·p10·p90 — 커리어 표에는 히스토그램만 있으니 `careers.csv`의 `peakOvrAge` 열을 직접 집계)·peakOvr 평균·나이별 OVR을 본다. 목표 밖이면 값을 조정해 최대 2회 반복. 1천 표본 오차(정점 연령 평균 ±0.1세 수준)를 감안한다.
  3. 최종 확인은 **1만 커리어를 nohup으로 띄우고 즉시 반환**(워커 호출 시간 상한): `nohup pnpm sim:career --ruleset 1.6.1 --pack <팩> --seeds 10000 --seasons 30 --to-retirement --policy opportunity --position all --jobs 8 --seed-prefix base-150 --out tooling/sim-out/t7025-10k > tooling/sim-out/t7025-10k.log 2>&1 &` — PID를 반환값에 적는다. 판정은 오케스트레이터가 한다.
  4. 짝 비교 검증: `pnpm sim:career --ruleset 1.6.0 --pack 0.6.1 --seeds 200 --seasons 30 --to-retirement --policy opportunity --position all --jobs 8 --seed-prefix base-150 --out tooling/sim-out/t7025-ctrl-160`을 돌려 `careers.csv`를 seed로 조인해 1.5.0(`tooling/sim-out/base-150-10k/careers.csv`)과 `stateHash`가 같은 seed 비율을 적는다(헤드리스에서 1.6.0==1.5.0이면 100%). 100%가 아니면 어떤 seed부터 갈리는지 1건만 예시로 적는다.
- 만지지 말 것: `packages/domain/**`, 룰셋 1.5.0·1.6.0 파일, 팩 0.6.0·0.6.1의 콘텐츠(manifest 호환 목록 외), `apps/**`, ACTIVE 시즌·승격 배선, `tooling/scripts/career-sim*.{ts,mjs}`, docs.
