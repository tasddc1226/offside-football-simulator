# T-7-013: 제안 비교(SCR-009) `<dl>` 구조 axe 위반 수정 (`definition-list`·`only-dlitems`, apps/web)

## 목표

origin/main 전체 e2e에서 a11y.spec:303(SCR-009 제안 비교)이 axe `definition-list`(serious)·`only-dlitems`로 실패한다. 대상은 `apps/web/src/shared/contract-presentation.tsx` 80행 `<dl className="grid grid-cols-2 gap-os-3">` — `<dl>`의 직접 자식으로 `<span class="font-os text-os-text-2">첫 프로 계약</span>` 같은 `dt`/`dd`가 아닌 요소가 들어간다.
이 작업은 **`apps/web`만** 고쳐 `<dl>` 안을 `<div><dt/><dd/></div>` 묶음(axe가 허용하는 유일한 래퍼)으로 바꾸고 시각은 그대로 둔다.

## 참조 명세

- 요구사항 ID: NFR-A11Y(axe serious·critical 0), SCR-009(제안 비교), D-70
- 읽어야 할 문서: `apps/web/src/shared/contract-presentation.tsx`(전체), `contract-presentation.test.tsx`, `apps/web/e2e/a11y.spec.ts` 303행 부근
- 재현: `E2E_PORT=5274 pnpm --filter @offside/web exec playwright test e2e/a11y.spec.ts:303 --workers=1`. 이 테스트가 흐름 드리프트(T-7-011 A 분류)로 SCR-009에 도달하지 못하면, 단위 테스트에서 렌더한 DOM으로 `dl > :not(div, dt, dd)`가 없음을 확인하는 방식으로 대신한다.

## 범위

- 만질 패키지·경로: `apps/web/src/shared/contract-presentation.tsx`(+테스트).
- 만들 것: `<dl>` 직접 자식을 `<div>`로 묶고 그 안에 `<dt>`(라벨)·`<dd>`(값·delta)를 둔다. 그리드 클래스는 `<div>`에 옮겨 2열 레이아웃과 간격을 유지한다. 라벨·값 텍스트, `data-testid`, 순서는 바꾸지 않는다(다른 테스트·e2e 셀렉터 유지).
- 만지지 말 것: 다른 화면의 `<dl>`(이번 위반 대상이 아니면), `packages/ui`, e2e, docs.
