# T-4-004: 대표팀 차출 기본 모듈·NATIONAL_DEBUT 챕터 예약 (domain + content)

## 목표

T-4-002의 건강 상태와 T-4-003의 관계·평판 상태 위에 D-51 대표팀 기본 모듈을 붙인다. step 8에서 자격을 결정론적으로 판정해 NATIONAL_TEAM pending을 열고, 참가·조건부·사양을 기존 `RESOLVE_EVENT`로 닫으며, 부상 중에는 자동 사양한다. 첫 참가 후 `NATIONAL_DEBUT` MAJOR 챕터 후보가 정확히 한 번 열리고, 국적별 특례가 없는 기본 `nationalityRuleState`가 저장·strict 검증된다.

## 참조·선행

- 정본: [phase-3-4-plan.md](../phase-3-4-plan.md) D-51·D-52·D-53/P4-7, [phase-04](../../phases/phase-04-injury-and-relationships.md), [화면 05](../../screens/05-hub-and-support.md) SCR-032·SCR-031, [ADR-010](../../adr/ADR-010-shared-contracts.md), [T-4-002](T-4-002.md), [T-4-003](T-4-003.md).
- 기존 골격: `Pending NATIONAL_TEAM`, `RESOLVE_EVENT.callUp`, `NATIONAL_TEAM_CALLED/DECLINED`, `nationalTeamRules`, `season.ts` step/slot 우선순위, content event의 `presentation:NATIONAL_TEAM`, chapter trigger/candidate 패턴.
- **T-4-002와 T-4-003이 모두 main에 머지된 뒤 최신 main에서 시작한다.** 두 작업이 추가한 `types.ts`·`simulate.ts`·contracts/content 필드, 부상 회복/관계 로그/평판/태그를 모두 보존한다.

## 1. 룰셋·저장 계약

- `nationalTeamRules`에 하드코딩 방지용 `event:{id:'EVT-NAT-001',version:1}`과 평점 대안 기준 `minRatingTenths`를 additive strict 필드로 추가한다. 초기값은 70. 기존 `callUpStep:8`, tier별 OVR, `minPopularityCenti:6000`, 체력 비용·관계 delta·가상 상대 목록은 유지한다. domain fixture 룰셋과 content 1.0.0, schema/test를 함께 갱신한다.
- `CareerState`에 additive `nationalityRuleState`를 둔다. 기본 모듈은 `{ moduleId:'DEFAULT', exceptions:[] }`처럼 특례 없음이 명시되는 최소 정수/문자열 구조이며 `CREATE_CAREER` 기본값·contracts strict schema·기존 golden 갱신을 함께 처리한다. 병역·이중국적·귀화 같은 특례 필드는 만들지 않는다.
- 첫 소집/데뷔 중복 방지를 위해 최소 상태를 저장한다. 기존 tag·timeline·chapter record로 정확히 파생 가능하면 새 boolean을 만들지 말고 그 근거를 테스트한다. 저장이 필요하면 `nationalTeam:{ callUps, accepted, debuted, pendingDebut }`처럼 additive 단일 구조로 두고 기본값을 명시한다. 같은 의미를 tag와 boolean에 중복 저장하지 않는다.

## 2. 자격 판정·step 8 pending

- `national-team.ts`에 rng 0 순수 판정/전이 helper를 둔다. 자격은 (a) `baseOvr >= minOvrByTier[current contract leagueTier]`, 또는 (b) 직전 시즌 평균 평점 `>= minRatingTenths`이면서 `reputation.popularityCenti >= minPopularityCenti`. 프로 계약·ACTIVE 시즌·현재 step 8이어야 하며 한 시즌 중복 소집은 금지한다.
- step 8 캘린더에 NATIONAL_TEAM 슬롯을 추가하되 기존 EVENT 슬롯과 결정 예산을 조용히 잃지 않는다. 자격 미달이면 슬롯은 pending·rng 소비 없이 건너뛰고 같은 step의 다음 후보를 평가한다. 자격 충족이면 `{kind:'NATIONAL_TEAM',step:8,eventId,version}`을 열며 FAST/CHAPTER 모두 사용자 결정이다.
- RULE-TIME-002의 경기 직후 강제 INJURY pending이 항상 대표팀보다 우선한다. 선수의 현재 availability/active episode가 부상 상태면 선택 화면을 열지 않고 `NATIONAL_TEAM_DECLINED(refId:'INJURY')`와 소집/시즌 중복 방지 기록만 남긴 뒤 같은 step 진행을 계속한다. 감독 신뢰·결정 rng는 바꾸지 않는다.
- 생성/자격/자동 사양은 결정 rng와 match rng를 소비하지 않는다. 대표팀 상대 선택은 첫 수락 시 별도 파생 시드 또는 고정 정렬 규칙으로 결정해 주 스트림 draws를 늘리지 않는다. 선택한 규칙을 PR 표에 적는다.

## 3. EVT-NAT-001과 RESOLVE_EVENT 전이

- 0.1.0·0.2.0에 `EVT-NAT-001`, `presentation:'NATIONAL_TEAM'`, callUp A=`ACCEPT`/B=`CONDITIONAL`/C=`DECLINE`을 추가한다. 각 choice는 대회·예상 출전·체력 비용·팬/협회(현 모델에서는 agent 축) 영향과 특례 없음 상태를 preview에서 보여준다. 워커 문구는 `authoring:'PROTOTYPE'`, 0.2.0 manifest는 `playtested:false`, 체크섬은 정상 재계산한다.
- domain은 클라이언트가 보낸 arbitrary effect로 의미 규칙을 우회하지 못하게 callUp 값과 룰셋에서 각 선택의 체력·관계 delta를 적용한다. ACCEPT·CONDITIONAL·DECLINE은 각각 `fitnessCost`·`relationDelta`의 동명 항목을 읽고 기존 clamp/log helper를 사용한다. agent는 협회 대리 축, 팬은 fans 축에 sourceId/reasonTag 로그를 남긴다.
- DECLINE과 부상 자동 사양은 `relationships.manager`를 절대 바꾸지 않는다(P4-7). ACCEPT/CONDITIONAL은 tag `대표팀_소집`과 `NATIONAL_TEAM_CALLED`, DECLINE은 `NATIONAL_TEAM_DECLINED`; pending은 항상 닫히고 다음 ADVANCE가 가능하다. 잘못된 callUp, eventId/version, 중복 resolve는 기존 validation/idempotency로 거부한다.

## 4. NATIONAL_DEBUT 챕터

- `ChapterTrigger`와 strict schema에 `{kind:'NATIONAL_DEBUT'}` 최소 변형을 추가한다. 첫 ACCEPT/CONDITIONAL 후 다음 열릴 수 있는 CHAPTER 슬롯을 위한 후보를 예약하며 importance는 MAJOR, FAST에서도 열린다. 이미 대표팀 데뷔 `ChapterRecord`가 있으면 다시 후보를 만들지 않는다.
- 0.1.0·0.2.0에 최소 `CHP-NAT-001` 정의를 추가한다. 상대는 `nationalTeamRules.opponents` 중 결정론적으로 고른 가상 국가, 판단은 1~3개·각 roll 1회인 기존 chapter 계약을 따른다. 실제 국가/협회/선수 실명, 병역 특례 문구는 금지한다. 0.2.0은 PROTOTYPE/playtested false를 유지한다.
- 소집을 수락했지만 시즌 남은 CHAPTER 슬롯이 없으면 예약이 유실되지 않고 다음 시즌 첫 적격 CHAPTER 슬롯까지 유지된다. 부상으로 경기 출전이 불가능하면 챕터를 열지 않고 예약을 보존한다. 챕터 완료 뒤 debuted/예약 상태가 원자적으로 닫히는지 테스트한다.

## 5. fixture·테스트·인수 조건

- 단위/속성: tier OVR 경계 4종, 평점+인기 대안 양/음성, 비프로·step 불일치·시즌 중복, 부상 자동 사양, 슬롯 우선순위, ACCEPT/CONDITIONAL/DECLINE 체력·관계 표, managerTrust 불변, 관계 log/source, pending 닫힘, rng 0, 기본 nationalityRuleState strict/default.
- 결정론 fixture를 추가하거나 기존 가장 작은 시즌 fixture를 확장해 step 8 소집 → ACCEPT → NATIONAL_DEBUT MAJOR → 시즌 계속을 고정한다. 같은 seed 두 번의 revision/hash/draws가 같고, DECLINE 분기는 감독 신뢰 불변·팬/agent만 변화함을 별도 테스트한다.
- contracts strict 순회, content pack/ruleset validation, Node/workerd hash probe에서 새 additive 상태가 통과해야 한다. 기존 career-10·11·12의 계약/부상/관계 의미와 Base OVR은 바뀌지 않는다. 뜻밖의 기존 결정 rng 변화는 결함으로 취급한다.
