# T-7-009: 대표팀 챕터 결과 요약 섹션 (이슈 #150)

## 목표

대표팀 소집 챕터(`ChapterContext.kind === 'NATIONAL_TEAM'`)의 결과 화면은 리그 경기용 `ChapterResultSection`을 재사용하면서 스코어·개인 기록·평점 변화·헤드라인을 모두 `isNationalTeam`으로 끄기 때문에
"결과가 없다"처럼 보인다(운영 QA 게임성 관점 P2, 이슈 #150). 도메인은 대표팀 경기 스코어를 만들지 않으므로 **꾸며내지 않고**, 이미 있는 데이터(판단 결과·효과·획득 태그·데뷔 예약)만으로 요약 섹션을 그린다.

## 범위

- 만질 패키지·경로: `apps/web`만 — `chapter.tsx`, 필요 시 `chapter-state.ts`의 뷰 헬퍼(+테스트).
- 만들 것: `isNationalTeam`일 때 스코어 자리에 `dl` 요약 섹션 `대표팀 소집 결과`를 렌더한다. 행(데이터가 없으면 행 생략, 섹션 자체는 항상):
  - `소집`: 소집 종류/상대 표기(`NationalDebutReservation`·챕터 컨텍스트에 있는 값만).
  - `판단 결과`: 결정 수 N 중 성공 M(`M/N 성공`) + 각 결정의 선택지 이름과 결과를 한 줄씩.
  - `효과`: 결정 효과 합계를 기존 효과 라벨 함수로(예: `감독 신뢰 +3 · 팬 지지 +2`).
  - `획득 태그`: `resultTagLabel`로 표시, 없으면 행 생략.
  - `데뷔`: 데뷔 예약이 이번 챕터로 확정됐으면 `A대표팀 데뷔 기록`.
  - 캡션: `대표팀 경기는 스코어와 개인 기록을 따로 집계하지 않습니다.`
  기존 헤드라인 자리는 `대표팀 소집을 마쳤습니다`로 고정.
- 만지지 말 것: `packages/domain`(대표팀 스코어 생성 금지), `packages/content`, `labels.ts`(T-7-005가 만진다 — 새 라벨이 필요하면 `chapter.tsx` 안 지역 상수로 두고 PR 본문에 적는다), docs.
