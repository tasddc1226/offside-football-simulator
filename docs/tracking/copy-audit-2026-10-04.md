- 앱: src 176개 파일의 사용자 한국어. 생성·게임·홈·기록·소식·채팅·은퇴·팀·설정·결제·푸시·로그인.
- 공용: app-core 35파일, contracts 19파일, API 38파일의 한국어 문자열. 내부 오류와 사용자 노출 오류를 구분했다.
- 게임: 데이터·훈련·투자·특성·이벤트·연속 스토리·팬 반응·병역·은퇴 성향, 경기·대회·국가대표·기록·칭호.

## 남긴 설명

백업 코드 공유 금지·데이터 소실·되돌릴 수 없는 작업·계정 불일치·복구 절차는 보호 및 복구에 필요해 남겼다.
병역 기한/복무 기간, 시즌 귀속, OVR 계산 및 추정치의 표시 전용 조건, 비용/자금 부족 대안은 선택에 필요해 남겼다.
개인정보/동의/결제·구매 복원·공개 범위·접근성 라벨도 보존했다. 게임 연출의 합니다체·팬 댓글체·은퇴 평의 반말은 유지했다.

조건·수치·밸런스·저장키·이벤트 ID·엔딩 라벨·칭호 키·사용자 작성 글/댓글/기록은 변경하지 않았다.

## 검증 및 앱 적용 범위

최종 결과는 PR과 배포 기록을 참조한다. 최종 독립 검토에서 계정 삭제 경고에 실제 서버 기록·팀·댓글·채팅 삭제 범위와 복구 불가 안내를 보강했다. 네이티브 Simulator/Xcode 작업은 실행하지 않는다.
운영 웹/API와 OTA 게시, 실제 설치 앱 수신은 별도로 확인한다. 호환 production binary가 없으면 앱 적용 예정으로 안내하며 스토어 제출은 하지 않는다.
