# 화면 문구 톤앤매너 가이드

2026-10-02 T-11-043에서 웹·앱·게임 문구를 정리하며 정한 규칙이다. 새 문구를 쓰거나 고칠 때,
리뷰할 때 이 문서를 기준으로 본다.

목표는 하나다. **사람이 쓴 것처럼 짧고 구체적으로.** 멋을 내는 문장, 감정을 대신 해석해 주는 문장,
번역한 것 같은 문장을 쓰지 않는다.

## 1. 말투

| 어디 | 말투 | 예 |
|---|---|---|
| 화면 안내·버튼 주변 설명·토스트·빈 화면·오류·설정 | 해요체 | 이 기기에 저장돼요. / 불러오지 못했어요. 잠시 후 다시 시도해 주세요. |
| 훈련·투자·특성 설명(게임 데이터지만 UI 안내 역할) | 해요체 | 훈련을 쉬고 몸을 추슬러요. / 부상 확률이 크게 낮아요. |
| 게임 속 이벤트 결과·스토리·기사·중계·로그, 영구결번 같은 연출 | 합니다체 | 끝까지 기다렸다가 정면 슈팅을 잡아냈습니다! |
| 은퇴 리포트 한 줄 평(플레이 스타일) | 반말 서술체 | 다른 유니폼은 입어 본 적이 없다. 한 팀에서 끝까지 뛰었다. |
| 팬 반응 | 댓글체(반말) | 이거 보려고 시즌권 끊었다. |
| 약관·개인정보·가이드 본문 | 합니다체 | |

- 한 문단, 한 토스트 안에서 말투를 섞지 않는다.
- 웹(`apps/web`)과 앱(`apps/mobile`)은 같은 문구를 각자 들고 있다. 하나를 고치면 다른 쪽도 같이 고친다.
- 서버 오류 메시지(`packages/app-core`, `apps/api`)도 화면에 그대로 뜨므로 해요체로 쓴다.

## 2. 대시(—)로 문장 잇지 않기

화면에 보이는 문장을 `A — B`로 잇지 않는다. 마침표로 끊거나, 짧은 부가 정보는 쉼표·가운뎃점(·)을 쓴다.

| 전 | 후 |
|---|---|
| 이 기기에만 저장됩니다 — 구글 계정으로… | 이 기기에만 저장돼요. 구글 계정으로… |
| 지난 시즌 팀이에요 — 보기만 할 수 있어요. | 지난 시즌 팀이라 보기만 할 수 있어요. |
| 원클럽맨 — 프로 10시즌 넘게 한 구단 | 프로 10시즌 넘게 한 구단에서 뛴 원클럽맨 |
| 시간 초과 — … | 시간 초과. … |

예외: 연도 범위(2026–2031), 음악 크레딧, 브라우저 탭 제목처럼 표기 관례가 있는 곳.

## 3. 미사여구·번역투 금지

쓰지 않는 말: **나만의, 당신만의, 여정, 특별한 순간, 빛나는, 전 세계, 완벽한, 환상적인, 감격, 영광,
~를 통해, 성공적으로 ~되었습니다, ~할 수 있습니다(가능 안내를 굳이 늘일 때)**.

| 전 | 후 |
|---|---|
| 나만의 커리어를 시작하세요 | 고3부터 은퇴까지, 한 선수로 살아요 |
| 이제 당신의 차례예요 | 이번엔 내 선수를 키울 차례예요 |
| 커리어 여정 | 커리어 이정표 / 구단별 커리어 |
| 오래, 크게 빛난 선수의 | 오래 크게 활약한 선수의 |
| 서버 응답을 해석할 수 없습니다. | 서버 응답을 읽지 못했어요. |
| 경쟁자와 함께 성장하기로 한다 | 경쟁자와 같이 훈련한다 |

- 추상적인 말 대신 무엇이 일어나는지 쓴다("공은 만국 공통어였습니다" → "말은 서툴러도 경기력으로 인정받았습니다").
- UI 안내에서 사용자를 "당신"이라 부르지 않는다. "당신"은 게임 속 이벤트·기사 문장에서만 쓴다.
- 느낌표는 하나까지("우승!!" → "우승!").

## 4. 빈 화면에 권유·응원 꼬리 붙이지 않기

빈 화면은 상태만 말하고 끝낸다. 무엇이 생기면 어디에 쌓이는지는 써도 된다.

| 전 | 후 |
|---|---|
| 은퇴 선수가 없습니다. 첫 번째 레전드가 되어보세요. | 은퇴 선수가 없어요. |
| 아직 조용해요. 첫 인사를 건네 보세요! | 아직 조용해요. |
| 첫 댓글을 남겨 보세요. | 아직 댓글이 없어요. |
| 아직 은퇴한 선수가 없어요. 첫 커리어를 끝까지 뛰어 보세요. | 아직 은퇴한 선수가 없어요. 커리어를 은퇴까지 마치면 여기에 올라와요. |

## 5. 게임 이벤트 결과는 장면 하나로 끝내기

결과 문장은 일어난 일을 보여 주고 끝낸다. 감정을 해석하거나 교훈을 덧붙이지 않는다.

| 전 | 후 |
|---|---|
| 골은 없었지만, 다시 뛸 수 있다는 것만으로도 충분했습니다. | 골은 없었지만 다친 곳 없이 끝까지 뛰었습니다. |
| 준우승. 눈물이 났지만, 아직 끝이 아닙니다. | 준우승. 눈물이 났지만, 결승까지 오른 경기력으로 눈도장을 받았습니다. |
| 경쟁이 당신을 더 날카롭게 만들었습니다. | 경쟁이 붙자 훈련에서 감각이 날카로워졌습니다. |
| 전 세계 축구 팬들이 당신 편에 섰습니다. | 해외 팬들 사이에서도 당신 이름이 오르내렸습니다. |

- 로그의 부가 정보는 괄호로 달지 않고 별도 문장으로 쓴다("(복무 2시즌)" → "복무 기간은 2시즌입니다.").
- 팬 반응은 실제 댓글처럼 짧고 구체적으로 쓴다("이 감격은 말로 설명이 안 된다" → "아직도 손이 떨린다.").

## 6. 바꾸면 안 되는 문구

- **엔딩 라벨**(`packages/game/src/stories.ts`의 endStory ↔ `titles.ts` STORY_ENDINGS)은 칭호 키이자
  세이브 저장값이다. 문구만 바꾸면 기존 세이브의 칭호가 끊긴다. 바꾸려면 세이브 마이그레이션과 함께 한다.
- 업적 그룹 이름처럼 게임 속 고유 명칭, SEO용 페이지 제목은 별도 결정 없이 바꾸지 않는다.

## 7. 문구를 바꿀 때 확인할 것

- 게임 문구를 바꾸면 `packages/game/src/golden.test.ts`의 스냅샷이 깨진다. 문구를 뺀 상태가 같은지 확인한
  뒤에만 스냅샷을 갱신한다(문구 말고 게임 결과가 바뀌었다면 밸런스 변경이다).
- e2e(`apps/web/e2e`)와 aria 스냅샷이 옛 문구를 확인하는 곳이 있다. 배포 전에 같이 고친다.
- 빠르게 훑는 검색:

  ```bash
  # 문자열 안의 대시(주석 줄 제외). 연도 범위·음악 크레딧·운영자 화면·내부 오류는 예외라 남아 있다.
  rg -n "['\"\`>][^'\"\`<]*\S — \S" apps/web/src apps/mobile/src packages/app-core/src packages/game/src \
    -g '!*.test.*' | rg -v ':\d+:\s*(//|\*|/\*|\{/\*)'
  # 미사여구·권유 꼬리(주석의 '여정'은 코드 용어라 걸러서 본다)
  rg -n '나만의|당신만의|여정|전 세계|빛나|되어 ?보세요|성공적으로' apps/web/src apps/mobile/src packages \
    -g '!*.test.*' | rg -v ':\d+:\s*(//|\*|/\*|\{/\*)'
  ```
