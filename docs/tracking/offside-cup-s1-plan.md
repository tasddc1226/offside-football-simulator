# T-11-145: 시즌 1 제1회 오프사이드 컵 기획

작성일: 2026-10-07 · 상태: 기획(추천값 적용, 사용자 확인 대기) · 이어받은 문서: T-11-125 초안(PR #535, 닫힘)

T-11-125 초안의 **사용자 확정 요구 R1~R5**는 그대로 두고, 초안이 "결정 필요"로 남긴 값을 운영 데이터로 정해 첫 회차를 실제로 열 수 있는 범위로 줄였다. 이 문서의 숫자는 모두 추천 기본값이고 §8 결정 목록에서 확인받는다.

## 1. 확정 요구 (T-11-125에서 이어받음)

| 번호 | 요구                                                                             |
| ---- | -------------------------------------------------------------------------------- |
| R1   | 선발 팀을 꾸린 팀만 참여한다                                                     |
| R2   | 참가 팀의 선발 선수는 이적시장 등록·방출을 못 한다                               |
| R3   | 기간 안에만 신청받고, 이후 하루 한 번 경기한다. 참가자에게 결과 앱 푸시를 보낸다 |
| R4   | 신청 → 조 추첨 → 조별 예선 → 32강 → 16강 → 8강 → 4강 → 결승                      |
| R5   | 명단 변경은 경기 시작 1시간 전까지만 된다                                        |
| -    | 서비스 시즌(시즌 1)에 귀속, 성적별 차등 보상                                     |

## 3. 대회 구성 (추천)

- **참가 자격(R1):** 시즌 1 팀, 실카드 **8명 이상**. 빈자리는 지금처럼 OVR 50 유스. 지난 시즌 카드 최대 3명 규칙도 그대로.
- **정원 64팀, 최소 48팀.** 16개 조, 조당 3~4팀(48팀이면 전부 3팀, 64팀이면 전부 4팀). 조 상위 2팀 → 32강. 정원을 넘으면 선착순.
- **미달:** 마감 시 48팀 미만이면 접수를 2일 한 번 연장. 그래도 미달이면 8개 조 → 16강으로 줄여 연다(R4의 32강을 건너뛰므로 확인 필요).
- **추첨:** 마감 시점 팀 OVR로 4개 포트(상위 16·다음 16·…)를 나눠 조마다 포트별 1팀. 시드는 서버 비공개 값, 추첨 기록 보존, 재추첨 없음.
- **조별:** 조당 풀리그 1회(3라운드). 3팀 조는 라운드마다 한 팀이 쉰다. 승 3·무 1·패 0. 동률은 승점 → 득실 → 다득점 → 승자승 → 추첨.
- **토너먼트:** 단판. 비기면 **승부차기**(신규, 양 팀 선발 슈팅·GK 능력치로 5명씩 + 서든데스, 경기 시드로 재현 가능). 3·4위전 없음.
- **중립 경기:** 컵은 홈 우대 1.08을 쓰지 않는다. 표시상 홈·원정만 있다.
- **일반 PVP와 분리:** 컵 경기는 하루 도전 횟수·레이팅·팀 전적(승무패)에 넣지 않는다.

## 4. 일정 (추천, 모두 KST)

| 단계        | 일시                                                      |
| ----------- | --------------------------------------------------------- |
| 구현·검증   | 10/8 ~ 10/12                                              |
| 접수        | 10/13(월) 00:00 ~ 10/18(토) 23:59                         |
| 조 추첨     | 10/19(일) 12:00                                           |
| 조별 1~3R   | 10/20(월) · 10/21(화) · 10/22(수)                         |
| 32강 ~ 결승 | 10/23(목) · 24(금) · 25(토) · 26(일) · **10/27(월) 결승** |

- 경기는 매일 **21:00**, 명단 마감(R5)은 **20:00**. 결승 진출팀은 8경기.
- 서버가 시각에 맞춰 알아서 치른다. 앱을 켜지 않아도 경기는 진행된다.
- 21:00 경기는 cron(5분 간격)이 21:00 이후 첫 회차에 처리한다. 결과는 늦어도 21:10 전후.
- 시즌 1 종료일이 아직 없어 10/27 안에 끝나는 일정이면 시즌 경계 문제는 없다. 시즌 1을 그 전에 닫지 않는다.

## 5. 명단과 선수 잠금 (R2·R5)

**공유 명단 + 20:00 스냅샷**을 추천한다. T-11-125의 "컵 전용 명단"보다 단순하고, 구단주가 팀을 두 벌 관리하지 않아도 된다.

1. 컵 경기는 일반 팀 명단을 그대로 쓴다. 매 경기일 20:00에 서버가 참가팀 명단을 **스냅샷**으로 저장하고, 21:00 경기는 스냅샷으로만 치른다.
2. 20:00 이후에도 일반 팀 편성은 바꿀 수 있다. 다만 그날 컵 경기에는 반영되지 않고 다음 경기부터 반영된다고 화면에 적는다. 20:00 직전 저장과 스냅샷이 겹치면 서버 시각 기준으로 하나만 반영한다.
3. **판매·방출 잠금:** 컵에서 탈락하기 전까지, ① 지금 선발에 있는 카드와 ② 아직 치르지 않은 경기 스냅샷에 든 카드는 시장 등록·방출이 막힌다. 선발에서 뺀 카드는 그날 스냅샷이 끝나면 풀린다.
4. 이미 시장에 올라간 카드는 신청할 때 선발에 둘 수 없다(신청 화면에서 안내). 신청 뒤 선발에 넣으려 하면 등록을 먼저 내려야 한다.
5. 탈락하거나 대회가 끝나면 잠금은 모두 풀린다. 보상 지급과는 묶지 않는다.
6. 잠금 검사는 시장 등록·방출 API 서버에서 한다. 화면의 사전 안내만으로 막지 않는다.

- 능력치·카드 보상은 주지 않는다. 강팀 독주가 쌓이지 않게 하려는 것이다.

- 기권(신청 뒤 팀 삭제·실카드 8명 미만으로 떨어짐)은 그 경기 0:3 패. 조별에서 기권하면 남은 경기도 0:3 패, 보상은 없다.

## 7. 화면·알림·기록

- **홈/구단 탭:** 컵 배너(접수 중 → 내 다음 경기·마감까지 남은 시간 → 결과).
- **컵 화면:** 규칙·일정·보상, 신청 버튼(자격 부족이면 이유), 조별 순위표, 대진표, 내 경기 결과(기존 팀 경기 상세 재사용 + 승부차기).
- **명단 화면:** 컵 참가 중이면 "오늘 20:00 컵 명단 마감" 띠, 잠긴 카드 자물쇠 표시.
- **푸시(R3):** 경기 결과 하루 1번(동의자만), 접수 마감 전날 1번, 추첨 결과 1번. 결과는 푸시와 상관없이 앱·웹에서 볼 수 있다.
- **웹·앱 같이:** 웹·앱 병행 정책대로 화면은 웹·앱 둘 다. 푸시만 앱 전용.
- ko/en(그리고 ja 사전이 있으면 ja) 문구를 같이 쓴다.

## 9. 구현 단위 (승인 뒤 티켓 분리)

1. **DB(마이그레이션):** `cups`, `cup_entries`, `cup_matches`(라운드·조·스냅샷·시드·결과), `cup_rewards`(유일 키). 잠금은 `cup_entries` + 스냅샷에서 계산해 별도 표 없이 검사.
2. **엔진:** 중립 경기 옵션, 승부차기(`packages` 쪽 순수 함수, 시드 재현, 단위 테스트).
3. **API:** 컵 조회·신청·철회(접수 중만), 시장 등록·방출 잠금 검사, cron 처리(20:00 스냅샷 → 21:00 경기 → 순위·진출 → 보상 → 알림), 실패 시 다음 cron이 이어서 처리(멱등).
4. **웹·앱 화면:** §7.
5. **운영:** 대회 생성은 코드 상수(`packages/contracts`의 컵 일정)로. 운영 도구 화면은 2회차부터.
6. **검증:** 64·48·미달 시나리오 시뮬, T-60 경계, 잠금 경합, cron 중복 실행, 스테이징에서 하루를 몇 분으로 줄인 리허설.

출시 전 스테이징에서 전체 대회(조별 3R + 토너먼트 5R)를 몇 분 간격으로 한 번 끝까지 돌린다.
