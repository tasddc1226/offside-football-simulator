# T-11-145: 시즌 1 제1회 오프사이드 컵 기획

작성일: 2026-10-07 · 상태: 구현(10/9 접수 시작 확정) · 이어받은 문서: T-11-125 초안(PR #535, 닫힘)

T-11-125 초안의 **사용자 확정 요구 R1~R5**는 그대로 두고, 초안이 "결정 필요"로 남긴 값을 운영 데이터로 정해 첫 회차를 실제로 열 수 있는 범위로 줄였다. 일정·보상은 사용자가 정했고(10/7), 나머지는 추천 기본값을 적용해 구현했다(§8).

## 1. 확정 요구 (T-11-125에서 이어받음)

| 번호 | 요구                                                                             |
| ---- | -------------------------------------------------------------------------------- |
| R1   | 선발 팀을 꾸린 팀만 참여한다                                                     |
| R2   | 참가 팀의 선발 선수는 이적시장 등록·방출을 못 한다                               |

| -    | 서비스 시즌(시즌 1)에 귀속, 성적별 차등 보상                                     |

## 3. 대회 구성

- **참가 자격(R1):** 시즌 1 팀, 선발 11자리 중 실카드 **8명 이상**, 선발에 시장 등록 카드 없음. 빈자리는 OVR 50 유스.
- **정원 64팀, 선착순.** 추첨 시점에 자격을 다시 본다(팀 삭제·8명 미만이면 빠지고 알림).
- **조 수는 팀 수로 정한다(`cupGroupCount`):** 32팀 이상 16개 조, 16팀 이상 8개 조, 8팀 이상 4개 조, 4팀 이상 2개 조. 조당 2~4팀, 상위 2팀이 토너먼트(32강·16강·8강·4강부터). 4팀 미만이면 취소하고 알린다. 접수 연장은 하지 않는다.
- **추첨:** 마감 시점 팀 OVR로 조 수만큼씩 포트를 나눠 포트마다 섞어 조에 한 팀씩. 시드는 서버 비공개 값(`cup_state.seed`), 한 번만 한다.
- **조별:** 조당 풀리그 1회(3라운드). 3팀 조는 라운드마다 한 팀이 쉬고, 2팀 조는 1라운드만. 승 3·무 1. 동률은 승점 → 득실 → 다득점 → (두 팀만 같으면) 승자승 → 추첨 시드.
- **토너먼트:** 단판. 첫 라운드는 홀수 조 1위 vs 짝 조 2위 식으로 같은 조 두 팀이 결승 전에 만나지 않는다. 비기면 **승부차기**(키커 ST→GK 순, 성공률 0.75 ± 키커·GK 능력 차, 5명 + 서든데스, 경기 시드로 재현). 3·4위전 없음.
- **중립 경기:** 홈 우대를 쓰지 않는다.
- **일반 PVP와 분리:** 컵 경기는 `cup_matches`에만 남고 하루 도전 횟수·레이팅·팀 전적에 넣지 않는다.
- **기권:** 경기 때 팀이 없으면 0:3 패.

## 4. 일정 (확정, KST)

| 단계        | 일시                                                            |
| ----------- | --------------------------------------------------------------- |
| 접수        | 10/9(목) 00:00 ~ 10/12(일) 23:59                                |
| 조 추첨     | 10/13(월) 12:00                                                 |
| 조별 1~3R   | 10/13(월) · 14(화) · 15(수) 21:00                               |
| 32강 ~ 결승 | 10/16(목) · 17(금) · 18(토) · 19(일) · **10/20(월) 결승** 21:00 |

- 명단 마감(R5)은 매 경기 1시간 전(20:00). 일정은 `packages/contracts/src/cup.ts`의 `CUPS` 상수.
- 경기는 5분 cron(`runCup`)이 시각이 지난 뒤 첫 회차에 치른다. 추첨 → 지난 라운드 경기 → 순위·다음 라운드 → 보상 순으로 한 번에 따라잡고, 몇 번 돌아도 결과가 같다(멱등).
- 조 수가 적으면 앞 토너먼트 라운드는 비고 그 날짜에는 경기가 없다(예: 8개 조면 32강 날 쉬고 16강부터).

## 5. 명단과 선수 잠금 (R2·R5): 잠금 방식

T-11-125의 컵 전용 명단, 첫 안의 20:00 스냅샷 대신 **경기 전후 잠금**으로 구현했다. 컵 경기는 경기 시각의 일반 팀 명단으로 치른다.

1. 참가 중인 팀은 **경기 1시간 전부터 그 경기가 끝날 때까지** 명단을 저장할 수 없다(`CUP_LINEUP_LOCKED`). 친선 명단은 상관없다.
2. 참가 중에는 실카드 8명 미만으로 줄이거나(`CUP_MIN_FILLED`) 시장 등록 카드를 선발에 넣을 수 없다(`CUP_CARD_LISTED`).
3. 지금 선발에 든 카드는 시장에 내놓을 수 없다(`CUP_CARD_LOCKED`). 방출은 원래부터 선발 카드를 막는다.
4. 탈락·취소·대회 종료면 모두 풀린다. 검사는 서버 API에서 한다.

## 6. 보상 (확정)

구단 자금은 주지 않는다. 영구 기록과 소모성 아이템 **선수 후보 리롤권**을 준다.

| 성적      | 기록                                            | 리롤권 |
| --------- | ----------------------------------------------- | ------ |
| 우승      | 우승 트로피 · 칭호 "제1회 오프사이드 컵 챔피언" | 10     |
| 준우승    | 준우승 트로피 · 칭호                            | 7      |
| 4강       | 4강 트로피 · 칭호                               | 5      |
| 8강       | 대회 기록                                       | 3      |
| 16강      | 대회 기록                                       | 2      |
| 32강      | 대회 기록                                       | 1      |
| 조별 탈락 | 참가 기록                                       | 1      |

- 기록은 `cup_entries.stage`·`rewarded_at`에 남고 팀 프로필(`cupHonors`)에 보인다.
- 리롤권은 `owner_items(profile_id, item='reroll', qty)`. 지급은 `rewarded_at IS NULL`로 막아 팀당 한 번만 한다. 탈락이 확정되는 순간 그 단계 보상을 준다.
- 리롤권 쓰기: `POST /v1/items/reroll/use`(멱등 키). 새 선수 만들 때 후보 3명을 다시 뽑는다(`rerollCandidates`).

## 7. 화면·알림·기록

- **구단 탭:** 컵 배너(접수 중 → 내 다음 경기·잠금 → 결과).
- **컵 화면:** 규칙·일정·보상, 신청·취소 버튼(자격 부족이면 이유), 조별 순위표, 대진표, 경기 결과.
- **알림:** 추첨 결과(조 배정·제외·취소)와 매 경기 결과를 알림함과 앱 푸시로. 결과는 컵 화면에서 언제든 본다.
- **웹·앱 같이.** ko/en 문구를 같이 쓴다.

## 9. 구현

- **DB(0073):** `cup_entries`, `cup_matches`, `cup_state`, `owner_items`.
- **엔진:** `simulateMatch(..., { neutral })`, `penaltyShootout`.
- **규칙:** `apps/api/src/team/cupRules.ts`(순수 함수). **진행:** `apps/api/src/team/cup.ts`의 `runCup`(5분 cron).
- **API:** `GET /v1/cups/:id`(`current` 가능), `GET /v1/cups/:id/me`, `POST /v1/cups/:id/entries`, `DELETE /v1/cups/:id/entries/me`, `GET /v1/cups/:id/matches/:matchId`, `GET /v1/items`, `POST /v1/items/reroll/use`. 명단 저장·시장 등록에 잠금 검사.
- **테스트:** 규칙 단위, 64·40·20·5팀 전체 진행·보상 멱등, 자격 미달 취소, 잠금 경계, 신청·취소·정원, 리롤권.
- 2회차부터 운영 도구 화면과 대회 상수 추가 방식을 다시 본다.
