# 시즌 경쟁 · 보상 · 승계 정책

기준일: 2026-10-10. 시즌 보상과 다음 시즌 승계의 기준 문서다.
시즌 결산·컵 보상은 main 구현 기준이며, 통합 명예관·영구 칭호는 PR #563에 포함된다.
PR에 구현됐다는 사실과 운영 배포 완료는 구분한다. 이 문서를 추가하면서 보상 수량·등급 문턱·경제 규칙을 바꾸지 않는다.

## 1. 보상 원칙과 용어

- **시즌 업적 등급:** 그 시즌 업적 점수의 절대 구간. 시즌 종료 때 확정되어 다음 시즌의 지난 시즌 등급으로 표시된다.
- **시즌 기록 배지:** 마감 순위나 달성 기록을 기념하는 영구 기록. 업적 등급과 별개다.
- **영구 칭호:** 여러 시즌의 직접 육성 기록 또는 확정된 최초 기록 배지로 얻는 계정 단위 목표. 대표 칭호 하나를 선택한다.
- **컵 성적·칭호:** 대회별 최종 성적과 4강 이상 기념 칭호. 소모성 리롤권도 지급한다.
- 시즌 랭킹·영구 칭호는 능력치·성장률·잠재력·레전드 점수·구단 자금을 가산하지 않는다.
- 이미 확정된 기록을 새로운 계산식으로 다시 평가하지 않는다. 신규 기준은 적용 시즌·조건 버전을 명시한다.

## 2. 시즌 경쟁과 보상

| 경쟁·달성                          | 마감 기준                                           | 보상                                               | 지급 시점           | 유지·노출                             |
| ---------------------------------- | --------------------------------------------------- | -------------------------------------------------- | ------------------- | ------------------------------------- |
| 구단주 업적 랭킹                   | 시즌 업적 점수, 동점은 달성 시각·구단주 ID 순       | 1위 / TOP 10 / TOP 100 배지                        | 시즌 마감 집계 완료 | 시즌 기록으로 영구 보관               |
| 팀 레이팅 랭킹                     | 레이팅, OVR, 팀 생성 시각·ID 순                     | 1위 / TOP 10 / TOP 50 배지                         | 시즌 마감 집계 완료 | 시즌 기록으로 영구 보관               |
| 명예의 전당                        | 마감 전 은퇴한 공개 적격 선수의 LS, 은퇴 시각·ID 순 | 내 선수 최고 순위 기준 1위 / TOP 10 / TOP 100 배지 | 시즌 마감 집계 완료 | 선수 기록과 해당 시즌 배지 유지       |
| 시즌 완주                          | 마감 전 은퇴 선수 1명 이상                          | 프리시즌 개척자 / 시즌 N 완주 배지와 은퇴 수       | 시즌 마감 집계 완료 | 영구 보관                             |
| 영구결번·명예의 벽·서버 최초 기록  | 마감 기준 달성 개수                                 | 종류별 기록 배지                                   | 시즌 마감 집계 완료 | 영구 보관                             |
| 구단 가치·팀 OVR 등 다른 정렬 순위 | 해당 화면의 조회 기준                               | 별도 시즌 순위 보상 없음                           | 해당 없음           | 조회 순위와 보상 순위를 혼동하지 않음 |

각 종류마다 해당하는 가장 높은 단계 하나를 지급한다. 예: 업적 7위 → TOP 10 배지, 실제 순위 7위 저장.
순위 배지의 팀·업적 대상은 Google 또는 Apple 계정이 연결된 미삭제 구단주이며, 팀은 선수가 있는 팀, 업적은 0점 초과다.
명예의 전당은 해당 시즌 공개 적격 선수 기준이고 구단주마다 가장 높은 선수 순위를 사용한다.
전체·포지션별·다른 정렬 화면의 순위가 각각 별도의 배지를 만드는 것은 아니다.

근거: `packages/contracts/src/season-recap.ts`의 `HONOR_BANDS`, `apps/api/src/team/seasonClose.ts`.

## 3. 지난 시즌 등급

| 등급     | 마감 업적 점수 |
| -------- | -------------: |
| 루키     |         0 이상 |
| 브론즈   |       200 이상 |
| 실버     |       500 이상 |
| 골드     |     1,000 이상 |
| 플래티넘 |     1,600 이상 |
| 다이아   |     2,400 이상 |
| 레전드   |     3,500 이상 |

- 상대 순위나 컵 성적을 섞지 않고 업적 점수만 사용한다.
- 시즌 2에는 시즌 1, 시즌 3에는 시즌 2의 마감 등급을 표시한다. 가장 높았던 시즌을 계속 표시하는 방식이 아니다.
- 가장 최근 종료 시즌의 집계가 끝나지 않았거나 그 구단주의 결산 기록이 없으면 지난 시즌 등급은 없다.
- 프로필·구단주 화면·댓글·채팅에서 쓰며, 기존 채팅은 보낸 때의 등급이 기록될 수 있다.
- 과거 시즌의 등급과 배지는 명예관 시즌 기록에 남는다.

근거: `owner-team.ts`의 `ACH_GRADES`, `owner-tier.ts`, API `db/repos/ownerTiers.ts`.

## 4. 컵과 승부예측

| 최종 성적 | 리롤권 | 기록·칭호               |
| --------- | -----: | ----------------------- |
| 우승      |     10 | 영구 우승 트로피·칭호   |
| 준우승    |      7 | 영구 준우승 트로피·칭호 |
| 4강       |      5 | 영구 4강 트로피·칭호    |
| 8강       |      3 | 대회 성적               |
| 16강      |      2 | 대회 성적               |
| 32강      |      1 | 대회 성적               |
| 조별 탈락 |      1 | 참가 성적               |

- 탈락 또는 우승이 확정되면 최종 단계 보상을 한 번 지급한다. 라운드별 누적 지급이나 시즌 마감 추가 지급이 아니다.
- 구단 자금을 지급하지 않는다. 컵 성적은 `cup_entries`에 저장하며 시즌 순위 배지의 `owner_honors`와 구분한다.
- 승부예측은 적중 경기마다 리롤권 1장. 대회 참가 여부와 별개이며 현재 대회별 지급 상한은 없다.
- 미사용 리롤권은 계정에 남으며 다음 시즌에도 사용할 수 있다. 이미 지급된 보상의 재지급은 지급 원장으로 막는다.

근거: `packages/contracts/src/cup.ts`, `apps/api/src/team/cup.ts`, `cupPredictions.ts`.
확정된 컵 설계는 [컵 기획 §6](offside-cup-s1-plan.md#6-보상-확정)를 따른다. 옛 시즌 결산 문서의 소액 자금 보상 제안은 채택되지 않았다.

## 6. 통합 명예관 (#563)

구단주 → 명예관을 개인 기록의 단일 진입점으로 한다. 구단주 허브의 별도 시즌 결산 카드는 제거한다.

- **시즌 기록:** 누적 은퇴·영구결번·배지 수, 시즌별 업적 점수·팀 순위, 시즌 등급·배지와 컵 성적.
- **상세 기록:** 선택한 마감 시즌의 선수단·통계·대표 선수·최종 순위·공유 이미지. 기존 확정 결산 데이터와 공유 코드를 재사용한다.
- **칭호:** 컵·영구 칭호와 진행도, 대표 칭호 선택. 선택한 칭호의 적용 위치는 기존 규칙을 따른다.
- 진행 중 기록, 마감 집계 중, 확정 기록을 구분한다. 집계 중인 점수를 최종 점수로 노출하지 않는다.
- 오래된 `recap` 진입은 명예관으로 연결한다. 결산 API·저장 테이블은 구버전 호환과 확정 기록 보존을 위해 유지한다.
- 요약은 명예관을 열 때 한 번, 상세는 해당 시즌을 펼칠 때만 조회한다. 시즌 수만큼 상세 API를 미리 호출하지 않는다.
- 모바일 작은 화면에서 줄바꿈·44px 이상 조작 영역·뒤로가기·하단 메뉴를 확인한다. 움직임 줄이기 설정을 존중한다.

## 7. 변경과 검증

정책 변경 시 이 문서·계약 상수·지급 코드·ko/en/ja 문구를 함께 검토한다.
과거 지급분 소급 변경, 조건 완화·강화, 회수는 별도 결정과 이력 없이는 수행하지 않는다.
조회 화면 개편은 순위 계산, 지급 수량, 과거 스냅샷을 변경하는 근거가 되지 않는다.

현재 문서의 확정 정책과 향후 제안은 구분한다. 컵 성적의 시즌 등급 합산, 상위권 추가 자금, 능력치 보상은 현행 정책이 아니다.
