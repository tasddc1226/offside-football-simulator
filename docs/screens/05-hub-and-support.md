# 화면 명세 05. 커리어 대시보드·핵심 경기 챕터·보조 화면

이 문서는 검토에서 누락으로 확인된 화면을 추가한다. 커리어 대시보드는 제품 설계서 11.2절의 "공간형 UI"를 구현하는 화면이며, 결정 자체는 여전히 한 화면에 하나만 둔다.

## SCR-029 커리어 대시보드

- **목적**: 진행 중인 커리어의 현재 상태를 한 공간에서 보고 다음 결정으로 들어간다.
- **진입**: ACTIVE Career의 마지막 checkpoint 복원. SCR-010 사인 완료, 결과 카드의 다음, 허브의 이어하기.
- **표시**: PlayerHeader, StatusStrip, 현재 step과 SeasonTimeline, 다음 결정 카드, 다섯 구역 탭.
- **구역**:

| 구역 | 내용 | 열리는 화면 |
|---|---|---|
| 일정표 | 현재 step, 다음 결정, 시즌 목표 | advance, SCR-031 |
| 라커룸 | 감독·주장·경쟁자·동료 관계 요약, 최근 기억 태그 | SCR-018 |
| 전술실 | 감독 전술, 역할, 전술 적합도, 주전 경쟁 순위, 능력치 상세 | SCR-012, SCR-033 |
| 휴대폰 | 계약 상태, 제안, 루머, 언론·SNS, 에이전트 | SCR-017, SCR-019, SCR-024 |
| 다이어리 | 이번 시즌 연대기, 리플레이 가능한 확정 결과 | SCR-027 |

- **동작**: 다음 결정으로, 진행(advance), 구역 전환, 설정.
- **이탈**: 서버가 반환한 nextAction 화면. 결정이 없으면 advance 후 다시 대시보드.
- **예외**: 결정이 여러 개면 가장 긴급한 카드 하나만 CTA로 두고 나머지는 목록. 응답 유실 시 commandId로 복구.
- **점진 공개**: U18 구간에서는 전술실·휴대폰 탭을 잠그고 첫 프로 계약 후 연다. 라커룸의 관계 숫자는 Phase 4 콘텐츠가 열릴 때까지 기억 태그만 보여준다.
- **인수 조건**: 대시보드에서 어떤 결정도 확정되지 않는다. 확정은 항상 전용 결정 화면에서 일어난다.

## SCR-030 설정·데이터

- **목적**: 접근성 설정과 데이터 권리를 한 곳에서 처리한다.
- **진입**: 허브와 대시보드의 설정 아이콘.
- **표시**: 모션 감소, 텍스트 크기, 테마, 복구 코드, Google 연결 상태, 동기화 상태, 데이터 내보내기, 삭제, 규칙·콘텐츠 버전. (시뮬레이션 기본 모드 항목은 2026-09-13 D-77 결정으로 제거됐다 — 모든 시즌은 항상 FAST로 시작한다.)
- **동작**: 설정 변경(즉시 저장), 복구 코드 다시 보기·재발급, 프로필 복구(코드 입력), Google로 연결·연결 해제, 병합 선택(`MERGE_REQUIRED` 시), 지금 동기화, 내보내기, 삭제(2단계 확인).
- **이탈**: 이전 화면.
- **예외**: 복구 코드 재발급은 이전 코드를 무효화하며 그 사실을 먼저 알린다. 삭제는 Career·Player·Contract·Archive를 추적 가능하게 삭제한다.
- **채널**: toss에서는 Google 연결·연결 해제·병합 항목을 숨기고 "토스 계정으로 자동 저장 중" 상태를 보여준다. 복구 코드 발급·입력은 두 채널 모두 제공해 web↔toss 이동을 지원한다. 웹 버전으로 유도하는 링크는 두지 않는다(앱인토스 정책). 약관·개인정보 처리방침은 두 채널 모두 앱 안 라우트로 연다.
- **인수 조건**: 모션 감소를 켜면 모든 카운트업과 라인 연출이 즉시 완료된다. 복구 코드로 다른 브라우저에서 같은 프로필을 복원한다. toss 채널에서 발급한 복구 코드로 web에서 같은 커리어를 연다.

## SCR-031 핵심 경기 챕터

- **목적**: 커리어 의미가 큰 경기 하나를 선택형 장면으로 플레이한다.
- **진입**: advance가 챕터가 열린 step에 도달. 챕터 생성 조건은 [시뮬레이션 엔진](../development/03-game-simulation-engine.md)의 핵심 경기 선택을 따른다.
- **표시**: 왜 이 경기인가(데뷔전, 더비, 결정전 등), 상대와 대회, 선발 여부와 이유(RULE-SEL-001), 감독 지시, 스코어보드.
- **흐름**:
  1. 경기 전 맥락과 선발 판정.
  2. 경기 중 판단 1~3개. 각 판단은 SCR-013과 같은 ChoiceCard 계약을 쓰되 시간·스코어·체력·지시가 함께 보인다.
  3. 경기 결과와 개인 기록, 폼·평판·감독 신뢰·태그 변화.
- **동작**: 판단 선택·확정, 결과 다음. 벤치라면 교체 투입 판단 또는 관전만 가능.
- **이탈**: 결과 확정 후 대시보드 또는 다음 결정.
- **예외**: 선발 제외 챕터도 유효한 장면이어야 한다. 부상으로 이탈하면 남은 판단은 열리지 않는다. 새로고침은 확정된 판단까지 재생한다.
- **중요도**: `MAJOR`(데뷔전, 결승, 승격·강등 결정전, 대표팀 데뷔)와 `MINOR`(더비, 친정팀, 경쟁자 복귀). FAST 모드는 MAJOR만 연다.
- **인수 조건**: 같은 챕터의 판단은 포지션에 따라 다른 선택지를 받는다. 판단마다 roll은 정확히 한 번 소비된다.

## SCR-032 대표팀 차출

- **목적**: 소집 참가와 클럽 잔류의 대가를 비교한다.
- **진입**: step 8 소집 창에서 국적 규칙 모듈이 자격을 판정.
- **표시**: 대회 종류, 예상 출전, 체력 비용, 클럽 감독 반응, 명성·태그 영향, 국적별 특례(예: 병역) 여부.
- **동작**: 참가, 사양, 조건부 참가.
- **이탈**: NAT Effect와 후속 챕터(대표팀 데뷔) 예약 후 대시보드.
- **예외**: 부상 중이면 자동 사양하고 이유를 남긴다. 사양은 감독 신뢰가 아니라 협회·팬 관계에 작용한다.
- **인수 조건**: 국적 규칙 모듈이 없는 국적은 기본 모듈로 동작하며 특례 항목이 표시되지 않는다.

## SCR-033 능력치 상세

- **목적**: Base OVR을 구성하는 세부 능력과 변화 원인을 본다.
- **진입**: 대시보드 전술실, 시즌 결과의 변화 상세.
- **표시**: 기술·신체·정신 묶음, 세부 능력 현재값과 시즌 변화, 역할 가중치, 포지션 숙련도, 정찰 범위, 최근 변화 원인 태그.
- **동작**: 역할별 OVR 미리보기 전환, 시즌 비교.
- **이탈**: 이전 화면.
- **예외**: 잠재력 실제 값은 절대 노출하지 않는다. 미집계 값은 `—`로 표시한다.
- **인수 조건**: 표시된 세부 능력과 역할 가중치로 계산한 값이 Base OVR과 일치한다.

## SCR-034 온보딩

- **목적**: 첫 방문자가 OVR 하나가 아닌 여러 수치를 단계적으로 이해하게 한다.
- **진입**: 커리어가 없는 첫 방문. 설정에서 다시 보기 가능.
- **표시**: 3장 이내. 대표 문장, 선택은 되돌릴 수 없고 위험은 미리 보인다는 규칙, 복구 코드의 의미.
- **동작**: 다음, 건너뛰기, KICKOFF.
- **이탈**: SCR-002 선수 생성.
- **점진 공개 규칙**:

| 구간 | 노출 수치 |
|---|---|
| U18 | Base OVR, 폼, 체력 |
| 첫 프로 계약 이후 | 전술 적합도, 감독 신뢰, 경기 예상치 |
| Phase 4 콘텐츠 이후 | 사기, 관계 수치 |

- **예외**: 건너뛰기해도 각 수치가 처음 열리는 순간 한 줄 설명을 한 번 보여준다.
- **인수 조건**: 온보딩을 건너뛴 사용자도 첫 프로 계약까지 5분 이내에 도달한다.

## SCR-023 보충: 포지션 전용 이벤트의 두 변형

SCR-023은 하나의 ID로 두 변형을 가진다. 제품 설계서 Screen 23과 화면 명세 03이 서로 다른 화면을 가리키던 문제를 이 정의로 닫는다.

| 변형 | 내용 | 열리는 곳 | Phase |
|---|---|---|---:|
| 경기 판단 | 역할에 맞는 경기 중 선택(공격수 돌파·연결·공간 창출, GK 빌드업·롱킥) | SCR-031 챕터 안 | 4 |
| 성장 이슈 | 결정력·반응·스피드 저하 같은 포지션 고유 능력 추세에 대한 훈련·역할 대응 | 시즌 준비, 결산 후 | 5 |

두 변형 모두 같은 원인으로 OVR과 세부 능력을 이중 차감하지 않는다.
