# 화면 명세 01. 커리어 시작과 첫 계약

## SCR-001 홈·커리어 허브

- **목적**: 새 커리어를 시작하거나 기존·은퇴 선수를 재개/열람한다.
- **진입**: 익명 프로필 복원 완료.
- **표시**: 활성 Career 카드, 선수 보관함, 현재 서비스 시즌, 전환 공지.
- **동작**: 새 커리어, 이어하기(SCR-029로), 리플레이, 보관함, 시즌 도전, 설정(SCR-030).
- **이탈**: 이어하기는 SCR-029 커리어 대시보드. 그 외는 Career 상태가 요구하는 최근 안전 화면.
- **예외**: 커리어 없음은 SCR-034 온보딩 후 KICKOFF CTA, 복구 실패는 복구 코드 입력 안내.
- **인수 조건**: 다른 시즌 ruleset Career 카드가 섞여도 각각 올바른 버전으로 열린다.

## SCR-002 선수 생성

- **목적**: 이름, 생년, 국적, 주발, 포지션군·세부 포지션, 배경을 입력한다.
- **진입**: DRAFT Career와 service/ruleset/content 버전 생성 완료.
- **표시**: 입력 규칙, 포지션 설명, 진행 단계.
- **동작**: 입력 수정, 임시 저장, 다음.
- **이탈**: 유효한 DRAFT를 SCR-003으로 전달한다.
- **예외**: 2~12자 이름, 허용 국적·포지션, 중복 제출을 서버에서 검증한다.
- **인수 조건**: 오류 후 입력과 포커스 문맥이 보존된다.

## SCR-003 플레이 스타일·아키타입

- **목적**: 포지션에 맞는 역할과 명시적 강점·약점을 고른다.
- **표시**: 포지션별 3개 아키타입, 핵심 능력, 약점, 예상 역할.
- **동작**: 카드 비교, 하나 선택, 이전/다음.
- **규칙**: 잠재력 실제 값과 최종 OVR을 미리 공개하지 않는다.
- **이탈**: 선택을 DRAFT에 저장하고 SCR-004로 이동한다.
- **인수 조건**: 포지션 변경 후 유효하지 않은 기존 아키타입이 자동 확정되지 않는다.

## SCR-004 생성 완료 확인

- **목적**: 영구 생성 전에 선수 정체성과 초기 능력 요약을 확인한다.
- **표시**: 이름·포지션·아키타입·주발·배경, 예상 강점, 규칙 버전.
- **동작**: 수정, `KICKOFF` 확정.
- **이탈**: API-CAR-005 성공 후 초기 Snapshot을 만들고, 프로필에 복구 코드가 없으면 발급 화면을 한 번 거쳐 SCR-007로 이동한다.
- **복구 코드 발급**: 코드 원문을 한 번만 보여주고 복사·저장을 유도한다. "이 코드가 없으면 다른 기기에서 복구할 수 없습니다"를 명시한다. 건너뛰기를 허용하되 설정에서 다시 발급할 수 있음을 알린다.
- **예외**: COMMITTING 중 CTA 잠금, 응답 유실 시 commandId로 결과 복구.
- **인수 조건**: 확정을 반복해도 능력 seed와 Career가 한 번만 만들어진다. 복구 코드 발급 여부가 Career 생성 결과를 바꾸지 않는다.

## SCR-007 졸업 후 진로 선택

- **목적**: 프로 직행, 아카데미 잔류, 대학/하부 경로의 성장과 위험을 비교한다.
- **표시**: 예상 성장, 입단 기회, 시간 비용, 현재 정찰 범위.
- **동작**: 경로 하나 선택·확정.
- **이탈**: 관련 Effect와 이벤트 pool을 저장하고 SCR-008 또는 SCR-009로 이동한다.
- **인수 조건**: 최적 답 하나가 되지 않도록 각 경로가 다른 이점을 가진다.

## SCR-008 입단 테스트 진행

- **목적**: 테스트 결과를 기다리는 긴장감은 주되 결과 데이터는 한 번만 확정한다.
- **표시**: 단계 진행, 평가 항목, 취소 불가 안내.
- **동작**: 모션 감소 시 즉시 결과 보기, 일반 모드에서 건너뛰기.
- **이탈**: 이미 저장된 결과를 SCR-009에서 표시한다.
- **인수 조건**: 새로고침·건너뛰기가 결과를 바꾸지 않는다.

## SCR-009 첫 프로 제안 결과

- **목적**: 제안 구단과 예상 역할을 OVR 순위가 아닌 맥락으로 비교한다.
- **표시**: 기간, 급여, 역할, 전술 적합도, 경쟁자 수, 출전 약속.
- **동작**: 제안 상세, 선택, 안전한 대안.
- **이탈**: 선택한 offer를 SCR-010으로 전달한다.
- **예외**: 제안 없음은 재테스트/하부 경로를 제공한다.
- **인수 조건**: 숨은 필드가 아니라 표시된 조건이 계약 결과와 일치한다.

## SCR-010 신인 계약 사인

- **목적**: 최종 계약 조건과 책임을 확인한다.
- **표시**: 기간, 급여, 보너스, 역할, 등번호, 출전 약속.
- **동작**: 사인, 뒤로.
- **이탈**: Contract·Team·Timeline을 원자 저장하고 SCR-029 커리어 대시보드로 이동한다.
- **우선순위 처리**: 손글씨 사인 캔버스는 P2다. Phase 1은 이름 자동 서명만 제공하며, 캔버스가 없어도 화면 계약과 저장 필드(`signatureType: 'AUTO'`)는 동일하다.
- **인수 조건**: 사인 이후 뒤로 가도 계약이 재생성되지 않는다.
