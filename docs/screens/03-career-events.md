# 화면 명세 03. 계약·관계·부상 이벤트

## SCR-016 윤리·위기 이벤트

- 목적: 평판·팀 규율·개인 원칙의 대가를 선택한다.
- 표시: 확인된 사실과 소문, 위험, 지원 가능한 인물.
- 동작: 해명, 침묵, 구단/에이전트 지원 등.
- 인수: 한 번의 실패로 진행 불가 상태를 만들지 않고 결과 원인을 설명한다.

## SCR-017 계약 만료·FA

- 목적: 잔류, 사전 협상, 자유계약의 조건을 비교한다.
- 표시: 잔여 기간, 현재 역할, 예상 시장, 구단 신뢰.
- 동작: 재계약, 시장 탐색, 시즌 후 결정.
- 인수: 계약 만료 6개월 전과 종료 후 허용 동작이 다르며 서버가 검증한다.

## SCR-018 라커룸 관계

- 목적: 주장·동료·경쟁자와의 갈등/협력을 선택한다.
- 표시: 관계 방향, 최근 기억 태그, 경기·출전에 미칠 맥락 효과.
- 동작: 직접 대화, 주장 중재, 훈련 집중.
- 인수: 관계 변화가 OVR을 직접 바꾸지 않고 source가 남는다.

## SCR-019 이적 루머·관심

- 목적: 공식 제안 전 관심과 대응 전략을 정한다.
- 표시: 신뢰도, 예상 역할, 현 구단 반응, 시장가치 영향.
- 동작: 관심 표명, 침묵, 잔류 선언.
- 인수: 루머와 확정 offer를 시각·데이터상 구분한다.

## SCR-020 이적·임대 결과

- 목적: 새 팀·역할·계약과 남겨진 관계를 결산한다.
- 표시: 이전/새 팀, 계약, 전술, 경쟁자, 관계 변화.
- 동작: 상세 계약, 새 팀 프리시즌.
- 인수: 결과는 원자 저장되고 뒤로 가도 재협상되지 않는다.

## SCR-021 슬럼프 대응

- 목적: 단기 폼 회복과 장기 신뢰·출전 기회의 대가를 고른다.
- 표시: 최근 5경기, 원인 후보, 감독 기대, 선택별 시간 비용.
- 동작: 추가 훈련, 휴식, 역할 단순화, 면담.
- 인수: 슬럼프가 Base OVR 직접 감소로 표현되지 않는다.

## SCR-022 부상·재활 대응

- 목적: 조기 복귀와 단계 재활의 위험을 비교한다.
- 표시: 진단, 예상 복귀 범위, 재발 위험, 주요 일정, Fitness.
- 동작: 조기 복귀, 표준 재활, 보수적 재활.
- 인수: 영구 능력 변화는 재활/재발 결과 확정 후에만 발생한다.

## SCR-023 포지션 전용 경기 이벤트

- 목적: 역할에 맞는 축구 판단을 선택한다.
- 표시: 시간·스코어·체력·전술 지시, 포지션별 선택.
- 동작 예: 공격수 직접 돌파/연결/공간 창출, GK 빌드업/롱킥.
- 인수: 같은 장면이 모든 포지션에 동일 선택지로 나오지 않는다.

## SCR-024 SNS·평판 이벤트

- 목적: 팬·언론·구단 반응을 관리한다.
- 표시: 공개 범위, 예상 팬/감독 영향, 사실 여부.
- 동작: 게시, 수정, 침묵, 에이전트 대응.
- 인수: 실제 외부 SNS 전송 없이 게임 내부 결과로만 처리한다.
