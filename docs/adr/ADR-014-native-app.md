# ADR-014: 네이티브 앱(Expo)과 게임 엔진 공용 패키지

- 상태: 확정 (2026-09-30)
- 관련: ADR-013(풀타임 전면 교체)

## 배경

클라이언트가 웹(Svelte 5 SPA) 하나뿐이다. App Store·Google Play에 온전한 네이티브 앱을 내기로 했다.
게임은 전부 클라이언트에서 돌고(ADR-013), 엔진은 순수 TS 약 1만 줄이다. 밸런스 조정·세이브 마이그레이션·
결정성 골든 스냅샷이 엔진 한 벌을 전제로 한다.

## 결정

1. **스택은 Expo(React Native)다.** 화면은 네이티브 컴포넌트로 새로 만들고, 빌드·서명·스토어 제출은 EAS로 한다.
   - Swift·Kotlin을 따로 만들면 엔진을 두 번 옮기고 밸런스 변경마다 세 벌을 맞춰야 해서 기각했다.
   - 웹을 감싸는 방식(Capacitor)은 '온전한 네이티브'가 아니고 앱스토어 4.2(최소 기능) 거절 위험이 있어 기각했다.
2. **게임 엔진은 `packages/game`(`@offside/game`)으로 옮겨 웹·앱·`tooling/fulltime-sim`이 함께 쓴다.**
   - 엔진은 브라우저 전역을 쓰지 않는다. 세이브 저장소만 `setStorage`로 주입한다(웹은 기본값 `localStorage`, 앱은 MMKV 같은 동기 저장소).
   - 플레이 신호(DOM 조작 횟수)처럼 플랫폼에 붙은 코드는 각 앱에 둔다.
   - 의존 방향: `@offside/game` → `@offside/contracts`만. `@offside/web`·앱 → `@offside/game`.
   - 엔진은 `crypto.randomUUID`(커리어 id)를 쓴다. 앱은 진입점에서 폴리필(expo-crypto)을 깐다.
3. **클라이언트 공용 층은 `packages/app-core`(`@offside/app-core`)다(T-11-002).** 화면 프레임워크를 모르는 TS다.
   - 앱 상태의 모양·처음 값(`state`), 시트 뷰 모델(`sheets`), 시트 연출(`sheet-controller`: 진행 단계·경기 중계·판정·미니게임),
     게임 진행 액션(`game-actions`: 구간 진행·이벤트·시즌 결산·이적 시장·은퇴·새 커리어), 업로드 본문·큐(`upload`·`outbox`),
     표시 형식(`format`) 같은 순수 헬퍼를 둔다.
   - 반응성은 클라이언트가 붙인다. 웹은 상태를 Svelte `$state`로 감싸 넘기고, 앱은 자기 프록시 스토어로 감싸 넘긴다.
     공용 코드는 넘겨받은 객체를 그대로 고친다(웹 원본과 같은 변경 순서 → 같은 RNG 소비 순서).
   - 저장·토스트·스크롤·분석·업로드 큐 불러오기는 `GameHost`로, 포커스·그리기 대기는 `SheetUi`로, 서버 주소·인증(웹 쿠키 /
     앱 Bearer)·UI 알림은 `configureOutbox`로 넣는다.
   - 의존 방향: `@offside/app-core` → `@offside/game`·`@offside/contracts`. 웹·앱 → `@offside/app-core`.
4. **v1 범위는 웹과 같은 기능이다.** 화면을 모두 옮긴 뒤 출시한다.
   - 2026-10-04 덧붙임(T-11-084): 결제(IAP)·푸시·보상형 광고는 앱 전용이다. 앱이 출시돼도 웹은 유지하며 게임 기능은 웹·앱에 함께 낸다([결정 로그](../tracking/decision-log.md)).
5. **로그인은 앱에서도 구글을 유지하고 Apple로 로그인을 더한다**(앱스토어 가이드라인 4.8). 앱은 쿠키 대신 토큰 세션을 쓴다.
   계정 삭제는 앱 안에서 할 수 있어야 한다(가이드라인 5.1.1(v), `/v1/profile/delete`).

## 결과

- 세이브 호환·골든 스냅샷·밸런스 규칙은 `packages/game/src` 기준으로 그대로 적용된다.
- 앱은 웹과 같은 세이브 포맷을 쓰므로 백업 코드·계정으로 기기 간 이동이 된다.
- Google Play 개인 계정은 정식 출시 전에 테스터 12명 이상이 14일 동안 비공개 테스트를 해야 할 수 있다. 일정에 넣는다.
