# 시즌 1 게임성 개선 배포 — 2026-09-06

근거: [운영 3회 평가](../qa/2026-09-06-production-three-runs/README.md).
사용자는 평가에서 발견한 부분의 개선과 운영 배포를 승인했다. 코드 작업은 Sol 에이전트가 분담하고,
주 에이전트가 변경 검토·통합 검증·배포를 담당한다.

## 버전과 적용 범위

- 신규 커리어: 규칙 **1.3.0**, 콘텐츠 **0.5.0**, 시작 나이 **19세**.
- 기존 선수: 생성 당시 규칙/콘텐츠, 나이, 명령, 저장 해시, 기록을 보존한다. 밸런스를 소급 변경하지 않는다.
- `svc_season_1`, 표시명 시즌 1, ACTIVE, `isTest=false`, 시작 `2026-09-05T15:00:00Z`, 종료일 미정을 유지한다.
- 기존 미배포 19세 시작·배경별 도입·허브/선수 홈 탭·등록/시즌 시작 연출·브랜드 부제를 함께 통합한다.
- 이전 로컬 버전 1.2.0/0.4.0/0.4.1은 로컬 선수 호환을 위해 남기며 운영 시즌의 중간 버전으로 활성화하지 않는다.
- 도메인 구매는 완료되지 않았다. 이번 배포는 기존 workers.dev 웹/API 주소를 사용한다.
  새 도메인 연결, OAuth 주소 이전, 검색 인덱싱 활성화는 이번에 실행하지 않는다.

## 개선 내용

1. 새 규칙에서 유소년 고정 첫 계약 경로는 성인 3부 기회로 연결한다. 연령을 넘긴 유스 선수의 재계약도 막는다.
2. 두 시즌 연속 0분 출전이면 기존 잔류 옵션과 별도로 하부리그 기회를 제공한다.
   계약이 남았다면 임대, 만료됐다면 자유계약 조건을 사용한다. 정상 선발 경쟁은 유지하므로 출전 보장이 아니다.
3. 보수 재활로 낮춘 재발 위험을 다음 재발에 이어 적용하고, 같은 부위의 연속 재발 사슬을 제한한다.
   독립적인 새 부상까지 없애거나 과거 규칙을 변경하지 않는다.
4. 새 도입부는 배경별 첫 사건/후속 사건을 사용한다. 공통 사건의 윙어 고정 문구·보상을 정리하고,
   계약 전 선수를 U18 소속인 것처럼 표시하지 않는다.
5. 허브는 이어하기/선수단/은퇴 기록, 선수 홈은 홈/일정/선수/계약/기록으로 분리한다.
   실제 저장된 나이·시즌을 강조하고, 등록과 시즌 시작의 저장 성공 뒤 짧은 전환 연출을 제공한다.
   건너뛰기·동작 줄이기·키보드 경로를 유지한다.
6. Legacy 1.1 점수 계산을 유지한다. 새 규칙의 검증된 기준 모집단이 없으므로 상대 백분위는 숨긴다.
   기존 버전의 기준 모집단을 새 버전 표본이라고 바꾸지 않는다.

## 저장과 배포 안전성

기존 운영 1.1.0/0.3.0의 아직 업로드되지 않은 선수를 위해, 시즌 1에서만 기존 쌍과 신규 쌍을
명시적으로 허용한다. 서로 섞은 버전이나 임의 시즌·다른 과거 버전은 허용하지 않는다.
서버가 이미 가진 선수는 기존 소유권·명령 재생 검사를 계속 거친다.

배포 순서: 정확한 main SHA 및 시즌 메타데이터 검사 → D1 복구 북마크/건수 확인 →
호환 API 배포 → 신규 웹 배포 → 정확한 구버전에서만 시즌 manifest 비교 후 변경(CAS) → readback/health/CORS 검증.
시즌을 새로 만들거나 사용자 기록을 초기화하지 않는다. 역전환 SQL은 진단 산출물이며 자동 실행하지 않는다.
새 선수가 생긴 뒤 호환 코드를 제거하는 구버전 Worker 롤백이나 DB 시점 복원은 안전한 기본 복구가 아니다.

## 검증 기록

- 웹 관련 기존/변경 단위 검사 104개 통과, SEO 검사 3개 통과.
- 도메인 기존 전체 검사 921개 통과. 이후 수정한 회복 정책은 offers/injury/market 집중 검사 80개로 재검증했다.
- API 은퇴 및 시즌 호환 검사 12개, 배포 guard 검사 8개 통과.
- 콘텐츠 집중 검사 31개, 현재 소속 표시 3개, 회복 기회 안내를 포함한 제안 화면 검사 3개 통과.
- 전체 lint, 타입 검사, 콘텐츠 체크섬 검사, 웹 빌드 및 초기 번들 예산 검증 통과.
- 신규 1.3.0/0.5.0 브라우저 E2E: 19세 생성 → 성인 계약 → 첫 시즌 결산 → 20세, 통과.
  키보드 전용 E2E도 통과. E2E는 서비스 시즌/동기화 응답을 대체하며 실제 클라이언트 엔진을 실행한다.
- 직접 로컬 브라우저에서 `개선검증GK`(여성/GK/학교 배경)를 생성하고 19세·1.3.0/0.5.0 확인 →
  학교팀 출발 이야기 → 성인 훈련 후속 → 3부 갈매 타운 FC 계약을 확인했다.
  별도 실제 로컬 API GET 200, revision 10, ACTIVE, 19세, 갈매 타운 FC, 신규 규칙/팩 저장도 확인했다.
- 로컬 QA는 `svc_gameplay_recovery_qa`, API 8798, 웹 5201이다. 운영과 별도이며 기존 로컬 선수도 삭제하지 않았다.

## 남은 한계

이번 개선은 특정 실패 경로와 첫 플레이 품질에 집중한다. 자연 은퇴까지의 대규모 엔딩 분포,
모든 성별의 별도 리그 체계, 전체 해외 커리어, 실제 사용자 평균 엔딩 시간 검증 완료를 의미하지 않는다.
통계 분석에서는 이전 QA 3건과 배포 확인용 QA를 일반 사용자 표본과 구분한다.
