# PRD — 리그 속에서 기억되는 선수 커리어

- 작성: 2026-09-14
- 상태: 검토 가능한 제품 제안. 문서 작성 요청을 반영했으며 구현·운영 활성화 완료를 뜻하지 않는다.
- 기준: main `cb6d2995c127a225a0cb926830ed47d808424ddd`
- 연결: [ADR-011](../adr/ADR-011-league-ledger-and-career-feedback.md), [작업 계획](../development/20-career-world-plan.md)
- 권위: 이 범위의 제품 의도·인수 기준은 통합 제품 설계서보다 이 PRD를 우선한다. 기존 development/phases/screens/content 구현 계약과 확정 ADR은 자동으로 대체하지 않는다([문서 우선순위](../development/README.md)). 새 동작은 연결 ADR과 작업별 계약을 확정한 뒤 구현한다.

## 1. 문제와 목표

내 선수의 기록과 구단 면담은 생겼지만, 그 기록이 리그 경쟁과 긴 선수 생활에서 어떤 의미인지 읽기 어렵다. 팀이 우승에 가까워지는지, 부상 뒤의 선택이 어떻게 돌아왔는지, 은퇴 시 무엇을 남겼는지가 한 흐름으로 연결돼야 한다.

목표 경험은 **팀의 상황 확인 → 나의 선택 → 경기·시즌 진행 → 선택의 후속 결과 → 커리어 회고**다. 원작의 이름·문구·점수 체계를 복제하기보다, 실제 저장된 원인과 결과를 읽기 쉽게 연결한다.

## 2. 확인된 근거와 현재 상태

### 대표 사용자 흐름

1. **리그를 보는 선수:** 대시보드 요약 → 리그 표 진입 → 내 팀과 바로 위 팀의 차이 확인 → 시즌 진행 → 완료된 라운드 기준 갱신 → 결산의 최종 표 → 다음 시즌 이후 과거 표 조회. 구체 배치는 WP-03의 360px 검토로 정한다.
2. **출전과 복귀를 고민하는 선수:** 실제 출전 감소/부상 상태 → 가능한 선택과 대가 확인 → 응답/효과 확인 → 복귀나 시장 결과에서 이전 선택 회수 → 시즌 이력에 근거 보존.
3. **은퇴하는 선수:** 기존 마지막 선택 → 은퇴 확정과 저장 → `커리어 돌아보기` 또는 `최종 기록 바로 보기` → 대표 순간 3~5개와 단계 표시 → 기존 Legacy 근거·최종 기록 → 보관함에서 다시 열기. 회고는 실제 Archive/Legacy에 source가 있는 선택 종류만 다루며 전체 선택 원장을 새로 약속하지 않는다.

## 5. 예외와 실패 경험

- 경기/선택 pending 동안 표는 마지막으로 확정한 라운드와 경기 수를 표시하며 미래 결과를 노출하지 않는다.
- 일시 중단·중복 클릭·두 탭 충돌 후 동일 결과로 복구한다. 모션을 다시 재생해도 명령을 재실행하지 않는다.
- 자유계약·유스·과거 저장 등 리그 원장이 없는 상태는 지원 여부와 이유를 표시한다. 빈 표를 0점 최하위로 해석하지 않는다. 부상·복무로 선수만 결장하면 소속팀의 경기와 표는 정상 진행한다.
- 이미 결산된 시즌의 표·이벤트·점수는 이후 새 규칙이나 새 계약으로 재계산하지 않는다.
- 동률 표시는 리그 규칙의 순서에 따르며, MVP의 최종 동률 해소는 고정 팀 ID다. 이 규칙을 실제 축구 규정이라고 표현하지 않는다.

## 7. 후속 결정 항목

실제 승강격과 다음 시즌 참가팀 교체, 해외 리그 이동 시 세계 일관성, 대륙 진출 자격은 후속 PRD/ADR 범위다. 이번 리그 계산으로 바뀔 우승·Legacy 분포는 출시 전 실측한다. 이벤트별 정확한 조건·쿨다운·가중치와 연출 체류 시간은 작업 계획의 계약 게이트에서 수치로 확정한다. 이 미결 항목을 임의의 기본값으로 구현하지 않는다.
