# Phase 3. 계약·임대·이적

## 목표

플레이어가 연봉 순위가 아니라 역할, 전술, 출전 약속, 경쟁 상황을 비교해 다음 경로를 선택한다.

## 완료 후 흐름

```text
시즌 종료/이적시장
→ SCR-017 계약 상태·FA
→ SCR-019 이적 루머/관심
→ 제안 비교·1회 협상
→ SCR-020 이적·임대·잔류 결과
→ 새 팀 프리시즌
```

## 포함 범위

- 재계약, 자유계약, 완전 이적, 임대, 바이아웃.
- 기간, 급여, 보너스, 역할, 출전 약속, 포지션 계획.
- 구단 전술 적합도, 경쟁자, 리그 수준, 국가대표 전망 비교.
- 제안 유효기간과 한 차례 협상.
- 임대 종료 후 원소속 복귀 또는 완전 이적 옵션.
- 이적이 관계·평판·시장가치에 주는 Effect.

## 상태기계

```text
GENERATED → OFFERED → NEGOTIATING → ACCEPTED
                    ├────────────→ REJECTED
                    └────────────→ EXPIRED
```

ACCEPTED 전환은 기존 계약 종료/정지, 새 계약, 팀 변경, 역할, Timeline을 한 트랜잭션으로 처리한다.

## 구현 슬라이스

1. Contract/Offer/Clause 스키마.
2. 시장가치·구단 수요·제안 생성.
3. 제안 비교 API와 화면.
4. 협상 결과와 cooldown.
5. 이적·임대 원자 명령.
6. 새 팀 전술·관계 초기화/이월.

## 완료 조건

- [ ] 역할과 전술이 다른 최소 3개 제안을 비교한다.
- [ ] 만료·거절·협상 실패에도 안전한 잔류/대안이 있다.
- [ ] 이적 중 중복 명령으로 계약이 겹치지 않는다.
- [ ] 임대와 원소속 계약의 기간·급여 규칙을 검증한다.
- [ ] 리그 이동이 Base OVR을 직접 변경하지 않는다.
- [ ] 계약 약속 위반이 다음 시즌 관계 이벤트 입력이 된다.

## 제외

실제 환율·세금, 다자 구단 경매, 에이전트 성격의 고급 모델, 실명 구단 라이선스. 국가·리그·등록·적응이 결합된 해외 이적은 기존 상태기계를 재사용해 [Phase 8 WORLD STAGE](phase-08-world-stage.md)에서 확장한다.
