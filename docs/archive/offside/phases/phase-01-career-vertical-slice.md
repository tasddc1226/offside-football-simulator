# Phase 1. 커리어 수직 슬라이스

## 목표

사용자가 선수를 만들고 유소년 배경과 입단 테스트를 거쳐 첫 프로 계약을 체결한다.

## 완료 후 흐름

```text
SCR-034 온보딩
→ SCR-001 커리어 허브
→ SCR-002 선수 생성
→ SCR-003 플레이 스타일
→ SCR-004 생성 확인 + 복구 코드 발급
→ SCR-007 진로 선택
→ 입단 테스트 이벤트
→ SCR-009 지명/제안 결과
→ SCR-010 첫 계약(자동 서명)
→ SCR-029 커리어 대시보드
```

## 포함 범위

- 이름, 성별, 주발, 국적, 선호 포지션군·세부 포지션, 아키타입, 유소년 배경.
- 초기 세부 능력과 Base OVR, Potential 정본·정찰 범위.
- 학교/클럽 아카데미/해외 유학 배경 효과.
- 입단 테스트 선택 이벤트와 1~3개 계약 제안.
- 첫 계약의 기간·급여·예상 역할·등번호. 사인은 이름 자동 서명만.
- DRAFT→ACTIVE 전환과 첫 Career Snapshot.
- 온보딩 3장과 점진 공개 규칙(U18 구간은 OVR·폼·체력만).
- 커리어 대시보드 다섯 구역의 틀. Phase 1에서는 일정표·다이어리만 열리고 나머지는 잠금 상태 표시.
- 설정·데이터 화면: 모션 감소, 텍스트 크기, 테마, 복구 코드 발급·재발급·복구, Google 연결·병합, 삭제.
- Google OIDC 로그인과 익명 프로필 연결·병합([ADR-008](../adr/ADR-008-auth-and-account-merge.md)).
- 개인정보 처리방침·이용약관 라우트(`/legal/*`). 랜딩과 SCR-030에서 연결. 국외 이전·토스 식별키 항목 포함(ADR-008·009).
- 시각 디자인 시스템 토큰과 CompareCards(SCR-009 제안 비교에 첫 적용).
- 채널 중립 규칙: 종료 확인, 뒤로 가기, SafeArea 토큰을 `platform` 어댑터로만 다룬다(DSN-CHN-001). 미니앱 QR 테스트는 출시 준비 단계(M-006)의 항목이다.

## 기능 요구사항

- FR-CAR-001, FR-PLY-001, FR-OVR-001, FR-EVT-001, FR-CON-001, FR-SAV-001, FR-REC-001, FR-HUB-001, FR-ONB-001, FR-DSN-001.
- 선수 생성 확정 전에는 영구 능력 seed를 소비하지 않는다.
- 포지션과 맞지 않는 아키타입 조합은 엔진 검증과 동기화 스키마 양쪽에서 거부한다.
- 성별은 선수 프로필 정보로만 저장하며 OVR·능력·잠재력·성장·부상·선발·계약·시장가치·Legacy 계산과 이벤트 적격 조건에 사용하지 않는다.
- 생성 시 고른 선호 포지션은 최초 주포지션과 숙련도 100의 시작값이 된다. 이후 포지션 전환이 일어나도 최초 선호 포지션은 프로필에 보존한다.
- 계약 확정은 Player, Career, Contract, Timeline을 IndexedDB 한 트랜잭션으로 저장하고 checkpoint로 동기화한다.

## 구현 슬라이스

1. 생성 DRAFT와 유효성 검사.
2. 역할 가중치와 OVR golden fixture.
3. 배경 선택과 Effect 적용.
4. 입단 테스트 EventDefinition/Resolver.
5. 계약 Offer 생성·비교·확정.
6. 새로고침·뒤로 가기·응답 유실 복구.

## 완료 조건

- [ ] 360px 모바일과 키보드로 첫 계약까지 완료한다.
- [ ] 새로고침 후 DRAFT와 확정 단계가 각각 복원된다.
- [ ] 포지션별 아키타입과 OVR 기대값이 golden test와 일치한다.
- [ ] 같은 seed·나머지 입력에서 성별만 달리한 선수의 능력·잠재력·계약 결과가 같다.
- [ ] 포지션 전환 뒤에도 최초 선호 포지션과 현재 주포지션을 구분해 표시한다.
- [ ] 중복 확정으로 선수·계약이 복제되지 않는다.
- [ ] 실패 결과도 안전한 계약 또는 재도전 경로를 제공한다.
- [ ] 생성된 Career에 서비스 시즌·규칙·콘텐츠 버전이 고정된다.
- [ ] 복구 코드로 다른 브라우저에서 같은 Career를 연다.
- [ ] 온보딩을 건너뛰어도 첫 프로 계약까지 5분 이내다.
- [ ] 대시보드에서 어떤 명령도 확정되지 않는다.
- [ ] 모든 화면이 시각 토큰만 쓰고 UI 문자열에 폐기 어휘가 없다.
- [ ] 화면·엔진 코드에 `@apps-in-toss/*` import와 채널 분기가 없다(lint로 확인).

## 제외

실제 리그 시즌, 임대·이적 협상, 부상, 관계망, 은퇴, 시즌 도전.
