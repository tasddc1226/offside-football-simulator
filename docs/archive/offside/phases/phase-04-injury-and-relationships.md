# Phase 4. 부상·관계·평판

## 목표

경기력 외의 인간관계와 위험 관리가 출전·계약·서사를 바꾸도록 한다.

## 포함 범위

- 감독 신뢰, 주장·동료, 경쟁자, 팬, 에이전트 관계.
- 라커룸 갈등, 주장 중재, 감독 교체, SNS·언론 이벤트.
- 부상 발생, 진단, 조기 복귀/단계 재활, 재발 위험, 후유증.
- 슬럼프와 폼 회복.
- 윤리·위기 이벤트의 실패 안전장치.
- 원클럽맨, 저니맨, 임대 신화, 라커룸 리더 등 커리어 태그.
- 대표팀 차출 이벤트: step 8 소집 창, 참가·사양의 대가, 대표팀 데뷔 챕터(MAJOR). 국적별 특례는 Phase 5 모듈이 붙기 전까지 비활성.
- 대시보드 라커룸·휴대폰 구역의 관계 수치 공개(점진 공개 3단계).

## 화면

SCR-016, SCR-018, SCR-021, SCR-022, SCR-023 경기 판단 변형, SCR-024, SCR-032와 공통 SCR-013~014를 구현한다.

## 부상 규칙

- 부상 직후에는 Fitness와 출전 가능 상태를 바꾼다.
- 영구 능력 변화는 중증도·부위·재활·재발 결과가 확정될 때만 적용한다.
- 조기 복귀는 단기 출전 기회와 재발 위험을 함께 보여준다.
- 회복 날짜는 범위로 시작하고 진단·재활 진행에 따라 좁힐 수 있다.

## 관계 규칙

- 관계 Effect는 OVR을 직접 변경하지 않는다.
- 감독 신뢰는 역할·출전 경쟁·재계약 확률에 작용한다.
- 동료 관계는 경기 중 선택의 도움·갈등 outcome을 바꾼다.
- 관계 변화는 source와 이유 태그를 남긴다.

## 구현 슬라이스

1. RelationshipEdge와 CareerTag.
2. 감독·라커룸 이벤트 pool.
3. InjuryEpisode·RehabPlan·recurrence.
4. 미디어/팬 평판과 시장가치 입력.
5. Effect 만료·stacking·후속 이벤트.
6. 관계망·재활 UI와 접근성.

## 완료 조건

- [ ] 같은 인물 관계 변화가 중복 Edge를 만들지 않는다.
- [ ] 감독 교체가 선호 역할·신뢰·출전 경쟁을 재평가한다.
- [ ] 조기 복귀와 단계 재활의 대가가 선택 전에 보인다.
- [ ] 부상 재발 fixture가 결정론적으로 재현된다.
- [ ] 관계·평판이 Base OVR을 직접 바꾸지 않는다.
- [ ] 단일 실패 이벤트가 강제 커리어 종료를 만들지 않는다.
- [ ] 대표팀 사양이 감독 신뢰가 아니라 협회·팬 관계에만 작용한다.

## 제외

자유 문장 AI 대화, 실시간 소셜 피드, 의학적 진단 시뮬레이션, 유해 콘텐츠 생성.
