# 계정 라커룸과 팀 편성

- `/locker-room`에서 해당 계정의 생성 완료 선수(현역·은퇴·보관)를 조회한다. 초안은 제외한다.
- 선수 능력치는 서버의 최신 커리어 Snapshot에서 읽는다. 은퇴 후 변경 불가 규칙에 따라 은퇴 선수는 최종 능력치를 유지한다. 전성기 복제나 추가 육성은 이번 범위에 없다.
- 팀 이름, 4-3-3 / 4-4-2 / 3-5-2, 선발 11자리와 후보 7자리를 저장한다. 빈자리와 여러 팀을 허용하며 한 팀 안에서 동일 선수의 중복 배치는 금지한다.
- 골키퍼는 GK 또는 후보 자리, 필드 선수는 필드 또는 후보 자리에 배치한다. 필드 세부 포지션 제한이나 적응 페널티는 아직 없다.
- `locker_teams`는 프로필 소유의 별도 테이블이다. 편성은 개인 커리어, RNG, 선수 능력치를 변경하지 않는다. 게임 규칙/콘텐츠 버전은 3.1.0 / 0.10.0을 유지한다.
- 조회와 변경 모두 세션 소유권을 검증한다. 수정은 revision 조건부 갱신으로 충돌을 막는다. 팀을 지워도 선수 기록은 남고, 선수를 지우면 팀에서 그 자리는 비어 보인다.
- 계정 복구·Google 병합은 선수와 팀을 같은 DB batch에서 옮긴다. 계정 삭제는 팀도 지운다.
- 마이그레이션 0008은 기존 게임 테이블을 변경하지 않고 팀 테이블과 소유자 인덱스만 추가한다.
- 팀 간 경기, 리그 운영, 이적시장, 선수 거래는 미포함이다. 다음 확장은 저장된 편성으로 치르는 친선 경기부터 연결할 수 있다.

검증: 실제 D1 기반 계정 격리·팀 CRUD·중복/포지션 검증·충돌·계정 병합 두 경로·탈퇴·선수 삭제 테스트, 편성 이동/저장 실패 시 초안 유지 UI 테스트. 로컬 브라우저 QA는 별도 임시 DB의 테스트 선수로 수행한다.
