## 범위

- 만질 패키지·경로: `apps/web/e2e/**`(헬퍼·spec·필요 시 `playwright.config.ts`의 타임아웃 아님 — 설정은 그대로). 새 spec 파일 금지, 기존 spec에 단계·셀렉터·기대 문자열 갱신만.
- 만들 것: 분류 A~D의 헬퍼·spec을 앱의 현재 동작에 맞춘다. 공용 흐름은 헬퍼 한 곳에 두고 spec 안 인라인 흐름은 헬퍼 호출로 바꾼다(같은 드리프트가 다시 흩어지지 않게). 인트로·연출은 `reducedMotion: 'reduce'` 에뮬레이션과 "인터랙티브 요소 대기"로 처리하고 `waitForTimeout` 고정 대기는 쓰지 않는다.
- 만지지 말 것: `apps/web/src/**`, `packages/**`, `playwright.smoke.config.ts`, CI 워크플로, docs. 타임아웃을 늘려서 통과시키는 방법 금지(원인이 대기 대상의 변경이면 대상을 바꾼다).
