# T-4-013: api 100회 병렬 테스트 타임아웃 조정 (api 테스트 전용)

## 목표

`apps/api/src/routes/careers.test.ts`의 100회 병렬 테스트 2건("100회 병렬 멱등: 같은 Idempotency-Key…", "100회 병렬 경쟁: 같은 baseRevision, 다른 내용…")이 GitHub 러너와 부하 있는 로컬에서 20초 예산을 넘겨(관측 20.8s·23.0s) 무관한 PR의 Quality gates를 깨뜨린다(PR #69 run 33940749934, 2026-09-05 로컬 재현). 테스트가 검증하는 성질(멱등 전부 200·revision 1회 증가 / 경쟁 정확히 1개 200·나머지 409)은 그대로 두고 예산만 현실화한다.

## 1. 작업

- 두 테스트의 vitest 타임아웃을 `60_000`으로 올린다(테스트 3번째 인자). 동시 요청 수(100)는 줄이지 않는다 — D1(Miniflare) 경합 특성이 테스트 목적이다.
- 같은 파일에서 20초 근처를 쓰는 다른 테스트가 있으면 표로 적되 바꾸지 않는다.
- 로컬에서 `pnpm --filter @offside/api exec vitest run src/routes/careers.test.ts` 3회 실행 결과(각 테스트 소요 ms)를 PR 본문에 적는다.

## 2. 인수 조건

- `pnpm lint && pnpm typecheck && pnpm --filter @offside/api test` 통과. web e2e 불필요.
