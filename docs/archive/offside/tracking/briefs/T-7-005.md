# T-7-005: 표시 라벨 정합 — 관계 사유 enum, 챕터 TAG 제목(#105), 결산 역할·약속 표 (이슈 #142·#143·#105)

## 목표

내부 키가 화면에 그대로 새는 세 곳을 `apps/web` 표시 계층에서 닫는다. (1) 라커룸·선수 탭의 관계 사유 `PROMISE_BREACH`·`NATIONAL_TEAM_ACCEPT` 등 대문자 키
(도메인 `RelationshipLogEntry.reasonTag`는 자유 문자열, 매핑 없음). (2) 챕터 제목 `chapterTriggerLabel()`의 `TAG` 분기가 `trigger.tag`(`프로_데뷔`)를 그대로 반환.
(3) 시즌 결산의 "역할 시작/종료"(선발 순위에서 나온 등급)와 "출전 약속"(계약의 역할 약속)이 서로 다른 출처인데 같은 표에 나란히 있어 모순처럼 읽힌다. 도메인은 바꾸지 않는다.

## 범위

- 만질 패키지·경로: `apps/web`만 — 위 파일들과 그 테스트(`labels.test.ts`, `career.$careerId.index.test.tsx`, `season-result-view.test.ts`, `chapter-state.test.ts`).
- 만들 것:
  1. `labels.ts`에 `RELATIONSHIP_REASON_LABEL_KO: Record<string, string>`와 `relationshipReasonLabel(tag: string | null): string`을 추가한다. 표:

     | 키 | 표시 |
     |---|---|
     | PROMISE_BREACH | 출전 약속 미이행 |
     | NATIONAL_TEAM_ACCEPT | 대표팀 소집 수락 |
     | NATIONAL_TEAM_DECLINE | 대표팀 소집 거절 |
     | NATIONAL_TEAM_CONDITIONAL | 대표팀 소집 조건부 수락 |
     | CAPTAIN_MEDIATION | 주장 중재 |
     | ETHICS_DISCLOSURE | 윤리 문제 공개 |
     | ETHICS_FAILURE | 윤리 문제 외면 |
     | ETHICS_REVIEW | 윤리 검토 |
     | LOCKER_SILENCE | 라커룸 침묵 |
     | MEDIA_MISREAD | 언론 오독 |
     | OPEN_CONVERSATION | 솔직한 대화 |
     | OVEREXERTION | 무리한 훈련 |
     | PERSONAL_GOAL | 개인 목표 우선 |
     | RECOVERY_ROUTINE | 회복 루틴 |
     | TACTICAL_REVIEW | 전술 복기 |
     | TEAM_FIRST | 팀 우선 |

     `LEGACY_`로 시작하는 키는 `'은퇴 평가'`. 그 외 미등록 키: `resultTagLabel(tag)`(한글 스네이크 태그)가 있으면 그것, 없고 `/^[A-Z][A-Z0-9_]*$/`이면 `'최근 변화'`, 나머지는 원문. `null`은 `'최근 변화'`. 이 함수를 `index.tsx` 986·991행과 `locker-room.tsx` 33행에 적용한다(memoryTags는 각 항목을 매핑한 뒤 ` · `로 잇는다).
  2. `chapterTriggerLabel`의 `TAG` 분기: `CHAPTER_TAG_TITLE_KO = { 프로_데뷔: '데뷔 이후의 무대' }`를 먼저 보고, 없으면 `resultTagLabel(trigger.tag) ?? '핵심 경기'`. 원시 키를 반환하는 경로를 없앤다. 결산의 핵심 경기 목록(`season-result.tsx` 523행 `chapterTitle`)도 같은 함수를 쓰므로 함께 바뀐다.
  3. 결산 표(`season-result-view.ts` + `season-result.tsx` 470~497행): 행 이름과 구성을 다음으로 고정한다.
     - `선발 등급 (시즌 시작 → 종료)`: 기존 `roleAtStart → roleAtEnd`.
     - `계약 역할 약속`: `promise.promised` 라벨.
     - `실제 출전 등급`: `promise.delivered` 라벨 + `(출전 시간 N%)`(= `minutesShareBp / 100`, 정수 반올림).
     - `약속 이행`: `이행` / `미이행` + 미이행이면 기존 신뢰 변화 문구(`promiseBreachTrustRuleDelta`가 0이면 문구 생략).
     - 캡션 한 줄: `선발 등급은 매 경기 경쟁 순위로 정해지고, 계약 역할 약속은 계약서의 역할입니다. 둘은 다를 수 있습니다.`
- 만지지 말 것: `packages/domain`(사유 키·결산 데이터), `packages/content`, `contract.tsx`·`offers.tsx`([T-7-004](T-7-004.md)), `result-narrative.ts`([T-7-010](T-7-010.md)), docs.
