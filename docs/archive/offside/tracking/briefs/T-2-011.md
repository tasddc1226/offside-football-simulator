## 제약

- domain 패키지는 외부 import·Node·브라우저 API 금지. 시간·난수는 입력으로만. 저장값은 정수(D-36).
- 커밋 메시지는 `T-2-011: …`로 시작, 브랜치는 `T-2-011-…`. 후속 4건은 각각 별 커밋으로 나눠 되돌리기 쉽게 한다.
- 골든 재생성이 생기면 PR 본문에 "왜 바뀌었는지"(어느 후속 커밋 때문인지) 파일별로 한 줄.
- 서브에이전트를 띄우지 않는다 — 리뷰용이든 조사용이든 전부. gstack `/review`·`/codex`·adversarial 리뷰·`/simplify`·병렬 fork·Agent/Explore 조사 에이전트 금지. 파일은 직접 읽는다. 유일한 예외는 Orca PR 게이트용 `/review:pr` 1회(로컬 모드)다. 리뷰는 오케스트레이터가 한다.
- 상태 타입을 확장하지 않는 작업이지만, 어떤 이유로든 다른 패키지 typecheck가 깨지면 그 PR이 최소 수정으로 루트 체인을 통과시킨다. "기존 버그"라고 적기 전에 origin/main에서 같은 명령이 통과하는지 확인한다.
- 의존성 추가 금지(측정은 Playwright·vitest만).
- e2e는 `E2E_PORT=5187`로 돌린다. seed 탐색 스크립트는 스크래치패드에 두고 저장소에 넣지 않는다(결과 seed와 근거만 fixture `.ts` 주석에).
- PR 직전 `git fetch origin && git merge origin/main`으로 최신 main을 합친다. `pnpm-lock.yaml` 충돌은 `git checkout origin/main -- pnpm-lock.yaml && pnpm install --no-frozen-lockfile`로 재생성한 뒤 전체 체인을 다시 돌린다.
