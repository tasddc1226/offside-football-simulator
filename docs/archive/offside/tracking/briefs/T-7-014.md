# T-7-014: 실시간 플레이 중 인원 API — 세션 하트비트·집계 엔드포인트 (apps/api + contracts)

## 목표

웹 상단 공통 네비바에 "지금 플레이 중인 사람 수"를 보여주기 위한 서버 쪽 근거를 만든다. 끝나면 `GET /v1/presence`가 최근 5분 안에 활동한 프로필 수를 돌려주고, `POST /v1/presence/heartbeat`가 호출한 세션의 `sessions.last_seen_at`을 갱신한다(D-78). 새 바인딩(KV·Durable Object·Cron) 없이 **D1만** 쓴다.

배경: `sessions.last_seen_at`(`apps/api/src/db/schema.ts` 40행)은 세션 생성 때만 쓰이고 이후 갱신되지 않는다(`apps/api/src/auth/session.ts` 67행, `db/repos/sessions.ts` 23행). `profiles.last_seen_at`은 `routes/profile.ts` 87~90행에서 1시간 단위로만 갱신돼 "지금 플레이 중" 창으로 쓰기엔 너무 거칠다. 웹 클라이언트(T-7-015)가 탭이 보이는 동안 60초마다 하트비트를 보내면 이 값으로 5분 창 집계가 가능하다.

## 범위

- 만질 패키지·경로: `packages/contracts/src/presence.ts`(신규) + `index.ts` 재export, `apps/api/src/routes/presence.ts`(신규) + `app.ts` 등록 한 줄, `apps/api/src/db/schema.ts`(sessions 인덱스 1개) + `drizzle-kit generate` 산출 마이그레이션, `apps/api/src/db/repos/sessions.ts`(하트비트·집계 쿼리 함수 2개), `apps/api/src/routes/presence.test.ts`(신규 1파일 — 라우트당 테스트 파일 1개인 기존 구조를 따르므로 D-62 허용, 케이스 3개 이내).
- 만들 것:
  1. contracts: `LivePresenceSchema = z.strictObject({ playingNow: z.number().int().nonnegative(), windowMinutes: z.number().int().positive(), sampledAt: IsoUtcSchema })`, `GetLivePresenceResponseSchema = successEnvelope(LivePresenceSchema)`. `index.ts`에 재export 블록 추가.
  2. `GET /v1/presence`(공개, 세션 불필요): `SELECT COUNT(DISTINCT profile_id) FROM sessions WHERE last_seen_at >= <now-5분 ISO> AND revoked_at IS NULL AND expires_at > <now ISO>` → `{ playingNow, windowMinutes: 5, sampledAt: now }`. `Cache-Control: public, max-age=30`. `now`는 `Date.now()`를 ISO로(서버는 순수 계층이 아니므로 허용).
  3. `POST /v1/presence/heartbeat`: 본문 없음(`{}` 허용). 세션이 없으면 **204로 조용히 끝낸다**(프로필을 만들지 않는다). 세션이 있으면 `last_seen_at`이 30초 이상 지났을 때만 `UPDATE sessions SET last_seen_at = ? WHERE id = ?`(스로틀은 `profile.ts`의 패턴을 따라 상수 `PRESENCE_TOUCH_MIN_MS = 30_000`). 응답 204, 본문 없음. `originGuard`·`bodyGuard`는 기존 미들웨어가 처리하므로 별도 코드 없음.
  4. `sessions(last_seen_at)` 인덱스 `sessions_last_seen_at_idx`를 schema에 추가하고 `pnpm --filter @offside/api db:generate`로 마이그레이션을 생성한다(손으로 SQL을 쓰지 않는다). `pnpm --filter @offside/api db:check`가 diff 없음이어야 한다.
- 만지지 말 것: `apps/web/**`, `packages/ui`, `packages/domain`, `profiles.last_seen_at` 갱신 로직, 세션 생성·만료 로직, `wrangler.jsonc`(새 바인딩 금지), CI 워크플로, docs.
