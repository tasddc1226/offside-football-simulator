9. 최종 능력치 상세: 터치라인 윙어 가중치(크로스22%·스피드18%·드리블16%)가 시종 일관, 다른 포지션 문구 혼입 없음 — `case3-10`.

## 해석

- 위 표에서 "부모/원소속 클럽에 머무는 시즌 = 0분, 클럽을 바꾸거나(임대·이적) 역할 업그레이드를 수락한 시즌 = 실제 출전"이라는 뚜렷한 상관관계가 관찰된다. 단일 커리어이므로 확률적 우연(그 시즌 스쿼드 경쟁 순위·전술 적합도가 우연히 낮았을 가능성)과 구조적 로직(원소속에서는 "다운그레이드 거절"이 사실상 무의미하고 실질 역할이 이미 예비 선수로 처리되는 로직)을 구분할 수 없다. 다만 "역할 약속: 벤치"로 서명한 계약에서 시즌 내내 0/22~0/26으로 결장하면서도 위반 카운트가 시즌 결산 시점에야 "위반 1회"로 집계되는 점은, 위반 판정이 실시간이 아니라 사후 집계라는 설계로 보인다.
- 조기 재계약 협상에서 "남은 계약 0시즌" 표기는 방금 시작한 1시즌 계약을 이미 소진된 것으로 계산하는 것처럼 보여, 오프바이원(off-by-one) 성격의 표시 오류일 가능성이 있다(확정 아님, 추정).
- `PROMISE_BREACH`는 한국어 라벨이 준비되지 않은 내부 enum이 그대로 노출되는 전형적인 i18n/렌더링 누락으로 보인다.
- 임대가 두 번 다 실제 출전으로 즉시 연결된 것은 긍정적 신호다. 다만 임대 복귀 시 "매입 옵션 없음 → 강제 복귀 → 역할 리셋"이 임대 성과(평점 6.3, 20경기)를 전혀 반영하지 않는 점은, 임대가 "일시적 우회"일 뿐 원소속 문제를 해결하지 못한다는 것을 보여준다.

## 제안 (P1/P2/P3)

- **P1**: `PROMISE_BREACH` 등 내부 enum 문자열이 라커룸/관계 UI에 그대로 노출되는 경로를 점검하고 한국어 라벨 매핑을 추가한다(케이스3에서 2회 재현, #105 계열 이슈와 동일 패턴).
- **P1**: "역할 협상"/"주급 협상" 버튼이 클릭 후 아무 결과 배너 없이 disabled로만 바뀌는 문제 — 협상 성공/실패/변경 내용을 명시하는 결과 UI(토스트·배너·조건 갱신) 추가.
- **P2**: 신규 계약 서명 직후(첫 매치 전) "재계약 사전 협상"이 "남은 계약 0시즌"으로 즉시 발생하는 흐름 재검토 — 최소 1경기 이상 진행 후, 또는 실제 잔여 시즌 수가 정확히 반영된 뒤에 열리도록 조정 제안.
- **P2**: 임대 복귀 시 임대 기간 성과(평점·출전)가 원소속 역할 재협상에 전혀 반영되지 않는 점 — 임대 성과 기반의 역할 재평가 로직 검토.
- **P3**: 시즌 결산 화면에서 상단 클럽 로고/이름(현재 소속)과 하단 "이번 시즌 요약" 클럽명(그 시즌 실제 소속, 임대 시 다를 수 있음)이 다르게 표기되는 경우가 있어 혼동 가능성 — 두 값이 다를 때 라벨을 명확히 구분("현재 소속" vs "이번 시즌 뛴 팀") 제안.

## 미검증 범위·자동화 제약

- 자동 진행 스크립트가 이벤트 선택지를 "위험도(낮음/보통/높음) 우선" 휴리스틱으로 골랐기 때문에, 매 이벤트의 전체 서사 텍스트를 사람이 정독하지 않은 구간이 있다(특히 시즌1·6·7·8의 일부 이벤트). "8 이벤트 대표팀"으로 표기된 스케줄 스텝이 실제로 국가대표 소집 관련 이벤트였는지 상세 확인하지 못함.
- 매 시즌 스케줄 탭을 전부 열람하지 않고 일부 시즌(4·5·7·8)은 season-result 요약 수치("N경기·M분")만으로 판단 — 경기별 상세(선발/교체/미선발 구분)는 시즌1·2·3·6에서만 확인.
- 부상 회복 화면(재활 선택 UI) 자체의 세부 옵션은 자동 스크립트가 "높음" 위험도 선택지를 반복 선택했을 뿐, 부상 화면의 모든 선택지·문구를 전수 캡처하지 않음.
- 대표팀 관련 화면, 은퇴 임박 이벤트(27세 시점 아직 미도달), 감독 교체 이벤트("감독 교체" 로그는 확인했으나 화면 내용 상세 미확인) 등은 심층 검토하지 않음.
- 병렬 세션 특성상 잠금 대기 시간이 예정보다 길었고(약 17~18분), 이는 게임 자체 문제가 아니라 QA 환경 제약임.
