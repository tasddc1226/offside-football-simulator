# 운영 3관점 플레이 리뷰 — 디자인·게임성·기능 (2026-09-07)

2026-09-07 오후, 사용자 요청으로 Sonnet 서브에이전트 3명이 각각 ego-browser(ego lite) 격리 작업공간에서
운영 사이트 [offside-lab.com](https://offside-lab.com)(시즌 1 ACTIVE, 룰셋 1.3.0·콘텐츠 팩 0.5.0, 19세 시작)을
직접 플레이하고 관점별 리뷰를 썼다. 오케스트레이터(Claude)는 세 문서를 검토하고 핵심 캡처를 직접 확인해
우선순위를 조정했다. 코드 수정·이슈 등록·배포는 하지 않았다.

## 종합 결론

1. **핵심 루프는 운영에서 끝까지 돈다.** 생성→첫 계약→CHAPTER 시즌→FAST 시즌→결산→이적·재계약→대표팀 소집까지
   세 커리어(합계 9시즌) 모두 막힘·오류 없이 진행됐고, 새로고침·딥링크·설정 원복·콘솔 오류 0건을 확인했다.
2. **PR #115의 성인 진로 전환은 확실히 좋아졌다.** 19세 시작 뒤 유스팀 반복이 사라졌고 첫 갈림길부터 성인 무대다.
   반면 **"출전이 막히면 벗어날 수단이 없다"는 9/6 결론은 그대로다.** 1부 이적 뒤 4시즌 연속 출전 비율 14~16%,
   재계약을 거절하면 더 나쁜 조건(예비 선수·0%)만 제시됐고, 역할 협상·감독의 역할 상향 제안도 다음 시즌 출전으로
   이어지지 않았다.
3. **디자인 완성도는 높지만(카드 비교 UI·브랜드 카피·포커스 링·트레이딩 카드 연출) 마감 결함이 몰입을 깬다.**
   하단 고정 버튼이 마지막 카드를 가리는 공통 레이아웃 문제, 관계 태그·챕터 제목의 내부 키 노출, 대표팀 경기 결과
   화면 공백, 커스텀 라디오의 키보드 무반응이 대표적이다.

### 제품 결함으로 보지 않은 것

- **다른 세션의 선수 데이터 노출**(디자인 문서 P1): 생성 도중 `QA게임성0907`의 확정 카드가 보였고 허브 "최근 선수"에도 그 커리어가 표시됐다
  ([design-05b](shots/design-05b-create-step2-identity-reload-desktop.png)). 세 에이전트가 **같은 브라우저 프로필(같은 익명 프로필·IndexedDB)**을
  공유해 생긴 테스트 환경 충돌이다. 허브에 세 커리어가 모두 보이는 것은 정상 동작이고, 생성 초안이 프로필당 하나라 **같은 브라우저의 두 탭에서
  동시에 선수를 만들면 초안이 섞일 수 있다**는 드문 경계 사례만 메모로 남긴다(우선순위 낮음).
- 순수 DOM `.click()`에 반응하지 않는 탭·포인터 이벤트 필요, 모바일 오버라이드가 풀리는 현상, 대표팀 안내 문구의 깨진 글자 1회: 자동화 도구 제약으로 분류.
- 시즌 결산 CountUp 값: 애니메이션 종료 뒤 재조회해 최종값이 변하지 않음을 확인(9/6의 `0→0` 의심은 해소).

## 잘 된 점 (세 문서 공통)

- 선택지 카드의 위험도 표시가 아이콘+텍스트라 색만으로 의미를 전하지 않음, 포커스 링이 뚜렷함.
- 미리보기 수치와 실제 결과가 항상 일치(폼·전술 적합도·신뢰 변화), 상충하는 가치(안전 vs 도전, 대표팀 vs 클럽 컨디션)가 실재.
- 트레이딩 카드 계약 연출, 스코어보드·경기 결과 스탯 그리드, 결산 서사 헤드라인, 위트 있는 카피 톤이 온보딩부터 결산까지 일관.
- FAST 모드가 이벤트 스텝을 배경 처리하면서도 MAJOR 챕터를 유지해 속도와 장면을 양립.
