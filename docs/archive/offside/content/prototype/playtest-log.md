# 종이 프로토타입 플레이 기록 (U-005)

[`season-01-inside-forward.md`](season-01-inside-forward.md)를 3회 플레이하고 회차별로 기록한다. 이 파일이 채워지면 Phase 0 pre-gate(U-005)가 닫히고, 팩 0.1.0의 밸런스 조정 작업이 열린다. 기록 항목은 프로토타입 문서의 "목적과 검증 질문"과 같다.

기록 규칙:

- 난수는 d100 또는 `RANDBETWEEN(1,100)`. roll 값을 그대로 적는다.
- 플레이어에게 보이는 숫자는 Base OVR·폼·체력뿐이다. 나머지는 진행자 열이다.
- 결정마다 소요 시간을 초 단위로 적는다. 시계는 결정 카드를 읽기 시작할 때 켠다.
- 2회차부터 다른 선택을 유도하지 않는다.

회차 메모: 플레이어가 물어본 숫자, 막힌 규칙, 진행자가 즉석에서 정한 것.

- OVR·폼·체력 외 숫자를 묻지 않았다. OVR이 절대적이지 않다는 핵심은 이해했지만 팬·에이전트의 첫인상 수치로도 해석했다. 화면 문구에서 Base OVR과 평판·정찰 평가의 차이를 더 분명히 해야 한다(`PT-CONTEXT`).
- 가장 먼저 회상한 것은 관계 이벤트였다. 핵심 경기 챕터는 도움 없이 하나도 먼저 말하지 않아 이번 회차의 챕터 기억 기준은 미달이다.
- Base OVR 59로 시즌 중 경쟁자 B를 제치고 주전이 됐다는 명시적 증거가 없다. 3부 주전 계약은 해당 검증을 대신하지 않는다.
- CH-P02가 `교체 출전`으로 판정됐지만 첫 판단 시각이 전반 35분으로 고정돼 있다. 진행자가 박준서의 이른 충돌과 교체를 즉석으로 추가했다. 선발·교체별 장면 시각 또는 축소 규칙이 필요하다(`PT-RULE`).
- 시즌 결산의 SelectionScore 밴드를 선발·교체·결장 횟수로 바꾸는 결정론적 환산 규칙이 없어 진행자가 3·5·2로 정했다(`PT-RULE`).
- EVT-P10은 제안 수와 리그만 정하고 구단·역할·Fit·급여를 만드는 종이 규칙이 없다. ruleset 범위에 맞춰 강동 로버스와 갈매 타운 FC 제안을 진행자가 구성했다(`PT-RULE`).
- 비동기 채팅이라 총 소요 시간과 결정별 초를 측정하지 못했다. 회차의 선택·이해 데이터는 사용하되 시간 게이트 표본에서는 제외한다(`PT-MEASURE`).
- 입단 테스트에서는 HIGH 선택이 성공했고, 시즌 내내 안전한 선택만 했던 플레이어가 `보여줄 때 보여줬다`고 자기 서사를 만들었다. 위험 선택의 타이밍이라는 의도가 작동했다.
- 제안에서는 주전 경험을 택했지만 회상 인터뷰에서는 다음에 더 높은 리그를 택하겠다고 했다. 대가가 이해됐고 다른 경로 반복 동기가 생긴 긍정 신호다.
