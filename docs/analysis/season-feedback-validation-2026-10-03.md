## 변경 범위

커뮤니티 개선안 1·4·5를 웹과 앱에 반영한다. 코치 메모는 시즌 시작과 현재 OVR·능력치의 실제 차이, 컨디션·사기·치우친 훈련을 설명한다. 이적 화면은 공개 기록과 일반 평가 요소, 구단 출전 조건을 함께 보여 준다. 커리어 목표는 대표팀·우승을 포함한 기존 목표 전부와 현재 프로 구단 출전 목표를 표시한다.

숨은 잠재력·성장 계수·제의 확률·보상·저장 필드·서버 설정은 바꾸지 않는다. API 호출도 추가하지 않는다. 특정 성장 정체의 원인이나 구단 제의를 확정적으로 설명하지 않는다. 개선안 2·3의 성장 확대·곡선 조정은 이번 범위에서 제외한다.

## 판정 기준

같은 시드와 선택에서 게임 상태, RNG, 기록 및 시뮬레이션 결과의 허용 차이는 **0**이다. 숫자 또는 선택 확률을 바꾸는 패치가 아니므로 통계적 오차로 차이를 정당화하지 않는다. 안내를 보고 사용자가 선택을 바꾸면서 생기는 실제 플레이 분포 변화는 이 기계적 비교의 범위 밖이다.
