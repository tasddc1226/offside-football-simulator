# 시즌 1 은퇴 나이 45세 시뮬 (T-11-045, 2026-10-02)

[시즌별 은퇴 상한 기획](../tracking/season1-retirement-extension-plan.md) 6장의 A/C 비교 결과다. B(상한만 45세)는 따로 돌리지
않았다. 재계약 기준을 크게 풀어 둔 첫 실행(평점 6.5)이 B에 가깝기 때문이다.

## 조건

- `tooling/fulltime-sim` smart 정책, 4,000커리어, `SEED=45`, `DPOS=1`(세부 포지션을 고른 시즌 1 선수)
- `RETIRE_AGE=99`: 스스로 은퇴하지 않고 강제 은퇴(제의 없음·은퇴 나이)까지 뛴다. 연장 효과의 상한을 보는 조건이다
- A: 프리시즌 규칙(41세 은퇴). C: `RETIRE_AT=45` + 베테랑 1년 재계약(지난 시즌 10경기 이상, 평균 평점 6.8 이상)
- 같은 시드라 41세 전에 은퇴한 커리어는 두 실행에서 결과가 같아야 한다 — 실제로 2,679개 모두 같았다

```bash
SEED=45 RETIRE_AGE=99 DPOS=1 npx tsx simulate.ts 4000 smart t045-A
SEED=45 RETIRE_AGE=99 DPOS=1 RETIRE_AT=45 npx tsx simulate.ts 4000 smart t045-C
```

## 재계약 평점 기준을 고른 근거

출전 경기 기준(10·15·20·25경기)은 결과를 거의 바꾸지 않았다. 41세까지 주전으로 뛰는 선수는 대개 경기 수가 충분하다.
갈린 것은 평점이다.

| 기준       | 41~45세 은퇴 분포           | 45세 은퇴 | 점수 중앙값 | 점수 p99 |
| ---------- | --------------------------- | --------- | ----------- | -------- |
| 10경기·6.5 | 93 / 191 / 317 / 310 / 410  | 31%       | +1.3%       | +6.3%    |
| 10경기·6.8 | 204 / 268 / 309 / 268 / 272 | 21%       | +0.8%       | +5.9%    |
| 25경기·7.0 | 271 / 353 / 277 / 194 / 226 | 17%       | +0.8%       | +6.3%    |

6.5는 거의 모두 45세까지 가서 "나이마다 다른 마무리"라는 목표에서 멀다. 7.0은 미드필더 45세 은퇴가 7%로 떨어져
포지션 차이가 커진다. 6.8은 오퍼 평가가 보통 시즌으로 보는 평점이고, 은퇴 나이가 41~45세에 고르게 퍼진다.

## 기획 기준과 비교

- 41세 전 결과 변화 0건: 통과
- 45세 은퇴 비율 5~20%(처음 목표): 21%로 경계. 끝까지 뛰는 정책이라 실제 유저(스스로 일찍 은퇴하기도 한다)는 더 낮다
- 점수 중앙값 +10%, p99 +15% 이내: +0.8%, +5.9%로 통과
- 포지션 차이: 수비수가 가장 오래 남는다(45세 28%, 미드필더 14%). 시즌 2 경계에서 다시 본다
