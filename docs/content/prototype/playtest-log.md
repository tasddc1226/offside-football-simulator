# 종이 프로토타입 플레이 기록 (U-005)

[`season-01-inside-forward.md`](season-01-inside-forward.md)를 3회 플레이하고 회차별로 기록한다. 이 파일이 채워지면 Phase 0 pre-gate(U-005)가 닫히고, 팩 0.1.0의 밸런스 조정 작업이 열린다. 기록 항목은 프로토타입 문서의 "목적과 검증 질문"과 같다.

기록 규칙:

- 난수는 d100 또는 `RANDBETWEEN(1,100)`. roll 값을 그대로 적는다.
- 플레이어에게 보이는 숫자는 Base OVR·폼·체력뿐이다. 나머지는 진행자 열이다.
- 결정마다 소요 시간을 초 단위로 적는다. 시계는 결정 카드를 읽기 시작할 때 켠다.
- 2회차부터 다른 선택을 유도하지 않는다.
