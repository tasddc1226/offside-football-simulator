# SEASON 1: KICKOFF 콘텐츠 제작 패키지

이 디렉터리는 개발 코드와 독립적으로 제작·검증할 수 있는 KICKOFF 시즌 콘텐츠 정본이다. 실행 JSON으로 옮기기 전의 기획·저작·밸런스 계약이며, 검증된 항목만 `packages/content/packs/`로 승격한다.

## 시즌 판타지

프로가 되는 순간보다 더 어려운 것은 프로로 남는 일이다. KICKOFF는 U18 선수가 첫 계약을 얻고, 자신에게 맞지 않는 전술과 경쟁자를 넘어 출전 자리를 만드는 이야기다.

핵심 질문은 세 가지다.

1. 나는 어떤 선수인가?
2. 감독이 원하는 선수가 될 것인가, 내 방식으로 감독을 설득할 것인가?
3. 기회가 왔을 때 몸·관계·미래 중 무엇을 걸 것인가?

## 콘텐츠 기둥

| 기둥 | 사용자 경험 | 금지 |
|---|---|---|
| 정체성 | 같은 포지션도 역할에 따라 전혀 다른 커리어 | OVR 높은 선택이 항상 정답 |
| 자리 경쟁 | 전술·신뢰·폼으로 낮은 OVR도 선발 가능 | 결과를 숨긴 뒤 운으로만 설명 |
| 대가 | 모든 선택은 얻는 것과 포기하는 것이 있음 | 실패 한 번으로 사실상 게임 종료 |
| 기억 | 선택이 관계·태그·엔딩 문장으로 돌아옴 | 능력치 변화만 남는 이벤트 |
| 반복 | 다른 역할·배경·경로가 다른 사건을 엶 | 문구만 바꾼 동일 이벤트 반복 |

## 완료 정의

- 선택지를 읽지 않고도 고를 수 있는 사실상 정답이 없다.
- 각 이벤트의 선택 전 미리보기와 결과 원인 문구가 일치한다.
- 관계·평판·폼은 Base OVR을 직접 바꾸지 않는다.
- 네 포지션군에서 계약·출전·도전 완료 기회가 크게 어긋나지 않는다.
- 3회 종이 테스트에서 한 번도 선택되지 않은 선택지가 없다.
- 실제 JSON 승격 전 schema 검사와 narrative token 검사를 통과한다.
