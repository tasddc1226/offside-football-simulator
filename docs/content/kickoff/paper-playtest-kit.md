# KICKOFF 3회 종이 플레이테스트 키트

이 키트는 [`../prototype/season-01-inside-forward.md`](../prototype/season-01-inside-forward.md)를 사람과 세 번 진행하기 위한 진행자용 패키지다. 고정 seed는 회차 재현을 위한 것이며 선택을 유도하기 위한 것이 아니다.

> 이 문서 작성과 내부 계산은 U-005 완료로 간주하지 않는다. 실제 플레이어 3명이 끝까지 진행하고 [`../prototype/playtest-log.md`](../prototype/playtest-log.md)를 채운 뒤에만 pack의 `playtested`를 true로 바꿀 수 있다.

## 준비물

- 진행자 1명, 회차마다 처음 보는 플레이어 1명 권장.
- 프로토타입 문서의 선수 카드, 팀 맥락, 이벤트와 챕터 표.
- 타이머, 아래 상태 기록표, 회차별 roll 열.
- 플레이어에게 보여줄 값: Base OVR, 폼, 체력.
- 진행자만 볼 값: 사기, 전술 적합도, 감독 신뢰, 스쿼드 상태, 관계, 숨은 잠재력, roll.

테스트 전에 시스템을 설명하지 않는다. 다음 한 문장만 읽는다.

> 17세 인사이드 포워드 김서준의 U18 마지막 시즌입니다. 선택 전에는 위험과 예상 영향을 볼 수 있고, 확정한 결과는 되돌리거나 다시 뽑지 않습니다.

## 통제 조건

- 세 회차 모두 CHAPTER 모드, 같은 초기 상태, 같은 이벤트 문구를 사용한다.
- 진행자는 숨은 숫자를 말하지 않고 프로토타입의 원인 문구만 읽는다.
- 2회차부터도 `지난 사람은 다른 선택을 했다` 같은 힌트를 주지 않는다.
- 조건을 충족하지 못한 이벤트는 건너뛰고 roll을 소비하지 않는다.
- FAST에서 생략되는 선택도 이 테스트에서는 CHAPTER 규칙에 따라 연다.
- 플레이어가 규칙을 물으면 답은 하되 질문 내용과 답변 시간을 기록한다.

## 고정 난수 덱

회차 시작 시 해당 덱을 왼쪽부터 사용한다. 실제 확률 판정이 필요한 순간에만 한 값을 소비한다. 확정 outcome과 조건 검사에는 소비하지 않는다.

| 회차 | seed 라벨 | d100 순서 |
|---|---|---|
| A | `LINE-101` | 42, 18, 77, 64, 29, 91, 35, 56, 12, 83, 47, 69, 24, 88, 31, 52, 73, 16, 95, 40 |
| B | `LINE-202` | 68, 23, 85, 14, 57, 39, 92, 46, 71, 8, 63, 27, 80, 34, 99, 51, 19, 75, 43, 60 |
| C | `LINE-303` | 11, 74, 32, 89, 48, 21, 66, 95, 37, 53, 17, 82, 44, 70, 26, 58, 93, 6, 61, 35 |

덱이 부족하면 `seed 라벨 + 소비 횟수`를 기록하고 d100을 추가로 굴린다. 같은 회차를 재현할 때는 추가 roll도 기록값을 사용한다.

## 진행 순서

### 1. 생성과 맥락 확인 — 2분

선수 카드와 다음 비교만 보여준다.

```text
김서준  Base OVR 59  폼 50  체력 80
경쟁자 A Base OVR 64 · 감독 역할에 잘 맞는 주전
경쟁자 B Base OVR 61 · 같은 역할의 로테이션
```

`누가 더 좋은 선수인가?`, `내가 선발되려면 무엇이 필요할 것 같은가?`를 묻고 첫 답을 기록한다. 정답은 알려주지 않는다.

### 2. 시즌 진행 — 15~22분

1. 현재 step의 상황과 선택지 미리보기를 읽는다.
2. 선택지를 처음 보여준 순간 타이머를 시작한다.
3. 플레이어가 선택과 이유를 말하면 시간을 멈춘다.
4. 필요한 roll 하나를 소비하고 결과와 원인 문구를 읽는다.
5. 진행자 시트에 Effect와 태그를 적용한다.
6. 다음 결정 또는 결산까지 진행한다.

선발 판정 때는 `Base OVR`, `현재 몸 상태`, `감독이 원하는 역할과 신뢰`가 함께 작용한다는 문장만 말한다. SelectionScore 수식은 플레이어가 명시적으로 요구할 때만 테스트 종료 후 보여준다.

### 3. 결산 — 3분

다음을 한 화면처럼 순서대로 읽는다.

1. 첫 프로 제안 또는 다음 경로.
2. 최종 Base OVR, 폼, 체력.
3. 시즌 원인 태그 3개와 각각 연결된 선택.
4. 가장 기억에 남을 후보인 핵심 경기 챕터 3개.

### 4. 회상 인터뷰 — 5분

아래 질문을 순서대로 묻는다. 앞선 답을 고치도록 유도하지 않는다.

1. 가장 먼저 떠오르는 장면은 무엇인가요?
2. 시즌 결과를 바꾼 선택 두 개는 무엇이었나요?
3. OVR이 무엇이고, 선발과 어떤 관계라고 이해했나요?
4. 결과가 억울하거나 원인을 모르겠던 순간이 있었나요?
5. 다시 한다면 같은 선택을 할 것 하나와 바꿀 것 하나는 무엇인가요?
6. 다음 시즌을 바로 시작하고 싶은가요? 그렇다면 무엇이 궁금한가요?

## 회차 기록표

[`../prototype/playtest-log.md`](../prototype/playtest-log.md)에 원본을 남기고 아래 요약을 회차마다 복사한다.

| 항목 | 기록 |
|---|---|
| 회차 / seed | |
| 날짜 / 진행자 / 플레이어 코드 | |
| 총 소요 / 결정 수 | |
| 첫 계약 도달 여부 / 제안 수 | |
| 최종 Base OVR / 폼 / 체력 | |
| 낮은 OVR로 경쟁자 B를 앞섰는가 | |
| 먼저 회상한 장면 1~3 | |
| 원인과 연결된 태그 수 `n/3` | |
| OVR·폼·체력 외 물어본 숫자 | |
| 이해 못 한 결과 | |
| 다시 할 의향과 이유 | |

결정 행:

```text
step | phase | 결정ID | 선택지 | roll | outcome | Base OVR | 폼 | 체력 | 사기 | 전술적합도 | 감독신뢰 | 스쿼드상태 | 태그 | 소요초 | 선택이유
```

관찰자는 플레이어의 말을 요약하되 평가 문구를 섞지 않는다. 녹음·실명·연락처는 별도 동의 없이 수집하지 않는다.

## 상태 계산 체크

- 영구 능력 Effect를 먼저 적용하고 역할 가중치로 Base OVR을 다시 계산한다.
- CURRENT는 만료 step을 적고 해당 경계에서 제거한다.
- CONTEXT와 RELATION은 Base OVR 재계산에 넣지 않는다.
- 확정한 CareerEvent의 roll과 outcome은 다시 뽑지 않는다.
- 조건부 이벤트를 열기 전에 현재 태그·폼·season step을 확인한다.
- 결과가 애매해 진행자가 즉석 판정했으면 반드시 `진행자 개입`으로 기록한다.

## 합격 기준

| 질문 | 합격 | 수정 신호 |
|---|---|---|
| 결정 밀도 | 회차마다 8~14개, 20~30분 | 한 회차라도 40분 초과 또는 6개 이하 |
| 선택 건강도 | 세 회차 합산 모든 선택지 1회 이상 선택 | 미선택 선택지 존재 |
| 숫자 이해 | OVR·폼·체력 외 숫자 설명 요구 0건 | SelectionScore나 숨은 잠재력을 먼저 요구 |
| 원인 체감 | 원인 태그 3개 중 2개 이상을 자기 선택과 연결 | 연결 1개 이하 |
| 맥락 증명 | Base OVR 61 경쟁자를 OVR 59 상태로 한 번 이상 추월 | 세 회차 모두 실패 |
| 장면 기억 | 챕터 3개 중 2개 이상을 도움 없이 회상 | 이벤트 숫자만 기억하고 장면 회상 없음 |
| 반복 의향 | 세 명 중 두 명 이상이 다른 아키타입 재시작 의향 | 한 명 이하 |

`세 회차 합산 모든 선택지 1회 이상`은 자연 선택을 관찰하는 기준이다. 이를 맞추려고 2·3회차 선택을 배정하지 않는다. 미선택은 실패 데이터이며, 대가·문구를 고친 뒤 추가 회차로 검증한다.

## 문제 분류와 수정 우선순위

| 코드 | 문제 | 먼저 수정할 것 |
|---|---|---|
| `PT-COPY` | 선택·결과 원인을 이해 못 함 | 상황 문장, 미리보기, 원인 문구 |
| `PT-COST` | 한 선택지가 사실상 정답 | 선택 대가와 Effect, outcome weight |
| `PT-PACE` | 오래 걸리거나 결정이 과다 | 중복 이벤트, 설명 길이, 결정 슬롯 |
| `PT-CONTEXT` | OVR만 보면 된다고 느낌 | Fit·신뢰 피드백과 주전 역전 장면 |
| `PT-RULE` | 진행자 즉석 판정 필요 | trigger, 만료, 동률 해소 규칙 |
| `PT-SAFETY` | 부상·가족·정신건강 표현이 불편 | 선택 제거 또는 회복 경로·건너뛰기 |

문구 문제를 확률로 고치지 않고, 대가 문제를 Base OVR 공식으로 고치지 않는다. 세 회차 결과를 합친 뒤 가장 좁은 계층부터 수정한다.

## 종료 산출물

- 세 회차의 원본 결정 로그와 인터뷰 답.
- 미선택 선택지 목록과 유지·수정·삭제 판정.
- 결정 수·시간·선발 역전·원인 연결의 합격표.
- 수정 전후 이벤트 version과 변경 이유.
- U-005 통과 여부. 통과 전에는 manifest의 `playtested: false`를 유지한다.
