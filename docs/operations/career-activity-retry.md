# 커리어 활동 기록 재전송 — T-11-401

`PUT /v1/career-activity`는 게임 세이브가 아닌 현재 활동 상태와 첫 은퇴 여부를 기록한다.
시간당 60회 제한과 서버의 소유권 검사는 유지한다.

기존 클라이언트는 실패한 항목도 큐에서 제거했고 다음 게임 이벤트가 발생해야 다시 보냈다.
변경 후에는 최신 상태와 은퇴 표시 하나를 유지하며 순차 전송한다. 빠른 상태 변경은 합치고
성공한 전송 사이에는 최소 1분 간격을 둔다. 같은 상태는 기존처럼 30분 동안 중복을 억제한다.
정상 상태에서 주기적으로 서버를 조회하거나 전송하지 않는다.

- 네트워크·일시적 서버 오류는 1분 → 5분 → 15분 → 30분 → 1시간 간격으로 최대 5회 자동 재시도한다.
  이후에도 대기 상태는 유지하며 다음 활동·화면 복귀·웹 online 이벤트가 재전송을 이어간다.
- 429는 기존 서버 윈도우 최대 길이인 1시간을 기다린다. 다른 상태가 들어오거나 복귀해도
  이 대기 시간을 건너뛰지 않는다. 추가 DB 조회나 프로필 생성 요청은 없다.
- 권한·소유권·입력 검증의 영구 실패는 반복 전송하지 않는다.
- 백그라운드에서는 전송 타이머를 멈추고 복귀 시 재개한다.
- 대기 큐는 메모리 안에 있다. 재시작·새로고침 때는 기존 로컬 세이브에서 최신 상태를 다시
  구성하며, 세이브가 없어진 `none` 상태도 보낸다. 과거 활동 전체를 보존하는 영구 이벤트 원장은 아니다.
  게임 세이브 포맷, RNG, 시즌/은퇴 업로드 아웃박스는 바꾸지 않는다.

적용 코드는 웹·앱 공용 `app-core/careerActivity.ts`이고 각 플랫폼 부팅 코드가 복귀 이벤트를 연결한다.
운영에서 확인할 항목은 이 경로의 429, 새로 발생하는 5xx, 정상 204 및 활동/은퇴 상태의 반영이다.
운영 계정에 임의 활동을 기록하거나 제한을 소진하는 테스트는 하지 않는다.

릴리즈 노트는 내부 동기화 복구 보강이므로 생략한다. 운영 배포 전이며, 실제 기기 및 장기
오프라인에서의 검증은 단위 테스트·웹 E2E와 구분한다.
