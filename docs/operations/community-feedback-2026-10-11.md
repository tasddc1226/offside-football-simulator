제보자의 저장본·앱 버전이 없으므로 동일 커리어의 원인까지 확정한 것은 아니다. 팀 저장 E2E는 API mock 기반이며,
실운영의 해당 계정 저장 성공을 증명하지 않는다. 기존 저장과 RNG를 안내 열기/닫기 전후 비교하는 회귀 검사를 추가한다.

## 먼저 보고할 밸런스 결정

- 후보의 표시값과 시작값을 완전히 동일하게 만들도록 `initSubs` 보정을 바꾸면 초기 세부 능력치 분포와 포지션 OVR에 영향. 이번에는 변경하지 않는다.
- 개인 코치의 스피드 배분, 자연 신체 성장, 노화 감소 폭 변경은 성장 밸런스다. 기존 [다음 시즌 기획 PR #562](https://github.com/tasddc1226/offside-football-simulator/pull/562)와 함께 시뮬레이션/기존 커리어 보호 기준을 검토한다.
- 개인별 영구결번 신규 인정, 경쟁 결번 중복 허용, 구단 레전드의 재계약 우대는 경쟁·자격 또는 커리어 진행 규칙 변경이다. 이번 표현 개선과 분리한다.
- 이벤트 성공/실패 효과 변경은 개별 이벤트 재현 및 보상·위험 분석이 선행되어야 한다. 이번 네 가지 추천 작업 범위에서는 변경하지 않는다.

## 운영 반영 경계

API·게임 엔진·밸런스 값·저장 형식·서버 심사 결과를 바꾸지 않는다. 웹과 앱의 표시/안내만 변경하고 한국어·영어·일본어를 함께 제공한다.
실기기에서 확인하지 못한 항목은 PR에 별도로 적는다. 이 문서는 배포 완료나 운영 버그 수정 완료를 주장하지 않는다.

## 검증과 제한

- app-core 관련 테스트 202개, 후보 관련 기존 테스트 24개와 임시 진단 1개 통과. 임시 진단은 삭제했다.
- 후보·팀 저장·훈련 안내·은퇴 인정 관련 웹 E2E 32개 통과. 안내 열기/닫기로 저장과 RNG가 바뀌지 않고 훈련 선택이 새로고침 뒤 유지됨을 확인했다.
- 로컬 브라우저 320px에서 한국어·영어·일본어 안내와 버튼 줄바꿈을 확인했다. 영어 보조 훈련 버튼은 최소 너비에 맞춰 줄을 나누도록 웹·앱을 정리했다.
- 웹·앱 타입 검사와 lint, i18n 검사 통과. 운영 형태의 첫 화면 번들 예산도 통과했다.
- Android 기기는 연결되지 않았다. iOS는 별도 시뮬레이터에 설치했으나 현재 Xcode의 Simulator GUI가 없어 화면 조작 검증을 완료하지 못했다. 만든 시뮬레이터와 Metro는 정리했으며 다른 세션은 유지했다.
- 릴리즈 노트 64KiB 제한을 지키기 위해 10월 4일의 네 항목(구단 가치·카드 기준가·이적시장·이적시장 화면)을 archive로 이동했다. [운영 게시글](https://api.offside-lab.com/v1/boards/posts/pst_release_20261004)에서 네 항목의 제목과 본문이 게시된 것을 확인했다. 내용·ID는 바꾸지 않았다.

### 기록실 세부 포지션 필터

- 기존 포지션 칩 아래에 해당 그룹의 세부 포지션 칩을 표시한다(FW: ST/W, MF: AM/CM/DM, DF: CB/FB). GK는 중복 선택지를 만들지 않는다.
- 시즌 1 이후와 전체 시즌에서 제공한다. 프리시즌 전환·상위 그룹 변경 시 세부 선택과 페이지를 초기화한다. 정렬·검색에는 세부 조건을 유지한다.
- 웹·앱·ko/en/ja에 적용하며 기존 이름 번역을 재사용한다. 서버의 목록·인원·검색 전 순위에 같은 dpos 조건을 적용한다. 세부 포지션 없는 기록은 임의 분류하지 않는다.
- 클라이언트/엣지 캐시 키에 dpos를 포함하고 로컬 migration 0089로 조회 인덱스를 검증했다. 운영 배포 시 API와 migration을 웹·OTA보다 먼저 적용해야 한다.
- Orca 실제 로컬 데이터에서 MF → CM 조회 및 좁은 화면의 칩 줄바꿈 확인. 네이티브 iOS·Android 화면 검증은 미실시.
