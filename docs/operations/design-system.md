# 디자인 시스템 (T-11-396)

OFFSIDE 웹·앱이 함께 쓰는 화면 규칙이다. 토스 디자인 시스템(TDS)의 **원칙**을 참고했지만 TDS 코드·값·UI Kit은 쓰지 않는다. TDS 라이선스는 앱인토스 미니앱 안에서만 사용을 허락하고(다른 제품 사용·복사·수정 금지), OFFSIDE는 앱인토스에 내지 않는다(2026-10-19 사용자 결정, [ADR-009](../adr/ADR-009-apps-in-toss-channel.md) 개정).

## 정본

| 무엇                                | 어디                                                                                                    |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 색 · 반경 · 간격 · 글자 크기 토큰   | `packages/app-core/src/design-tokens.ts`                                                                |
| 웹 CSS 변수                         | `apps/web/src/tokens.css` — 위 파일에서 생성. 손으로 고치지 않는다                                      |
| 앱 색                               | `apps/mobile/src/theme/colors.ts`가 같은 토큰을 다시 내보낸다                                           |
| 대비 검사                           | `design-tokens.test.ts` — 글자색은 카드·바탕 위 4.5:1 이상(주의 색은 카드 위만)                        |

토큰을 바꾸면 `pnpm --filter @offside/app-core exec vitest run design-tokens -u`로 `tokens.css`를 다시 만들어 같이 커밋한다.

## 원칙

1. **바탕 위 흰 카드.** 면 구분은 테두리보다 바탕색 차이로 한다. 그림자는 라이트에서 아주 옅게만, 다크에서는 쓰지 않는다.
2. **색은 OFFSIDE 팔레트 그대로.** 잔디빛 회색 바탕, 진초록 그라운드, 금색 강조, 초록빛 다크. 토스에서는 색이 아니라 쓰는 규칙만 가져온다.
3. **채운 버튼은 화면에 하나.** 다음 단계는 초록 면(`.btn-primary`, 앱 `kind="primary"`), 보상 · 결정적 동작은 금색 면(`.btn-accent`). 나머지는 테두리 없는 옅은 면(`.btn`), 중간 동작은 옅은 초록 면(`.btn-tonal`).
4. **크고 굵은 숫자, 적은 글자 단계.** 숫자는 Barlow Condensed, 본문은 Pretendard. 화면 하나에서 글자 크기는 `--fs-*`(caption2 · caption · label · body2 · body1 · body · title3 · title2 · title1 · display) 중 세 단계 안팎만 쓴다. 앱은 `rem(FONT.*)`, `RADIUS.*`.
5. **둥근 모서리는 단계로.** 카드 `--radius-lg`(20), 버튼·입력 `--radius-md`(14), 작은 버튼 `--radius-sm`(10), 칩 `--radius-xs`(6), 동그란 것 `--radius-pill`.
6. **상태는 옅은 같은 색 면.** 성공·위험·주의 칩은 테두리 대신 그 색 12% 면에 그 색 글자.
7. **새 코드에 hex를 쓰지 않는다.** 메달 금 · 은 · 동, 유니폼, 구글 · 애플 로그인 버튼처럼 의미가 정해진 색만 예외다. 색은 토큰으로만 쓰고, 투명도는 웹 `color-mix`, 앱 `alpha` · `mix`로 만든다.
