# T-11-242 홈·저장·업적 조회 비용 개선

## 변경

- 홈 배너는 `GET /v1/cups/home`의 요약만 조회한다. 팀 로고·선수 명단·전체 경기·순위표를 가져오지 않는다. 공개 읽기에 세션을 조회하지 않는다. 기존 대회 상세 API와 이전 앱 계약은 유지한다.
- 요약은 클라이언트/엣지에서 각각 30초 재사용한다. 참가/취소·관리자 일정·팀 이름·계정 삭제 등 성공한 쓰기와 컵 cron 이후 해당 캐시를 지운다. Cache API 삭제는 해당 데이터센터에 적용되며 다른 데이터센터는 TTL에 따라 갱신된다.
- 업적 알림은 `GET /v1/owner-team/achievement-notifications`로 시즌·그룹·점수만 받는다. 전체 순위 COUNT 두 번을 생략한다. 업적 화면은 기존 순위를 유지한다.
- 서버가 확인한 구단주 자격 거절(`GOOGLE_LOGIN_REQUIRED`)만 아이템·보상·알림 조회 사이에서 10분 공유한다. 로그인/계정 전환/쓰기 성공 시 비운다. 언어별 오류와 진행 중 요청의 인증 전환을 구분하고 네트워크·서버 오류는 저장하지 않는다.
- 요청 제한은 조건부 UPSERT RETURNING 한 번으로 판정/기록한다. 동시 요청도 제한 수만 통과한다. 시즌 저장은 같은 트랜잭션의 RETURNING으로 기존 active/retired 상태를 반환해 마지막 전체 커리어 읽기를 제거한다. 소유권·검증·멱등·은퇴 기록 불변성은 유지한다.
- 세이브 형식·DB 스키마·인프라 크기 변경 없음.

## 검증

- 관련 로컬 D1 API 92건, app-core 19건, 전체 타입/린트/i18n 통과.
- 공개 요약 캐시 적중 시 SQL 0건, 세션·로고·경기 상세 조회 없음. 신청 취소 후 인원 갱신 및 모든 대회 단계 검증.
- 알림 응답과 전체 업적의 점수/그룹 일치, 전역 순위 COUNT 미호출, 익명 403 유지.
- 동시 요청 12개 중 제한 3개만 성공, 거절 후 카운트 증가 없음, 정확한 1시간 경계 초기화.
- 모바일 웹 390px 홈 배너→상세 탐색 및 가로 넘침 없음(Ego). 구조 E2E 6건 통과. iOS 격리 시뮬레이터에서 현재 Metro 번들 실행 및 새 요약 API 200을 확인했다. Simulator GUI가 설치되어 있지 않아 배너 스크롤·탭 조작은 미확인이고 Android 실행 환경도 없다. 최종 CI와 운영 측정 결과는 후속 기록한다.

## 운영 비교 방법

배포 직전/직후 동일한 길이의 실제 트래픽 구간에서 logger `durationMs`의 평균·p95·p99와 상태별 요청 수를 비교한다. 시즌/은퇴 경로는 ID와 연도를 묶은 API군을 서버에서 먼저 집계해 백분위수를 계산한다. Workers wall time과 혼동하지 않는다. D1 adaptive query 통계는 가중 샘플이며 정확한 요청 수가 아니다. 구버전 앱의 전체 대회/업적 요청은 유지되므로 새 API 전환율을 함께 확인한다. 5xx·D1_ERROR, 응답 크기와 새 요약/알림의 실제 호출도 확인한다. 단기 관측으로 간헐 오류의 완전 해소나 모든 기기의 OTA 적용을 단정하지 않는다.
