# 잠재력 관찰과 서버 조정 (T-11-030)

잠재력 분포는 시즌 1 개막(2026-10-06)까지 그대로 두기로 했다(프리시즌 데이터에 잠재력이 없어 등급별 결과를 운영
기록으로 확인할 수 없었다). 대신 시즌 1 동안 데이터를 모으고, 시즌 2 전에 조정할 수 있게 수치를 서버 밸런스로 열었다.

## 서버 밸런스 키

운영 도구 → 밸런스 → 성장·부상. 기본값은 지금 코드와 같아서 설정하지 않으면 아무것도 바뀌지 않는다.

- `potMean`, `potSd`: 새 선수의 실제 잠재력 추첨(정규분포, 55~96로 자름). 시즌 1부터 기본값 75 · 6([T-11-093](../analysis/season1-potential-spread-2026-10-05.md)). 시즌에 만든 선수에만 쓰이고, 프리시즌 선수는 74 · 8로 고정이다.
- `potScoutSd`: 화면에 보이는 스카우트 평가가 실제에서 벗어나는 폭.

새 버전은 **새 커리어에 바로** 적용된다(잠재력을 첫 시즌 전에 뽑으므로 `newGame`이 최신 설정을 먼저 맞춘다). 진행 중인
커리어의 잠재력은 이미 정해져 바뀌지 않는다. 적용 전 초안은
`BALANCE=<values json> pnpm --filter @offside/fulltime-sim sim`으로 먼저 돌려 본다.

## 관찰 데이터

최초 스카우트 평가 `pot`는 화면에 보이지 않는다. 은퇴 시점의 실제값 `pot_real`은 은퇴 리포트와 기록실/명예의 전당 재열람에만 공개한다. 점수·순위에는 쓰이지 않는다.

T-11-049부터 은퇴 전 등급·범위·재평가 소식은 표시하지 않는다. 계산과 저장된 원본 로그, 추첨·성장·관측 업로드는 그대로다. 은퇴 카드는 기존에 저장된 반올림 수치의 등급을 보여 주므로 첫 화면과 재열람이 같다. 소수점 원값의 등급과 경계에서 다를 수 있다. 값이 없는 옛 은퇴 기록에는 카드를 만들지 않는다. 고정된 최대 OVR이나 출생 시 잠재력으로 해석하지 않는다.

| 열 (`careers`) | 값                                                                      | 올라오는 때                                        |
| -------------- | ----------------------------------------------------------------------- | -------------------------------------------------- |
| `pot`          | 처음 스카우트 평가(55~96)                                               | 첫 시즌 기록 업로드. 서버는 비어 있을 때만 채운다. |
| `pot_real`     | 은퇴 때 공개되는 실제 잠재력(스카우트 평가 + 숨은 성장 + 이벤트 보너스) | 은퇴 업로드                                        |

한계: 21세 재평가를 지난 뒤 늦게 올라온 첫 시즌 기록은 `pot`을 싣지 않는다(옛 저장본). 값은 기기가 보내므로
조작될 수 있다 — 관찰용이고 어디에도 쓰지 않는다. 숨김 커리어(`hidden = 1`)는 집계에서 뺀다.

## 집계 예

시즌 1 은퇴 선수의 처음 평가 등급별 결과(`pot`이 있는 커리어만):

```sql
SELECT CASE WHEN pot >= 90 THEN 'S' WHEN pot >= 84 THEN 'A' WHEN pot >= 78 THEN 'B'
            WHEN pot >= 70 THEN 'C' ELSE 'D' END AS grade,
       count(*) AS n, round(avg(peak), 1) AS avg_peak, round(avg(legend_score)) AS avg_legend,
       round(avg(pot_real - pot), 1) AS avg_hidden_growth
FROM careers
WHERE hidden = 0 AND status = 'retired' AND pot IS NOT NULL AND service_season = 1
GROUP BY grade ORDER BY grade;
```

시뮬레이터(똑똑한 선택 정책)와 비교할 때는 은퇴 나이 30세 미만(중도 포기)을 같은 기준으로 맞춘다.
