# 팀 시너지 안내 점검

## 범위와 결론

팀 편성의 듀오 9개, 팀 색깔·배지·주발 맞춤 3개, 공개 게임 가이드의 팀 시너지 안내를 실제 `team-synergy.ts` 및 `BASE_DETAIL`과 대조했다. 시너지 조건·보정 수치·기존 선수 데이터는 변경하지 않았다.

| 혼동 지점                                       | 수정                                                                              |
| ----------------------------------------------- | --------------------------------------------------------------------------------- |
| W 포지션을 윙어 유형으로 이해                   | 유형과 배치 자리가 모두 필요함을 설명하고, 스피드스터 예시 및 카드 확인 방법 추가 |
| 역습·킬패스·중원 엔진 등의 배치 조건 생략       | 각 듀오에 허용 배치 코드 명시. 기존 FB/W와 확장 포지션 모두 포함                  |
| 영어 철벽의 GK 유형이 Shot-stopper로 표기       | 카드의 The wall로 정정. 수호신은 Shot-stopper로 통일                              |
| 일본어 유형명이 카드와 불일치                   | 鉄壁・ウインガー・ビルドアップCB・点取り屋 등 카드의 명칭으로 통일                |
| 주발 맞춤도 특정 육성 유형이 필요하다고 오해    | 유형과 무관하며 배치 자리와 주발을 확인함을 설명                                  |
| 국가대표 라인업도 경기 보정이라고 오해          | 배지 전용임을 공통 안내에 명시                                                    |
| 같은 듀오를 양쪽에 만들면 효과가 두 배라고 오해 | 동일 듀오는 한 번, 다른 시너지 효과는 합산한다고 명시                             |

KO/EN/JA 공용 사전과 웹·앱에 반영했다. 공개 `/guide/`에 같은 설명을 추가하고 번역 사전도 함께 작성했다. 기존 정적 가이드의 언어 제공 범위는 변경하지 않았다.

## 검증

- contracts 시너지 15개, app-core 팀 안내 11개, SEO 10개 기존 테스트 통과.
- 웹·모바일 타입 검사 통과. Svelte 기존 경고 2개, 오류 0개.
- 변경 파일 ESLint, i18n 검사, 릴리즈 노트 검증 통과.
- 실제 TeamSynergy 컴포넌트의 임시 로컬 미리보기에서 KO/EN/JA 320px, 영어 1024px 확인. 미적용 펼치기·활성 항목 선택, 설명 줄바꿈 및 가로 넘침 확인. 미리보기 파일은 검증 후 제거.
- Android 연결 기기 없음. 부팅된 iOS 시뮬레이터는 다른 작업용이므로 네이티브 화면 검증은 미완료.
- 이번 점검은 팀 시너지와 관련 가이드 범위이며 게임 전체 안내를 전수 검증한 것은 아니다.
