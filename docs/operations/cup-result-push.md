# 컵 종료 결과 푸시

대회 결승 정산이 끝나면 컵 참가자와 승부예측 참여자를 합쳐 계정당 한 번 알립니다.

- 참가자(조별 탈락 포함): 컵 종료 및 결과·보상 리롤권 확인 안내. 예측도 참여했다면 이 알림만 받습니다.
- 예측만 참여: 경기 수와 관계없이 컵당 한 번. 실제 지급된 예측 보상이 있으면 리롤권 확인을 안내하고, 없으면 예측 결과만 안내합니다.
- 참가 취소자는 예측 참여 이력이 있을 때만 예측 안내를 받습니다. 삭제된 계정은 제외합니다.
- 결승 경기의 개별 알림은 알림함에만 남깁니다. 그 이전 라운드 경기 푸시는 유지합니다.
- 성적·리롤권 지급 시점과 수량은 바꾸지 않습니다. 리롤권은 이미 지급되므로 별도 수령 버튼은 없습니다.

## 중복과 실패 처리

결승 보상, `cup_state.done_at`, 알림, 발송 원장을 같은 D1 트랜잭션으로 저장합니다.
`(profile_id, source_key=cup-complete:<cupId>)` 유일 제약과 `done_at IS NULL` 갱신이 중복 정산을 막습니다.
같은 컵의 여러 예측·참가 이력은 UNION으로 합칩니다. 가장 최근 유효 앱 기기 한 곳만 등록합니다.

커밋 후 `CUP_PUSH_QUEUE`에 `{version:1,cupId}`만 넣습니다. 소비자는 그 컵의 종료 알림만 처리하며 기존 D1 lease를 공유합니다.
Queue 중복 전달과 cron 동시 실행도 이미 전송 중이거나 접수된 메시지를 다시 보내지 않습니다.
429/5xx는 D1 backoff로 재시도하며, 전송 여부를 알 수 없는 timeout은 `unknown`으로 남기고 중복 재발송하지 않습니다.
Queue 발행 실패·DLQ 이동 시에도 5분 cron이 D1 원장을 복구합니다. 영수증 조회는 기존 cron이 처리합니다.

팀 알림 설정, 로그아웃·수신 동의 철회, 기기 유효성을 생성·발송 시 확인합니다.
발송 시간은 기존 컵 정책인 한국 시간 09:00–22:00입니다. 종료 알림은 일반 푸시 일일 예산을 소모하지 않습니다.
알림을 누르면 기존 앱과 호환되는 홈(컵 배너)으로 이동합니다.
운영 도구 앱 푸시의 팀 알림 통계에서 접수·영수증·클릭을 확인할 수 있습니다.

## 배포

Worker 배포 전에 다음 Queue를 만듭니다(보관 24시간).

- `offside-cup-push-production`
- `offside-cup-push-production-dlq`

`wrangler.jsonc`의 producer/consumer를 배포합니다. batch 1, concurrency 1, 재시도 3회입니다.
새 DB 마이그레이션이나 앱 OTA는 필요하지 않습니다. 배포 전에 이미 종료된 컵을 소급 발송하지 않습니다.
실제 단말 수신 확인은 로컬 Queue·가짜 Expo 테스트와 별도로 기록해야 합니다.
