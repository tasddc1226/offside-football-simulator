# 비정상 기록 정기 점검 (T-11-025)

게임은 브라우저에서 돌고 서버는 올라온 기록만 받는다. 그래서 값을 고친 기록이 명예의 전당에 오를 수 있다. 업로드 때의
값 검사(`plausibility.ts`)와 자동 플레이 제외(`careers.hidden`)에 더해, 매일 cron이 이미 받아 둔 기록을 다시 훑어 확실한
이상은 숨기고 애매한 것은 운영자 검토로 남긴다. 코드는 `apps/api/src/db/repos/anomalies.ts`.

## 매일 하는 일

매일 KST 04:00 cron(`src/cron/daily.ts`)이 정리 다음, 백업 전에 점검한다. 마지막 점검(`app_meta.anomaly_sweep_at`) 한 시간
전부터 시즌이 올라온 커리어만 본다. 처음 도는 날은 전부 본다. 결과는 Workers Logs의 `job: daily` 줄 `anomalies`에
숨긴 수·검토 수·숨긴 커리어 id 앞 8자리와 이유가 남는다(선수 이름은 남기지 않는다).

| 이유      | 기준                                             | 처리      |
| --------- | ------------------------------------------------ | --------- |
| `ovrFar`  | 시즌 OVR이 나이별 상한(`ovrCapAt`)을 2 넘게 초과 | 자동 숨김 |
| `jump`    | 한 시즌에 OVR이 25 이상 상승                     | 자동 숨김 |
| `ovrHigh` | 나이별 상한을 1~2 초과                           | 검토      |
| `legend`  | 은퇴 레전드 점수 3,600 이상                      | 검토      |
| `legend`  | 은퇴 레전드 점수 4,000 이상(`legendHide`)        | 자동 숨김 |

기준은 운영 실측(커리어 1만 2천 개)이다: 정상 최대 시즌 상승 22, 정상 OVR 최고 78/84/88(만 18/19/20세), 정상 레전드 점수
상위 3,300 안팎, 조작이 확인된 두 커리어는 만 18세 OVR 99·4,480대. 서버 밸런스의 성장 수치를 올리면 기준도 다시 구한다
(`plausibility.ts`의 나이별 상한과 같다). 숫자는 `ANOMALY` 한 곳에서 바꾼다.

숨김은 `hideCareerStatements`와 같다 — 공개 순위·서버 기록에서 빠지고, 쥐고 있던 최초 기록·서버 기록은 비운 뒤 다시 훑어 실제
달성자에게 넘긴다. 본인의 "내 선수"에는 남는다.

`ovrFar`·`ovrHigh`는 업로드 때 서버가 OVR을 나이별 상한으로 자르기 전(T-11-023 이전)에 들어온 기록을 위한 정리용이라, 저장된 새 기록에는 `jump`·`legend`만 걸린다. 그래서 시즌 업로드(`PUT /v1/careers/:id/seasons/:year`)가 자르기 전 값이 `ovrFar`(상한 +2 초과)면 그 자리에서 커리어를 숨긴다(`exceedsOvrCap`, T-11-037). 정상 선수는 상한을 한 번도 넘지 않았다(숨기지 않은 커리어 전체 실측).

## 운영자 도구

- `GET /v1/admin/anomalies`: 검토 대상(숨기지 않은 의심, 레전드 점수순)과 숨겨진 커리어(이유 포함).
- `POST /v1/admin/careers/hidden` `{ careerId, hidden }`: 숨기거나 되돌린다. 되돌린 커리어는 `app_meta`의
  `anomaly_cleared:<id>`로 기억해 다음 점검이 다시 숨기지 않는다. 순위 목록 캐시는 1분 안에 바뀐다.

## 한계

- 값이 정상 범위 안이면 잡지 못한다(나이를 꾸민 기록, 서서히 부풀린 기록). 레전드 점수 검토가 마지막 안전망이다.
- 자동 플레이(`isAutomatedCareer`)는 업로드 때만 판정한다. 정기 점검은 값만 본다.
- 자동 플레이로 숨겨진 커리어를 되돌려도 다음 시즌 업로드가 신호를 다시 판정해 숨길 수 있다(되돌림 표시는 정기 점검만 막는다).
- 숨김 사유를 저장하지 않아 숨겨진 목록의 이유는 지금 값으로 다시 계산한 것이다(자동 플레이로 숨긴 커리어는 비어 있다).
- 이미 올라온 옛 시즌을 같은 값으로 다시 올리면 시각이 처음 값 그대로라 증분 점검이 놓친다(그 커리어에 새 시즌이 오거나 운영자 화면을 열면 보인다).
- 알림은 없다. 로그와 운영자 화면에서 본다.
