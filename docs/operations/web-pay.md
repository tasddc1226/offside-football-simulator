# 웹 결제 (토스페이먼츠)

T-11-454. 웹(offside-lab.com) 구단주 화면에서 앱과 같은 인앱 상품(리롤권 · 잠재력 강화권 · 프리미엄 스카우트권 · 선수 이름 변경권 묶음)을
같은 한국 정가(`IAP_PRICE_KRW`)로 판다. PG는 토스페이먼츠 결제위젯(v2)이다. 국내 카드 · 간편결제(토스페이 · 카카오페이 · 네이버페이 등)는
결제위젯 하나로 열리고, 해외 카드(VISA · Master · JCB 등)는 토스페이먼츠 해외결제 추가 계약 뒤 상점관리자에서 결제 수단만 켜면 된다
(코드 변경 없음). 결제 금액은 원화(KRW) 하나다.

기본은 **꺼져 있다**. 아래 출시 전 확인이 모두 끝나야 켠다.

## 구조

- 원장은 앱과 같은 `iap_purchases`이고 `store = 'toss'`, `transaction_id = paymentKey`다. 매출 탭 · 결제 알림 · 운영 도구 구매 기록에 그대로 잡힌다.
  옛 앱이 엄격한 enum으로 읽는 `IapStoreSchema` · `GET /v1/items`의 `iap.stores`에는 넣지 않았다.
- 주문은 `web_pay_orders`(0124). 금액은 주문을 만들 때 서버가 정하고, 승인 때 결제창이 돌려준 금액 · 토스 승인 결과와 맞춰 본다.
- API (`apps/api/src/routes/webPay.ts`)
  - `GET /v1/web-pay/config`: 로그인 구단주에게 켜져 있는지 · 클라이언트 키 · customerKey(프로필 uuid) · 상품 목록.
  - `POST /v1/web-pay/orders`: 주문 생성(구단주당 시간당 30번).
  - `POST /v1/web-pay/confirm`: 토스 승인(`/v1/payments/confirm`, 시크릿 키 Basic 인증) 뒤 아이템 지급. 같은 결제를 다시 보내면 그대로 돌려준다.
  - `POST /v1/web-pay/webhook`: 토스 웹훅. 본문은 믿지 않고 paymentKey로 토스에 다시 조회해, 취소(`CANCELED`)면 아이템을 회수한다.
- 웹: `ui/cup/WebPayShop.svelte`(구단주 화면 상점 아래), `ui/cup/webPay.svelte.ts`(설정 메모 · SDK 지연 로드 · 돌아온 뒤 승인).
  토스 SDK(`js.tosspayments.com/v2/standard`)는 '상품 선택' 때만 불러온다. 결제창에서 `/?webpay=success|fail`로 돌아온다.
  승인 응답을 못 받으면 기기에 두고 다음에 구단주 화면을 열 때 다시 보낸다.
- 앱은 바뀌지 않는다. 앱 안에서 웹 결제로 안내하지 않는다(스토어 정책).

## 설정

| 이름              | 종류   | 값                                                                                                         |
| ----------------- | ------ | ---------------------------------------------------------------------------------------------------------- |
| `WEB_PAY_ENABLED` | var    | `1`이면 연다. 없거나 다른 값이면 닫힌다.                                                                   |
| `TOSS_CLIENT_KEY` | var    | 결제위젯 클라이언트 키(`test_gck_…` · `live_gck_…`). 공개값이다.                                           |
| `TOSS_SECRET_KEY` | secret | 결제위젯 시크릿 키(`test_gsk_…` · `live_gsk_…`). `test_`로 시작하면 구매를 테스트로 적는다(매출에서 빠짐). |
| `WEB_PAY_TESTERS` | secret | 쉼표 구분 프로필 id. 있으면 이 구단주에게만 연다. 실결제 확인 뒤 지운다.                                   |

토스 상점관리자 → 개발자센터 → 웹훅에 `https://api.offside-lab.com/v1/web-pay/webhook`(이벤트 `PAYMENT_STATUS_CHANGED`)을 등록한다.

## 출시 전 확인 (운영자)

1. 토스페이먼츠 가입 · 결제위젯 계약 · 심사(사업자 정보 · 사이트 · 판매 상품 · 환불 정책). 해외 카드가 필요하면 해외결제 추가 계약.
2. 통신판매업 신고, 사이트 아래 사업자 정보 표시(상호 · 대표자 · 사업자등록번호 · 통신판매업 신고번호 · 주소 · 연락처).
3. 게임물 등급: 웹 배포 게임의 등급분류(GRAC) 필요 여부를 확인한다. 앱 스토어의 IARC 등급은 웹에 적용되지 않는다.
4. 이용약관 · 개인정보처리방침 · 가이드 FAQ에 웹 결제(토스페이먼츠가 처리하는 결제 정보, 환불 · 청약철회)를 더한다(`apps/web/scripts/seo.mjs`).
   지금 문구는 "결제 상품은 앱에서 삽니다"라서, 켜는 PR에서 함께 고친다.
5. 테스트 키로 staging에서 결제 · 취소 웹훅 · 매출 탭을 확인한 뒤, 운영에 라이브 키 + `WEB_PAY_TESTERS`(본인)로 실결제 1건 · 취소 1건을 해 본다.

## 환불

받은 아이템을 쓰지 않았으면 결제일로부터 7일 안에 환불한다(웹 상점 안내 문구). 운영자가 토스 상점관리자에서 결제를 취소하면 웹훅이 와서
남은 장수 안에서 회수한다(`revokeIapPurchase`, 이미 쓴 장수는 회수하지 못하고 `revoked_qty`에 남는다).
