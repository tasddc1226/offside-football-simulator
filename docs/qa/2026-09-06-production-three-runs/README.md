# 운영 3회 플레이 — 게임성 평가

2026-09-06, 사용자 요청으로 Luna 에이전트 3명이 실제 운영 웹에서 새 QA 커리어를 각각 한 번 진행했다.
총 3커리어·17시즌을 진행하고 정상 UI의 자발 은퇴로 마무리했다. 주 에이전트는 각 보고서를 검토한 뒤,
해당 QA ID의 운영 API 저장 기록·은퇴 Archive·Legacy를 읽기 전용으로 대조했다.

## 종합 결론

**서로 다른 결과를 만드는 시뮬레이션과 기록·결산 체계는 동작한다. 그러나 실패 후 회복과 성인 진로 전환이 약해,
현재 운영 버전은 “다음 시즌도 해보고 싶다”는 동기를 안정적으로 유지하기 어렵다.**

출전이 이어진 골키퍼는 성장·우승·지도자 에필로그까지 보상을 경험했다. 반대로 공격수는 임대와 이적을 해도
6시즌 동안 한 번도 뛰지 못했고, 안정형 미드필더는 부상 재발로 출전이 막혔다. 결과의 다양성은 확인했지만,
재미있는 선택지의 다양성과 실패 후 반등까지 충분하다고 판단할 수는 없다.

로컬에서 준비한 19세 시작·새 도입부 개선을 이번 운영 평가에 포함하지 않았다.

## 범위와 방법

- 대상: `https://offside-web.tasddc1569.workers.dev/`. 로컬 미배포 변경과 구분한다.
- A: `QA안정0906` — 중앙 미드필더, 감독 신뢰·기본기·안정적인 출전.
- B: `QA도전0906` — 공격수, 높은 리그·해외 기회·주력기·자기어필.
- C: `QA변주0906` — 여성 골키퍼, 동네 클럽 배경·관계와 실출전 중심.
- 실제 가능한 생성 옵션이 계획과 다르면 각 보고서에 실제값을 기록한다.
- 첫 시즌은 CHAPTER 모드로 관찰하고 이후 모드 변경은 명시한다.
- 중간에 약 6~8시즌 후 자발 은퇴하는 제한 탐색으로 범위를 조정했으며, 실제 완료는 A·B 6시즌,
  C 5시즌이었다. 이는 30~40대까지 자연 은퇴한 전체 생애의 평가가 아니다. 조기 은퇴 점수를
  완전한 경력의 점수 상한으로 해석하지 않는다. 최종 완료 시즌 수는 각 Archive에서 확인했다.
- UI로 진행하며 게임 상태/seed/엔진을 주입하지 않는다. 기존 사용자 기록은 변경·삭제하지 않는다.
- 결과는 독립 커리어 3건의 탐색적 관찰이다. 서로 포지션·배경·seed·선택이 달라 전략 하나의 인과 효과를 증명하지 않는다.
- 에이전트 수행 시간은 도구 대기·관찰·기록 시간을 포함한다. 사람의 평균 엔딩 시간이나 전체 유저의 이탈률로 환산하지 않는다.

## 우선 개선할 부분

### 1. 성인 진로 전환 — 운영 기록으로 확인한 세계관 문제

A는 23세까지 6시즌, C는 22세까지 5시즌을 모두 `hangang-u18`에서 뛰었다.
안전한 잔류를 선택하면 성인이 되어도 유소년 팀 생활을 반복할 수 있었다.
연령별 유스 종료, 성인팀 승격·하부리그·진학 등의 전환을 필수 분기로 만들고,
성인 선수에게 U18 재계약이 계속 제시되지 않도록 점검해야 한다.
여성 선수의 리그 진로도 실제 배경에 맞게 구분할 필요가 있지만, 이번 표본만으로 전체 여성 콘텐츠의 부재를 단정하지 않는다.

### 2. 장기 무출전·재발에서 벗어나는 선택 — 게임성 최우선

- B는 부상 이력 없이 6시즌의 대상 경기 152개에서 모두 0분이었다. 임대 2회와 2부 이동도 출전으로 이어지지 않았다.
  상위 리그 도전 실패 자체보다, 실패를 인지한 뒤 무엇을 바꿔야 하는지와 회복 수단의 효용이 부족한 점이 문제다.
- A는 최초 부상 1회 뒤 `INJURY_RECURRED`가 6회 기록됐다. 보수 재활을 주로 선택했지만
  통산 11경기 중 부상 교체가 7회였다. 단일 사례로 재발 확률 오류를 단정할 수 없으나, 장기적인 실패 반복은 재검토할 가치가 크다.
- 제안: 무출전 누적 시 경쟁 수준이 낮고 실제 기회가 있는 팀 추천, 감독 면담에서 선발 조건 설명,
  재활 계획 변경과 복귀 단계 선택을 제공한다. 모든 선택을 성공시키거나 출전을 무조건 보장하는 방향은 아니다.

### 3. 포지션에 맞는 도입부 — 에이전트 UI 관찰과 콘텐츠 대조

C의 GK 도입부에 “터치라인 윙어”, 크로스·드리블 중심 문구가 노출됐다.
저장된 선택 이력에 `EVT-DEV-001:B:B1`이 있으며, 운영 콘텐츠 버전 0.3.0의 해당 이벤트 상황문에도
“감독은 터치라인 윙어를 원하지만 당신은 안쪽으로 파고드는 선수다”라는 고정 문구가 있다.
GK 경기 통계에는 세이브·크로스 캐치·빌드업 패스가 정상 기록되어, 통계 모델과 도입부 서사의 정합성 문제로 구분한다.
이벤트의 등장 조건뿐 아니라 상황문·선택지·결과문·보상을 포지션별로 함께 점검해야 한다.

### 4. 계약 반복을 줄이기보다, 계약 이후 실제 변화와 연결

운영 연대기의 확정 재계약 건수는 A 3회/6시즌, B 1회/6시즌, C 2회/5시즌이다.
이는 제안 노출 횟수와 다르므로 “매 시즌 재계약이 확정된다”거나 전체 이벤트 중 비중을 계산하지 않았다.
B는 계약·임대·복귀로 소속이 바뀌었지만 경기 경험은 생기지 않았다. 이 때문에 진행이 계약 관리처럼 느껴질 수 있다.
반복 제안은 요약하고, 역할·출전 약속이 왜 지켜지지 않았는지와 다음 행동의 기대 효과를 보여주는 것이 우선이다.
출전 약속 비율은 결과 보장과 동일하지 않으므로 불이행 자체를 소프트웨어 오류로 분류하지 않았다.

### 5. FAST의 핵심 장면과 회고를 보강

세 캐릭터 모두 첫 시즌은 CHAPTER, 이후는 FAST였다. 빠른 진행·결산·저장·은퇴 흐름은 끝까지 동작했다.
다만 후반 관찰은 FAST 중심이므로 CHAPTER 전체 콘텐츠나 모바일 전환 연출 품질을 완전히 검증한 것은 아니다.
FAST에서도 첫 선발, 재활 복귀, 첫 우승, 장기 무출전 탈출처럼 경력이 달라지는 순간을 짧게 부각하고,
엔딩에 “왜 이런 커리어가 됐는지”를 주요 결정과 연결해 주면 재플레이 동기가 강해질 것으로 판단한다.

## Legacy와 성장에 대한 판단

최종 OVR이 A 66 > C 64 > B 60인 반면, Legacy는 C 55 > A 34 > B 20이었다.
OVR 하나로 커리어 점수가 결정되지 않고 출전·성취·관계가 반영된다는 점은 장점이다.
A의 관계 축은 82, C의 기여 축은 90으로 실제 플레이 성격의 차이도 기록됐다.
다만 C는 유스 5시즌에서 얻은 55점이므로 리그 수준 간 보정이 적절한지는 장기·동일 조건 표본으로 별도 검증해야 한다.
이번 결과로 점수식을 즉시 낮추거나 ICON·LEGEND 출현율을 결론 내릴 근거는 없다.

## 확정 결함에서 제외한 사항

- 시즌 결산 OVR `0→0`: 에이전트가 관찰했지만 CountUp은 0에서 시작해 800ms 동안 수치를 올린다.
  백그라운드 자동화에서 애니메이션 중간값을 읽었을 가능성이 있어 영구적인 표시 오류로 확정하지 않았다.
  운영 저장값은 A 62→66, B 58→60, C 61→64로 확인했다. 화면에 머문 뒤 최종값 확인은 별도 재검증 대상이다.
- 국적 native select 입력: 아래 초기 진단처럼 자동화 제약으로 구분했다.
- 저장: 정상 진행과 은퇴 Archive 생성은 확인했지만, 새 기기 복구·네트워크 단절·동시 접속·OAuth 충돌까지 검증한 것은 아니다.

## 미검증 범위와 다음 평가

이번은 3회, 17시즌의 탐색 평가이며 자연 은퇴, 30대 이후, 해외 리그, 국가대표, 최고 등급 엔딩은 검증하지 않았다.
C는 5시즌에 먼저 종료했으므로 A·B와 완전히 같은 기간의 비교도 아니다.
성별·포지션·잠재력·난수·선택이 동시에 달라 “골키퍼가 유리하다” 같은 인과 결론을 내릴 수 없다.
에이전트 도구 대기까지 포함된 시간으로 사람의 평균 엔딩 시간을 추정하지 않았다.

다음에는 성인 전환과 무출전 회복을 개선한 버전에서, 자연 은퇴까지의 장기 플레이와 같은 조건의 전략 비교를 우선 권한다.
평균 소요 시간은 별도로 실제 사용자 세션의 시작·마지막 입력·유휴 시간을 구분해 측정해야 한다.

이번 작업은 평가 문서 작성만 수행했다. 코드 수정·GitHub 이슈 등록·커밋·배포는 하지 않았다.
운영에는 QA 이름의 은퇴 기록 3건이 남아 있으며 기존 사용자 기록은 삭제하지 않았다.
운영 통계나 랭킹을 분석할 때 위 QA ID를 식별해 제외할 필요가 있다. 이 평가에서는 통계·랭킹 설정을 변경하지 않았다.

## 초기 진행 진단

국적 native select를 자동화 도구의 마우스/키보드 입력으로 선택하지 못한 사례가 있었다.
실제 폼의 DOM value와 change 이벤트로 입력한 뒤 진행이 재개됐다. 이 사실만으로 일반 사용자의
입력을 차단하는 게임 버그 또는 진입성 결함으로 판정하지 않는다. 게임 저장 상태를 직접 바꾼 것은 아니다.
