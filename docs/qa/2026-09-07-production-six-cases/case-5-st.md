## 해석

- 스트라이커·타겟맨 아키타입의 "전술 적합도"가 낮은 클럽(34~36)에서는 거의 항상 예비선수/벤치 역할만 제시되는 경향이 관찰됐다. 전술 적합도가 높았던(74) 첫 두 클럽에서만 실제 출전 기회가 있었던 것과 대조적이다. 이 상관관계는 단일 커리어의 관찰이라 인과로 단정할 수 없지만, 4개 시즌 연속 무출전이 우연이라기엔 패턴이 뚜렷하다.
- 훈련 계획(역할 집중)에 따른 Base OVR 성장은 실제 출전 여부와 무관하게 발생했다(0경기 시즌에도 OVR 64→65, 65→66 성장). 즉 "성장"과 "출전"이 완전히 분리된 시스템으로 보이며, 그 결과 "출전은 없지만 능력치는 조금씩 오르는" 기묘한 정체 상태가 장기간 지속될 수 있다.
- 역할 다운그레이드 제안을 거절(시즌 3·6)해도 수락(시즌 7)해도 동일하게 0경기로 귀결된 것은, 이 특정 프로필(낮은 전술 적합도)에서는 플레이어의 역할 관련 선택이 실질적으로 결과에 영향을 주지 못함을 시사한다.

## 제안 (P1/P2/P3)

- **P1**: 계약 상세 화면의 "역할 협상"/"주급 협상" 버튼 무반응(silent fail) 수정 — 협상이 불가능하다면 버튼을 비활성화하거나 사유를 안내해야 한다. 현재는 클릭해도 아무 피드백이 없어 사용자가 자신의 조작이 실패했는지조차 알 수 없다.
- **P1**: 출전 약속 위반이 누적될 때(예: "위반 1회" 이상) 플레이어가 쓸 수 있는 최소한의 대응 수단(조기 이적 요청, 이적 시장 강제 오픈, 감독 면담 등) 추가. 현재는 "최근 두 시즌 출전 없음" 경고 배너가 뜬 뒤에야 대안(하부리그 이적)이 제시되는데, 그 전 구간(시즌 3·4처럼)에는 아무 탈출구가 없다.
- **P2**: 챕터 헤딩 enum 노출("프로_데뷔") 수정 — 두 번째 이후 재사용되는 챕터 타입에 대한 로컬라이제이션 키가 누락된 것으로 보인다.
- **P2**: 팀명 중복 렌더링("강동강동 로버스" 등) 수정 — 짧은 이름과 긴 이름을 이어붙이는 컴포넌트에 공백 또는 조건부 렌더링 필요.
- **P3**: 국적 select 옵션을 최소 30개 이상으로 확대(또는 검색 가능한 콤보박스로 전환). 현재 10개국뿐이라 대다수 해외 배경 이용자가 자국을 찾을 수 없다.
- **P3**: 국적·성별이 생성 이후 서사에 전혀 재등장하지 않는 점 — 버그는 아니지만 기획 의도상 "국적/성별이 커리어에 어떤 의미가 있는지"를 재검토할 필요가 있다(현재는 순수 장식적 속성).

## 5점 평가 표

| 항목 | 점수 | 근거 |
|---|---|---|
| 선택의 의미 | 2/5 | 역할 수락/거절이 결과(출전 여부)에 영향을 주지 못한 사례를 직접 대조 확인(시즌 6 거절 vs 시즌 7 수락 모두 0경기). "관심 표명"류 선택이 11회 반복돼 다양성도 부족 |
| 출전·성장 루프 | 2/5 | 8시즌 중 4시즌 무출전. 반면 성장(OVR)은 출전과 무관하게 진행돼 "정체된 채로 소폭 성장"하는 이상한 밸런스 |
| 계약·시장 | 3/5 | 협상 버튼 고장은 심각하지만, 자유계약/임대/완전이적 비교 UI 자체의 정보 구성은 명확하고 이해하기 쉬움. 자기 인지형 경고 배너("최근 두 시즌 출전 없음")는 좋은 설계 |
| 부상·회복 | 4/5 | bp 단위 위험 설명이 명확하고, 고위험 선택(조기 복귀)이 실제로 재발로 이어지는 인과가 두 번 모두 체감됨 |
| 서사·연출(국적·성별 정합) | 3/5 | 부정합 문구는 없음(안전)이지만 국적·성별이 이후 전혀 언급되지 않아 존재감이 없음(밋밋함) |
| 속도·부담 | 3/5 | FAST 모드로 시즌당 6개 내외 결정만 필요해 진행은 빠르지만, "재계약 사전 협상"이 시즌 초반 갑자기 끼어들어 몰입 흐름이 끊기는 인상 |
| 재플레이 동기 | 2/5 | 벤치/예비선수 루프에 한 번 빠지면 이후 여러 시즌이 사실상 관찰자 모드가 되어, 이 프로필로는 다시 플레이하고 싶은 유인이 낮음 |

## 확정된 결함과 추정 구분

**확정(재현·원문 로그로 뒷받침됨)**
1. 계약 상세 "역할 협상"/"주급 협상" 버튼 클릭 무반응(DOM 불변, 모달 없음으로 직접 검증)
2. 챕터 헤딩 raw enum 노출 "프로_데뷔"(시즌 1·2·5·8, 4회 재현)
3. 팀명 중복 렌더링("강동강동 로버스" 등, 제안 비교·계약 화면에서 다수 재현)
4. 출전 약속 위반("위반 1회" 명시적 기록)에도 플레이어가 쓸 수 있는 이의제기/탈출 수단이 전혀 없음(시즌 3·4·6·7에서 반복 관찰)

**추정(단일 커리어라 인과 단정 불가, 추가 재현 필요)**
- 전술 적합도가 낮은 클럽에서는 역할 선택(수락/거절)과 무관하게 항상 저조 출전으로 귀결되는 경향 — 표본이 1개 커리어뿐이라 정확한 임계치나 규칙은 특정할 수 없음
- 대표팀 소집 시스템이 이 프로필(낮은 폼, 잦은 벤치)에서 트리거되지 않은 것이 국적별 로직 부재 때문인지 단순 조건 미충족 때문인지 불명

## 미검증 범위·자동화 제약

- **대표팀 소집(H2 핵심)**: 8시즌 내내 단 한 번도 트리거되지 않아 국적별 처리 방식을 전혀 검증하지 못함
- **챕터 모드 전체 비교**: 시즌 1만 챕터 모드였고 이후 전부 FAST라 "모든 챕터·이벤트" 완전 노출 시나리오는 시즌 1 한정으로만 관찰
- **은퇴 절차**: "8시즌 완료" 표시까지만 확인했고, 안전 규칙에 따라 실제 은퇴 확정 화면에는 진입하지 않음(출력·저장 금지 대상은 아니지만 시간 제약으로 생략)
- **협상 버튼 무반응이 모든 계약 유형에 적용되는지**: 잔류 재계약은 서명 절차 자체가 없어(협상 UI 미노출) 완전 대조 불가, 신규 이적/완전 이적 건에서만 확인
- **자동화 제약**: 초반 매치 챕터의 라디오 버튼이 뷰포트 밖(스크롤 컨테이너 하단)에 있어 ref 기반 클릭이 실패하는 문제를 겪었고, 좌표 기반 클릭(scrollIntoView + getBoundingClientRect)으로 전환한 뒤 안정화. 이후 세션 대부분은 텍스트 매칭 기반 자동 진행 스크립트로 처리했으며, 반복되는 "관심 표명"류 선택을 매번 동일한 휴리스틱(위험도 마커 우선)으로 골라 실제 사용자가 탐색했을 다른 선택지 조합은 보지 못했을 수 있음
