# Player life 3.0 — 훈련·경기·관계 연결

새 커리어는 ruleset 3.0.0 / content pack 0.9.0을 사용한다. 기존 커리어는 저장된 버전으로 계속 재생한다.

## 플레이 변화

- 매 시즌 초반·중반·후반에 한 번씩 육성 계획을 정한다. 훈련 종류, 강도, 함께할 사람을 한 화면에서 확정한다.
- 포지션 기술 / 피지컬 / 경기 읽기 중 하나를 훈련한다. 기술 훈련은 스트라이커의 슈팅, 수비수의 태클, 골키퍼의 선방처럼 포지션별 실제 능력치를 사용한다.
- 회복은 능력 성장 없이 체력 +20, 균형은 두 능력 +1~2와 체력 -5, 한계 도전은 +2~3과 체력 -18이다. 성장 한도·심한 피로·부상 제한과 0~100 체력 상한을 적용한다.
- 감독 / 주장 / 경쟁자의 반응을 기존 신뢰와 저장된 난수로 결정한다. 높은 신뢰의 지원은 성장을 돕는다. 훈련 기록, 숙련, 상대 반응은 저장 후에도 유지된다.
- 중요한 경기 선택은 능력·숙련·관련 인물의 신뢰·체력 또는 사기로 성공/실패 가중치를 계산한다. 화면 확률과 실제 판정은 같은 함수를 쓴다.
- 성공·실패는 관계와 사기에 남는다. 실패도 숙련을 쌓고, 과감한 플레이는 체력을 소모한다. 이후 훈련과 경기 준비에 반영한다.
- 성장 노트에서 세 숙련과 훈련 기록을, 라커룸에서 감독·주장·경쟁자 관계를 확인한다. 경기 화면은 맥락·스코어를 한 카드로 합친다.
- 커리어 상한은 12시즌이다. 훈련을 늘리는 대신 평범한 시즌 이벤트 상한을 2→1로 줄였다. 일상 경기는 다음 실제 결정까지 진행한다.

## 구현 범위와 재현성

`DEVELOP`은 별도 저장 명령이다. 시즌당 구간별 1회만 가능하며 계획 없이 다음 구간 경기를 넘길 수 없다. 계약·부상·국가대표·경기 판단은 기존 명시 결정을 보존한다. 새 시스템은 opt-in ruleset 플래그로 동작해 역사적 커리어 해시를 바꾸지 않는다.

경기 선택은 중요한 장면의 성공 확률, 평점, 관계, 사기와 후속 준비에 영향을 준다. 해당 장면의 선택으로 이미 시뮬레이션된 경기의 득점·리그 원장을 다시 쓰지는 않는다. 훈련으로 바뀐 능력치와 체력은 이후 경기 엔진의 선발·경기 계산에 사용된다. 실시간 축구 조작이나 자유 생성 대화는 이번 범위가 아니다.

## 검증

- 도메인: 구간별 중복 훈련 금지, 성장/회복 tradeoff, 같은 seed 재현, ACTIVE/REHAB 부상 제한, 성장 상한, 능력·숙련·신뢰에 따른 확률 변화, 실패의 관계/숙련 효과.
- 계약 스키마: 새 상태 JSON roundtrip, 타입 일치, 잘못된 계획과 숙련 상한 거부.
- 웹 엔진 통합: 세 훈련 구간 모두 저장, 준비 전 ADVANCE 거부, 중복 DEVELOP 거부, 경기 중복 없음, 결산 완료.
- 전체 기존 테스트 + 웹 674개 통과. 전체 병렬 실행 중 모바일 테스트 1건은 5초 타임아웃이었으며 worker 수를 2로 제한한 전체 웹 재실행에서 통과했다.
- 브라우저: 생성→계약 서명→시즌 시작→훈련→저장 후 새로고침→데뷔전 판정→성장/라커룸 확인. 모바일 경기 카드 높이를 줄여 선택지 접근을 개선했다.
- 40개 seed × 최대 12시즌 FAST 은퇴 시뮬레이션 및 snapshot 검증. 40/40 은퇴, 480시즌, 실패 0건, 엔딩 5종. 평균 저장 명령 219.4개.

20~30분은 UX 목표이며 사람의 전체 플레이 시간을 측정한 결과가 아니다. 명령 수에는 자동 진행·저장·결산도 포함되므로 클릭 수나 플레이 시간으로 환산하지 않는다.
