# 짧게 완주하는 선수 육성 — 2.1.0 / 0.8.0

한 선수에게 오래 묶이지 않으면서, 직접 정한 육성 방향과 진로가 후속 사건에 남도록 한다. 목표 세션은 20~30분이다. 이는 설계 목표이며 실제 이용자 완주 시간 측정치는 아니다.

- 새 커리어는 최대 12시즌 뒤 마지막 선택(은퇴 / 지도자 에필로그)에 도달한다. 마지막 시즌 뒤 신규 이적 시장은 열지 않는다.
- 다음 중요한 순간까지 진행한다. 선택 없는 계약 확인은 통과하지만, 이벤트·부상·역할 변경·제안 수락은 사용자가 결정한다. 내부 명령은 단계별로 저장한다.
- 시즌당 일반 사건은 최대 2회다. 필수 부상·국가대표 선택은 별도로 처리한다. 과거 선택 재등장 제한도 유지한다.
- 기술·몸·판단력 육성 선택은 실제 능력치와 태그를 바꾸고, 해당 경로의 후속 사건만 후보에 넣는다. 국내 정착 / 해외 도전 / 적응 / 경쟁 / 재도전 / 마지막 시즌 회고 등 10개 사건을 추가했다.
- 해외 도전 의사를 밝히고 2시즌을 경험한 선수에게 시장가치에 맞는 해외 구단이 제안한다. 일본·포르투갈의 가상 리그 2개와 계약 가능 구단 4개를 추가했다. 각각 8팀 홈·원정 14경기이며 한국 컵에는 참가하지 않는다. 해외 재계약과 결과 화면도 실제 리그명을 유지한다.
- 기존 커리어는 고정된 원래 룰셋·팩으로 진행한다. 이전 콘텐츠 파일은 수정하지 않는다. 새 pair를 서비스 시즌·클라이언트·API 허용 목록에 함께 등록한다.

## 검증

- 무작위 정책, GK/DF/MF/FW, FAST, 시드 40개, 최대 14시즌, 엔딩 및 결정론 검증: **40/40 성공, 전원 12시즌 종료**.
- 해외 진출: 8/40명, 해외 리그 34시즌. 신규 해외 4개 구단 모두 실제 시즌 진행에 등장했다.
- 결말: COMPLETE-SHORT 25명, COMEBACK-PLAYER 11명, PROMOTION-CAPTAIN 2명, NATIONAL-HERO 1명, JOURNEYMAN 1명.
- 내부 저장 명령 평균 149.7회(115~202회). 자동 진행과 생성 명령을 포함하므로 사용자 클릭 수나 플레이 시간으로 해석하지 않는다.
- 도메인 979개, 콘텐츠 494개, 웹 672개, API 230개 테스트 통과. 새 육성 분기·해외 제안 자격·일정·마지막 시즌 시장 종료·추가 시즌 차단·자동 진행 중단 테스트를 포함했다.
- 전체 타입 검사, lint, 의존성 검사, 빌드, 팩 및 과거 룰셋 체크섬 검증 통과.
- 병렬 검사 중 기존 1,000회 결정론 성능 테스트가 10초 한도를 초과했다. 단독 재검사에서 6개 테스트 모두 통과(전체 1.53초), 해시 불일치는 없었다.

## 남은 측정

20~30분 완주와 후속 사건의 체감 빈도는 실제 이용자 세션으로 측정해야 한다. 12시즌에서는 기존 장기 커리어보다 최종 OVR과 수상 기회가 낮을 수 있다. 이번 실험의 최고 OVR 평균은 66.22이며, 장기 육성용 Legacy 분포와 동일한 결과라고 주장하지 않는다. Jev 호출은 포함하지 않는다.
