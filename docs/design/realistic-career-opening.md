# 현실적인 출발 상황과 후속 이야기 — 로컬 개선

2026-09-06. 사용자 요청: 한국 선수 사례 조사 내용을 반영하고 로컬에서 검증한다. **배포·운영 시즌 변경·커밋·PR은 하지 않는다.**

근거: [한국 축구 선수 사례 조사](../research/korean-football-career-stories.md). 이전 상태: [19세 도입 설계](nineteen-kickoff.md).

## 이번 범위

이번 구현은 조사 문서 전체의 시스템 확장이 아니라, 현재 엔진으로 실행 가능한 첫 콘텐츠 묶음이다.

- 모든 선수가 명단에서 탈락한 뒤 같은 공개 테스트에 도전한다는 공통 도입을 제거한다.
- 아카데미·학교·지역 클럽 배경마다 다른 첫 사건을 연결하고 선택별 후속 사건을 제공한다.
- 선호 포지션을 강제로 바꿨다고 서술하지 않고, 감독과 훈련·평가 방식을 조율하는 짧은 이야기를 다룬다.
- 계약과 출전 성공을 보장하지 않는다. 실제 효과와 다른 미래의 성과를 미리 확정해 쓰지 않는다.

배경과 별개인 독립 출발 상황 필드는 아직 추가하지 않는다. 이번에는 저장되는 `backgroundId`를 사용해 출발 상황을 결정한다. 대학, 생활비, 언어 적응, 별도 부상 복귀 출발점은 미구현이며 선택지로 제시하지 않는다. 실존 선수의 이름·사진·대사를 게임에 옮기지 않는다.

## 버전과 로컬 환경

- 규칙 `1.2.0`의 19세 시작은 유지하고 새 콘텐츠 팩 `0.4.1`을 추가한다.
- 이미 로컬 선수가 사용하는 `0.4.0`과 기존 규칙 파일은 수정하지 않는다. 기존 선수의 이야기를 중간에 교체하지 않는다.
- `svc_realistic_story_qa`는 INSERT-only 로컬 테스트 시즌이다. 기존 행과 운영 포인터를 덮어쓰지 않는다.
- API: `http://localhost:8797`, 웹: `http://localhost:5200`.
- 기존 `5199/8796` 환경도 유지한다. 새 환경에 만든 테스트 선수만 새 사건을 경험한다.
- 서버 현재 시즌 API에서 `isTest:true`, `PRESEASON`, `1.2.0/0.4.1`, 종료일 미정을 확인했다.

## 검증 방침

문구 하나마다 테스트를 고정하지 않고, 배경별 도달·선택의 후속·저장 복구·계약 진행·기존 버전 보존을 우선 검증한다. 자동 테스트의 API 응답 대체 여부와 실제 로컬 API를 사용한 직접 플레이를 구분해 결과를 아래에 기록한다.

## 실제 구현된 사건

| 출발 배경 | 첫 사건 | 선택별 후속 |
| --- | --- | --- |
| 클럽 아카데미 | `EVT-CON-020` — 추가 평가에 남거나 다른 팀 탐색 | `023` 평가 기준 확인 / `024` 관찰 훈련 이후 진로 결정 |
| 학교팀 | `EVT-CON-021` — 성인 하부리그 훈련 또는 상위 팀 테스트 | `025` 성인 무대 템포 적응 / `026` 평가에서 무엇을 보여줄지 결정 |
| 지역 클럽 | `EVT-CON-022` — 현재 생활에서 준비 또는 환경을 옮겨 참가 | `027` 준비한 경기와 자료 평가 / `028` 합동 훈련의 적응 방식 |

각 첫 사건의 두 선택과 후속의 두 선택은 모두 기존 계약 생성 규칙에 연결된다. 새 제도나 새 리그를 만든 것은 아니다. 기존 시스템의 안전한 진로 제안은 유지하며, 관찰 초대와 계약 체결을 같은 장면으로 취급하지 않는다.

`EVT-MGR-020`은 젊은 프로 선수의 프리시즌에 훈련 임무를 협의한다. 새 임무 시험은 전술 적합도와 초기 폼 부담을, 기존 장점 증명은 감독 신뢰와의 교환을 다룬다. `EVT-MGR-021`은 시즌 중에 그 협의를 마무리한다. 실제 선수 포지션을 바꾸거나 존재하지 않는 출전 기록을 서술하지 않는다.

새 사건을 판별하기 위해 조건 DSL에 `player.backgroundId`를 추가했다. 새 저장 필드나 과거 선수 마이그레이션은 없다. 결과 카드에서는 내부 태그 ID 대신 읽을 수 있는 표시용 라벨을 쓰며 저장·분기용 ID는 유지한다.

## 리뷰·직접 플레이에서 수정한 문제

1. 공통 ‘명단 탈락·내일 공개 테스트’ 도입을 배경별 상황으로 변경했다.
2. 같은 후속에서 한 선택만 이득인 구성을 조정하고, 실제 효과와 안내가 일치하도록 검토했다.
3. 골키퍼도 윙어로 설명하던 `EVT-DEV-001`을 새 팩에서 제외하고, `EVT-REL-001`의 포지션 고정 문구를 수정했다. 이전 팩은 그대로다.
4. 새 후속에서 평가를 마쳤는데 기존 입단 테스트가 다시 나오던 경로를 차단했다. 첫 계약 조건이 갖춰지면 다른 청소년 사건 대신 제안으로 진행한다.
5. 위 우선 처리는 새 팩·첫 시즌 전·YOUTH·계약 없음·진행 중 시즌 없음으로 한정했다. 이후 무계약 상태의 사건을 가리지 않는다.
6. 복제된 구버전 테스트와 사건을 비활성화하기 위한 임의 `maxAge:0` 규칙을 제거했다. 새 팩의 실제 등록 목록으로 관리한다.
7. 선수 생성 CSS의 기존 직접 색상값을 디자인 토큰으로 바꿔 색상 정책 검사 실패를 해소했다.

직접 플레이 선수 ID는 `48260f63-644c-44de-ab34-7d47a818fd8d`다. 수정 중 발견한 중복 테스트 사건은 이 QA 선수의 과거 기록에 남겨두었고, 최종 변경분은 12경로 엔진 검증과 브라우저 E2E로 다시 확인했다. 기록을 지워서 문제가 처음부터 없었던 것처럼 만들지 않았다.

새 팩 최종 체크섬: `8d46e7407eeb60f99f6a6e6a76df3b592c00126e48eb7ee790b0f3149ab0939a`.

콘텐츠 검사에는 일회성 사건 10개의 ‘높은 weight·cooldown 없음’ 정적 경고가 남는다. 이 엔진은 cooldown이 없으면 해결한 사건을 재등장시키지 않는다. 경고를 없애려고 반복 가능성을 부여하지 않았다. 빌드의 기존 라우트 테스트 파일 안내 및 번들 크기 경고도 이번 기능 오류와 구분한다.

신규 팩의 모든 엔딩·장기 밸런스·모든 기기에서의 제스처를 검증한 것은 아니다. 대학·독립 출발 상황·해외 적응 확장은 여전히 후속 범위다. 운영 서비스 시즌은 바꾸지 않았으며 커밋·PR·배포는 하지 않았다.
