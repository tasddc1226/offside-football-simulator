# Phase 1. 커리어 수직 슬라이스

## 목표

사용자가 선수를 만들고 유소년 배경과 입단 테스트를 거쳐 첫 프로 계약을 체결한다.

## 완료 후 흐름

```text
SCR-001 커리어 허브
→ SCR-002 선수 생성
→ SCR-003 플레이 스타일
→ SCR-004 생성 확인
→ SCR-007 진로 선택
→ 입단 테스트 이벤트
→ SCR-009 지명/제안 결과
→ SCR-010 첫 계약
→ 커리어 대시보드
```

## 포함 범위

- 이름, 주발, 국적, 포지션군·세부 포지션, 아키타입, 유소년 배경.
- 초기 세부 능력과 Base OVR, Potential 정본·정찰 범위.
- 학교/클럽 아카데미/해외 유학 배경 효과.
- 입단 테스트 선택 이벤트와 1~3개 계약 제안.
- 첫 계약의 기간·급여·예상 역할·등번호.
- DRAFT→ACTIVE 전환과 첫 Career Snapshot.

## 기능 요구사항

- FR-CAR-001, FR-PLY-001, FR-OVR-001, FR-EVT-001, FR-CON-001, FR-SAV-001.
- 선수 생성 확정 전에는 영구 능력 seed를 소비하지 않는다.
- 포지션과 맞지 않는 아키타입 조합은 서버에서도 거부한다.
- 계약 확정은 Player, Career, Contract, Timeline을 한 트랜잭션으로 저장한다.

## 구현 슬라이스

1. 생성 DRAFT와 유효성 검사.
2. 역할 가중치와 OVR golden fixture.
3. 배경 선택과 Effect 적용.
4. 입단 테스트 EventDefinition/Resolver.
5. 계약 Offer 생성·비교·확정.
6. 새로고침·뒤로 가기·응답 유실 복구.

## API·데이터

- API-CAR-001, 004, 005.
- API-EVT-001~002.
- API-CON-001, 003.
- Player, Career, Contract, CareerEvent, Snapshot.

## 완료 조건

- [ ] 360px 모바일과 키보드로 첫 계약까지 완료한다.
- [ ] 새로고침 후 DRAFT와 확정 단계가 각각 복원된다.
- [ ] 포지션별 아키타입과 OVR 기대값이 golden test와 일치한다.
- [ ] 중복 확정으로 선수·계약이 복제되지 않는다.
- [ ] 실패 결과도 안전한 계약 또는 재도전 경로를 제공한다.
- [ ] 생성된 Career에 서비스 시즌·규칙·콘텐츠 버전이 고정된다.

## 제외

실제 리그 시즌, 임대·이적 협상, 부상, 관계망, 은퇴, 시즌 도전.
