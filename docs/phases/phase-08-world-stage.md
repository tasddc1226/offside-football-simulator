# Phase 8. WORLD STAGE 세계관 확장

## 목표

국내에서 성장한 선수가 해외 제안을 비교하고 등록·적응의 대가를 감수하며, 가상 해외 리그와 대륙 클럽 대회 및 대표팀 국제대회까지 커리어를 확장한다.

Phase 8은 운영 안정화 후 출시하는 확장 개발 단계다. 새 ruleset에서는 선수 인생의 Phase 3 이적시장부터 WORLD STAGE 콘텐츠가 나타나며 Phase 4~5의 관계·대표팀·Legacy에도 이어진다.

## 완료 후 흐름

```text
국내 시즌·이적시장
→ 해외 관심과 진출 가능성 확인
→ 국내 잔류/해외 주전/상위 리그 후보 제안 비교
→ 등록·계약 원자 확정
→ 현지 적응 계획과 주전 경쟁
→ 리그·컵·대륙대회·대표팀
→ 월드 커리어 결산·이적 또는 은퇴
```

## 포함 범위

- `Country`, `League`, `Competition`, 확장 `Team`, `RegistrationPolicy`, `AdaptationContext`.
- 구 `leagueTier` Team을 국내 가상 리그로 읽는 호환 변환기.
- 해외 관심, 제안, 등록 판정, 통화·급여 비교, 이주 지원 선택.
- 해외 국가 2개·4개 디비전·24개 구단의 첫 콘텐츠 슬라이스.
- 리그·국내 컵·대륙 클럽 대회 일정과 대표팀 차출 충돌 처리.
- 서로 다른 축구 문화를 가진 최대 5개 가상 리그 스타일 확장.
- 국내 잔류, 해외 중소 구단 주전, 유명 무대 후보를 모두 유효하게 만드는 밸런스.
- 국제 커리어 연대기, 트로피, Legacy 설명 태그.

상세 계약은 [WORLD STAGE 개발 명세](../development/15-world-stage-expansion.md)를 따른다.

## 구현 슬라이스

1. 세계 데이터 스키마와 content validation.
2. ruleset 1.x Team 호환 어댑터와 구 fixture hash 회귀.
3. 제안 생성기의 국가·리그·등록·통화·전술 입력.
4. 해외 Offer 비교와 `ACCEPT_OFFER` 원자 등록 판정.
5. 적응 Context·이벤트·성과 원인 태그.
6. 복수 대회 일정과 `CompetitionRecord` 집계.
7. 국제 경기 챕터와 대표팀 연계.
8. 월드 커리어 결산, Timeline, Legacy 정규화.
9. 리그 팩 검증·번역 키·가상 브랜드 자산 파이프라인.
10. E2E·마이그레이션·접근성·밸런스 리포트.

## 화면

- SCR-035 세계 무대·관심 현황.
- SCR-036 해외 제안 비교.
- SCR-037 등록·이적 결과.
- SCR-038 현지 적응 계획.
- SCR-039 국제 경기 챕터.
- SCR-040 월드 커리어 결산.

SCR-017~020, SCR-029, SCR-032도 WORLD STAGE 데이터로 확장한다.

## 완료 조건

- [ ] 국내 Career가 해외 콘텐츠 없이 이전과 같은 결과로 완주한다.
- [ ] 새 Career가 국내→해외 이적→현지 첫 시즌을 완주한다.
- [ ] 등록 실패 시 기존 계약·팀·Snapshot이 보존된다.
- [ ] 리그 이동 전후 Base OVR이 같다.
- [ ] 적응 상태가 영구 능력과 truePotential을 직접 변경하지 않는다.
- [ ] 서로 다른 통화의 제안을 역할·등록·적응과 함께 비교할 수 있다.
- [ ] 리그·컵·대륙대회·대표팀 기록이 중복 집계되지 않는다.
- [ ] 국내 원클럽과 해외 커리어가 각각 고유 엔딩에 도달한다.
- [ ] 네 포지션군이 모든 출시 리그에서 한 시즌을 완주한다.
- [ ] 실명 리그·구단을 연상시키는 금지 자산 검수가 완료된다.
- [ ] TEST-E2E-011~013과 구 ruleset migration suite가 통과한다.

## 선행 조건

- Phase 3 계약·임대·이적 상태기계 완료.
- Phase 4 관계·대표팀 기본 흐름 완료.
- Phase 5 Legacy 정규화와 Archive 완료.
- Phase 7 콘텐츠 배포·rollback·분포 리포트 완료.
- LINE TEST와 최소 한 개 서비스 시즌에서 국내 경로 기준선 확보.

## 제외

실시간 환율·세금·비자 법률, 실명 라이선스, 모든 구단의 전체 경기 시뮬레이션, PvP 이적시장, 고급 귀화·복수 대표팀 자격.
