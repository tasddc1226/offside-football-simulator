# Phase 5. 장기 성장·은퇴·Legacy

## 목표

여러 시즌의 선택을 성장·노쇠·정체성·복수 엔딩으로 회수하고, 완결된 선수 인생을 다시 볼 수 있게 한다.

## 포함 범위

- 능력별 연령 곡선, 큰 부상 후유증, 출전·코칭 기반 성장.
- 은퇴 의향과 시장가치·출전 기회·내구성·계약 상태의 합성 판정.
- 자동 은퇴 직전 마지막 계약, 코치 전환, 하부리그 도전 중 하나의 선택 기회.
- 통산 기록, 트로피, 대표팀, 최고 시즌, 수입 요약.
- Legacy Score의 구성 요소와 설명.
- CareerTimeline, CareerTag, 최종 프로필, 선수 보관함.
- 원클럽 레전드, 무관의 제왕, 승격 주장, 대표팀 영웅, 부상 복귀, 저니맨 등 복수 엔딩.

## 화면

SCR-025 은퇴·통산 기록, SCR-026 Legacy Score, SCR-027 연대기, SCR-028 최종 프로필.

## 은퇴 판정

```text
Retirement Pressure = age curve + injury burden + low market demand
                    + low playing opportunity + player intent
```

나이 하나로 자동 은퇴시키지 않는다. 판정 입력과 마지막 선택 가능 여부를 결과 전에 설명한다.

## Legacy Score

초기 구성:

- 경기·대회 성취.
- 팀 기여와 중요한 역할.
- 장기성·내구성·복귀.
- 관계·리더십·팬 기억.
- 희귀한 커리어 태그와 서사.

총점과 함께 상위 3개 기여 요인, 아쉬운 기회, 대표 엔딩을 표시한다.

## 구현 슬라이스

1. 다년 진행 성능과 연령 곡선.
2. 은퇴 압력·마지막 선택 이벤트.
3. 통산 집계와 불변 Archive.
4. Legacy 계산·설명.
5. Timeline과 최종 프로필.
6. 보관함·새 커리어 반복 루프.

## 완료 조건

- [ ] 20년 범위 fixture를 제한 시간 안에 완주한다.
- [ ] 포지션별 성장·노쇠 경계가 golden curve와 일치한다.
- [ ] 은퇴 후 일반 진행 명령이 거부된다.
- [ ] 통산 합계가 FootballSeason 기록 합과 일치한다.
- [ ] 같은 Career의 Legacy 결과가 재현된다.
- [ ] 세계 최고가 아니어도 의미 있는 엔딩을 최소 5종 제공한다.
- [ ] Archive는 생성 후 변경되지 않는다.

## 제외

은퇴 후 감독 커리어 전체 시뮬레이션, 온라인 명예의 전당, 공유 이미지 자동 생성.
