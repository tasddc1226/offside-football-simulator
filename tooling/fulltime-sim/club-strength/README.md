# 구단 전력표 월 1회 갱신 (T-11-135)

현실 리그 순위표로 게임 NPC 구단 전력(`packages/contracts/src/club-strength-fallback.json`)을 갱신한다. 기획은 T-11-132 2단계.
이 도구는 K리그1의 배포용 기본값을 수동으로 갱신하는 호환 도구다. 서버의 일일 갱신과 연결 준비는 [운영 문서](../../../docs/operations/club-strength.md)를 따른다. 서버에서 발행한 더 높은 버전은 이 기본값보다 우선한다.

## 적용 방식

- 전력표는 코드에 들어 있고 웹 배포 · 앱 OTA로 나간다. 서버 밸런스 설정은 서비스 시즌 중 잠겨 있어서(T-10-090) 쓰지 않는다.
- 커리어는 새 시즌을 시작할 때 최신 전력표를 세이브(`GameState.cs`)에 복사해 쓴다. 시즌 도중에는 바뀌지 않는다.
  새 버전을 받으면 소식에 "구단 전력표 vN(현실 순위 날짜 기준)" 한 줄이 남는다.
- 전력표에 없는 구단은 `data.ts` 기본 전력 그대로다.

## 절차

1. 공식 순위표를 보고 `standings/<리그>-<YYYY-MM-DD>.csv`에 옮겨 적는다(파일 이름 날짜 = 기준 시점, KST).
   열은 `team,p,w,d,l,pts,gf,ga`, 팀 이름은 대응표(`k1.json`)의 키와 같게. 진행 중인 경기가 없는 확정 순위표를 쓴다.
2. 미리 보기: `cd tooling/fulltime-sim && npx tsx club-strength.ts club-strength/k1.json club-strength/standings/k1-<날짜>.csv`
   - 검사(승+무+패 = 경기 수, 3×승+무 = 승점, 득실 합 0, 팀 중복, 대응표에 없는 팀·구단)에 걸리면 아무것도 쓰지 않는다.
   - 구단마다 기본 · 이전 · 목표 · 새 값이 나온다.
3. 값이 괜찮으면 `--write`를 붙여 다시 실행한다 → 버전이 1 오른다.
4. `packages/game`에서 `pnpm exec vitest run -u`(특성화·골든 스냅샷 갱신) → PR → 배포.

## 계산

- 목표 = 리그 구단 기본 전력 평균 + 6 × (경기당 승점 − 리그 평균) + 2 × (경기당 득실차 − 리그 평균, ±2에서 자름)
  - 리그 평균 경기당 승점·득실은 대응하지 않는 팀(김천 상무)까지 포함한 전체 순위표로 낸다.
  - 중심을 기본 전력 평균에 두어 리그 전체 수준은 그대로, 구단 사이 순서·간격만 현실을 따른다.
- 섞기: 새 값 = 반올림((1 − w) × 기본 + w × 목표), w = 경기 수 / (경기 수 + 10)
- 한 번에 이전 값에서 ±3, 기본 전력에서 ±6까지만. 3경기 미만이면 이전 값 유지.
- 계수는 `packages/contracts/src/club-strength-calc.ts`의 `CALC`.

## 대응표

`k1.json`은 공식 순위표 팀 이름 → 게임 구단 id. 이름이 바뀌거나 승강이 있으면 사람이 고친다(이름 유사도로 맞추지 않는다).
김천 상무는 병역 중에만 들어가는 고정 전력(63)이라 갱신하지 않고 리그 평균 계산에만 넣는다.
현실에서 강등된 팀이 게임 K1에 남아 있으면 검사가 멈춘다 — 그때 대응표와 처리 방법을 정한다.
